# Contributing To The Discovery

Genesis is a developing cognitive system 🧠

Genesis is a research codebase, and a developing cognitive intelligence. Any proposed change should make the architecture more capable, more measurable, or safer. 

## Read first 📖

- [`AGENTS.md`](AGENTS.md) — architecture invariants and the no-hardcoding rule.
- [`SECURITY.md`](SECURITY.md) — runtime boundary and reporting rules.
- [`DEVLOG.md`](DEVLOG.md) — measured behavior and known gaps.

## Required checks ✅

From a checkout with the documented system dependencies installed:

```bash
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
ruff check
python3 -m pyflakes python/ genesis_client/ infrastructure/ eval/ *.py scripts/*.py
python3 -m mypy python/ genesis_client/ infrastructure/ eval/ --ignore-missing-imports
PYTHONPATH=python:. python3 -m pytest python/tests/ -q -o addopts=''
```

On a host without a C linker, source the helper first:

```bash
. ./scripts/cargo-env.sh
```

Do not weaken a repository check to make a change pass.

## Rules that matter most

- **No canned cognition**🗑️
  Thoughts, speech, plans, and benchmark behavior must be generated by the
  architecture.
- **No hidden benchmark shortcuts** 🙈
- Do not read an evaluation's
  internals, encode a task-specific solver, or bypass honesty and readiness contracts.
- **Fix root causes** 🪾
- Prefer a small correct change over a broader workaround or quick fix.
- **Respect persistent state** 🚨
- The developmental record is not disposable;
  isolated tests and disposable daemons are required for experiments.
- **Match existing style** 🍎🍎
- Use the code's own abstractions, naming, error boundaries, and verification patterns.
- **Nothing sits unwired** 🔌
- A dormant subsystem is always wired, never removed.
