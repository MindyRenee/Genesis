# Genesis — Python runtime dependencies
# Versions float — bare names only. No pins, no bounds, no
# lockfiles, no Dependabot — see CONTRIBUTING.md.

# Core
numpy
nltk
# nltk's import chain pulls scipy.stats (collocations → metrics.
# association → fisher_exact), so scipy is a hard runtime dep — a
# stale system-site scipy built for numpy 1.x cannot substitute.
scipy
orjson
psutil

# Symbolic mathematics is an optional capability: symbolic.py imports
# sympy lazily and degrades without it. Listed in requirements-dev.txt
# so dev/CI still exercises it, or install the "math" extra.
# Image processing (visual cortex + canvas)
Pillow
opencv-python-headless
pycairo

# Browser transport — WebDriver BiDi (Firefox) and Chrome DevTools
# Protocol (Chromium) both ride one websocket session.
websockets

# Test runner — runtime dep: her tools call it through
# `sys.executable -m pytest` (project creation, proposal
# verification, self-checks), not just the dev suite.
pytest

# Optional: voice / ambient listening (Vosk offline STT + microphone,
# Piper TTS). Install separately if you want voice:
#   vosk
#   sounddevice
#   speechrecognition
#   piper-tts

# Optional: virtual HID — her hand on the machine's input bus
# (tools/hid.py). Source build (needs a C compiler); at runtime it
# needs write access to /dev/uinput — see scripts/genesis-uinput.rules.
#   evdev

# Optional: official ARC-AGI-3 games (worlds/games/official.py) plus
# the local Game Arena shelf (worlds/games/arena.py — game-arena
# pulls pyspiel, the engine Kaggle's arena evaluates on). ARC imports
# lazily; needs ARC_API_KEY from https://three.arcprize.org for full
# online access (anonymous offers fewer; the arena shelf is local and
# needs no key). arc-agi 0.9.9 was the last release validated
# against her; newer releases should be checked before relying on them.
#   arc-agi
#   game-arena
#   kaggle-environments
