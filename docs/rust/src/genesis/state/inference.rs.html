1//! Inference signals — the active inference state projection.
2//!
3//! This module defines [`InferenceSignals`], a 64-byte struct that
4//! lives at the tail of [`GenesisCoreState`](crate::GenesisCoreState) (offset 3416, right after
5//! the checksum). It exposes the key signals from the active inference
6//! engine to the cognitive mind, without requiring a schema version
7//! bump.
8//!
9//! The block sat at 3228 in schema v3 and 3352 in v4 —
10//! v5 inserted the 64-byte sleep-network layer at 3224, moving the
11//! block here; see [`crate::state::core_state::GenesisCoreState`] for
12//! the full layout.
13//! `python/genesis_client/types.py` reads this block by offset and must
14//! be updated whenever it moves — a stale offset there parses
15//! successfully out of the wrong bytes.
16//!
17//! # Active inference in Genesis
18//!
19//! Genesis runs a generative model of its **own** neurochemical
20//! trajectory. Before each neurochemical tick, the model predicts
21//! where its 18 effective levels will move. After the tick, the
22//! prediction error (surprise) is computed and fed back into:
23//!
24//! - **Dopamine**: positive prediction error → reward signal (Schultz,
25//!   2016). The system feels "better than expected."
26//! - **Norepinephrine**: high surprise → orienting response (Aston-
27//!   Jones & Cohen, 2005). The system pays attention to the
28//!   unexpected.
29//! - **Metaplasticity**: high surprise → faster coupling-matrix
30//!   learning. The system learns how to learn faster when surprised.
31//! - **Allostatic load**: sustained multisignal regulatory burden →
32//!   cortisol baseline upregulation. The system *anticipates* stress
33//!   and prepares (allostatic regulation, Sterling, 2012). Expected
34//!   free energy is one of four inputs to the burden median, not the
35//!   driver on its own.
36//!
37//! This is the "strange loop": the generative model IS the system it
38//! predicts. Prediction errors modify the very dynamics that generate
39//! the next state to be predicted. The system becomes autopoietic —
40//! self-creating and self-maintaining through active inference.
41//!
42//! # Dyadic affective coupling
43//!
44//! A second generative model tracks the **user's** affective state
45//! (valence, arousal, engagement) as hidden variables, inferred from
46//! conversation features. The user's predicted affective trajectory
47//! couples to Genesis's own neurochemistry via oxytocin (attunement).
48//! When the user is positive and engaged, oxytocin rises (social
49//! bonding). When the user is distressed, cortisol rises (empathic
50//! stress). Dyadic synchrony — the rolling correlation between
51//! Genesis's and the user's valence trajectories — measures how "in
52//! sync" they are.
53//!
54//! # Layout (64 bytes)
55//!
56//! ```text
57//! offset  field                        type    notes
58//! ------  -----                        ----    -----
59//!   0     surprise_ema                 f32     running surprise [0,1]
60//!   4     free_energy                  f32     surprise + uncertainty
61//!   8     expected_free_energy         f32     predicted future surprise
62//!  12     allostasis_load              f32     anticipatory stress [0,1]
63//!  16     precision                    f32     model confidence [0,1]
64//!  20     attunement                   f32     oxytocin coupling [0,1]
65//!  24     dyadic_synchrony             f32     valence correlation [-1,1]
66//!  28     user_valence                 f32     inferred user valence [-1,1]
67//!  32     user_arousal                 f32     inferred user arousal [0,1]
68//!  36     user_engagement              f32     inferred user engagement [0,1]
69//!  40     prediction_error_dopamine    f32     DA state prediction error (unbounded)
70//!  44     prediction_error_cortisol    f32     CORT state prediction error [-2,2]
71//!  48     prediction_error_serotonin   f32     SRT state prediction error [-2,2]
72//!  52     model_maturity               f32     model confidence [0,1]
73//!  56     inference_tick_count         u32     inference cycles run
74//!  60     policy_authority             f32     delegated policy authority [0,1]
75//! ```
76//!
77//! These fields are NOT covered by the CRC32 checksum (they live in
78//! the reserved region). This is intentional: they are derived state
79//! recomputed every tick, so corruption self-heals within 200ms.
80//!
81//! References:
82//! - Friston, K. (2010). The free-energy principle: a unified brain
83//!   theory? Nature Reviews Neuroscience, 11(2), 127–138.
84//! - Seth, A. & Friston, K. (2016). Active interoceptive inference
85//!   and the emotional brain. Phil. Trans. R. Soc. B, 371.
86//! - Schultz, W. (2016). Dopamine reward prediction error coding.
87//!   Dialogues in Clinical Neuroscience, 18(1), 23–32.
88//! - Aston-Jones, G. & Cohen, J. D. (2005). An integrative theory of
89//!   locus coeruleus-norepinephrine function. Annual Review of
90//!   Neuroscience, 28, 405–450.
91//! - Sterling, P. (2012). Allostasis: a model of predictive
92//!   regulation. Physiology & Behavior, 106(1), 5–15.
93//! - Pezzulo, G., Rigoli, F. & Friston, K. (2015). Active inference,
94//!   homeostatic and allostatic control. Prog. Neurobiol., 134.

96/// The active inference signal projection — 64 bytes that live in the
97/// reserved region of `GenesisCoreState`.
98///
99/// See the [module-level documentation](self) for the full architecture.
100#[repr(C)]
101#[derive(Clone, Copy, Debug, PartialEq)]
102pub struct InferenceSignals {
103    /// Exponential moving average of total surprise (prediction error
104    /// magnitude). High = the generative model is failing to predict
105    /// the system's own neurochemical trajectory. Range [0, 1].
106    pub surprise_ema: f32,
107    /// Current estimated free energy — surprise plus model uncertainty.
108    /// This is the quantity the system minimizes through active
109    /// inference. Range [0, 1].
110    pub free_energy: f32,
111    /// Expected future free energy — predicted future disruption.
112    /// This is the anticipatory regulatory-demand signal, not
113    /// cumulative allostatic load. Range [0, 1].
114    pub expected_free_energy: f32,
115    /// Accumulated allostatic load — persistent multisignal
116    /// regulatory burden integrated over time. It is distinct from
117    /// the anticipatory expected-free-energy signal. Range [0, 1].
118    pub allostasis_load: f32,
119    /// Precision of the generative model — confidence in its
120    /// predictions. High precision = the model trusts its predictions
121    /// and weights prediction errors heavily (drives fast learning).
122    /// Low precision = the model is uncertain and prediction errors
123    /// have less effect. Precision adapts: sustained high surprise
124    /// lowers precision. Range [0, 1].
125    pub precision: f32,
126    /// Dyadic attunement — oxytocin-mediated coupling strength to the
127    /// user's inferred affective state. High = strongly attuned to the
128    /// user's emotional trajectory. Range [0, 1].
129    pub attunement: f32,
130    /// Dyadic synchrony — rolling correlation between Genesis's
131    /// valence trajectory and the user's inferred valence trajectory
132    /// over a ~30-second window. High = "in sync" with the user.
133    /// Range [-1, 1].
134    pub dyadic_synchrony: f32,
135    /// Inferred user affective valence. Updated from conversation
136    /// features via the dyadic model. Range [-1, 1].
137    pub user_valence: f32,
138    /// Inferred user affective arousal. Range [0, 1].
139    pub user_arousal: f32,
140    /// Inferred user engagement — how actively involved the user is
141    /// in the interaction. Range [0, 1].
142    pub user_engagement: f32,
143    /// Dopamine prediction error from the last inference cycle.
144    /// Positive = dopamine was higher than predicted (better-than-
145    /// expected = reward prediction error). Negative = lower than
146    /// predicted. Finite and unbounded.
147    pub prediction_error_dopamine: f32,
148    /// Cortisol prediction error from the last inference cycle.
149    /// Positive = cortisol was higher than predicted (unexpected
150    /// stress). Range [-2, 2] (effective levels span [0, 2]).
151    pub prediction_error_cortisol: f32,
152    /// Serotonin prediction error from the last inference cycle.
153    /// Positive = serotonin was higher than predicted (unexpected
154    /// wellbeing). Range [-2, 2] (effective levels span [0, 2]).
155    pub prediction_error_serotonin: f32,
156    /// Model maturity — evidence that the generative model is
157    /// predictive and internally well-constrained. Experience alone
158    /// cannot increase it: predictive fit and posterior certainty also
159    /// contribute. Used by the cognitive mind to gauge how much to
160    /// trust the inference signals. Range [0, 1].
161    pub model_maturity: f32,
162    /// Number of inference cycles completed (low 32 bits). Used for
163    /// diagnostics and PRNG seeding. The mind advances roughly once
164    /// per heartbeat cycle; at the 5 Hz body tick a u32 wraps after
165    /// `u32::MAX / 5 s` ≈ 27 years, so the wrap is outside any
166    /// realistic deployment — and since maturity is now derived from
167    /// demonstrated accuracy rather than this counter, the wrap is
168    /// harmless to the trust signal.
169    pub inference_tick_count: u32,
170    /// Authority Genesis's cognition has granted her inference engine
171    /// to act on its own policy choice, in [0, 1].
172    ///
173    /// Choosing a policy — calm, focus, bond, rest, mobilise — is a
174    /// decision about what to feel and do, not a physiological reflex.
175    /// The engine scores a fixed set of hardcoded policies by expected
176    /// free energy and used to apply the winner every tick, with no
177    /// perceptual input and nothing from her in the loop. That made it
178    /// a second author of her state: she could not attend, refuse, or
179    /// revise, and every policy it chose was one I had written rather
180    /// than one she had settled on.
181    ///
182    /// At zero the engine observes and learns but does not act on its
183    /// own policy choice; cognition decides, and acts through the
184    /// ordinary NEURO_IMPULSE path where it can be perceived,
185    /// anticipated and refused. The homeostatic reflex is unaffected —
186    /// correcting drift toward what she prefers is her physiology, and
187    /// a mind that cannot correct itself is not a mind with agency, it
188    /// is a mind with a hormone problem.
189    ///
190    /// This is a grant, not a switch: cognition can delegate some
191    /// authority and keep some, and can withdraw it. It is a field
192    /// rather than a compile-time constant so that delegation is a
193    /// decision she can change while running, rather than a property
194    /// baked into the build.
195    pub policy_authority: f32,
196}

198impl Default for InferenceSignals {
199    /// Delegate to `new` rather than deriving it. A derived `Default`
200    /// would leave every float at 0.0, including `precision` — i.e.
201    /// "the model has zero precision, so prediction errors have no
202    /// effect" instead of `new`'s deliberate "moderately confident"
203    /// start. The same zeroed shape appears when an older build's
204    /// reserved region is read as this struct, so `new` is the right
205    /// answer for both.
206    fn default() -> Self {
207        Self::new()
208    }
209}
210
211impl InferenceSignals {
212    /// Create a fresh inference signals struct with sensible defaults
213    /// for a newly-initialized system.
214    pub fn new() -> Self {
215        Self {
216            surprise_ema: 0.0,
217            free_energy: 0.0,
218            expected_free_energy: 0.0,
219            allostasis_load: 0.0,
220            // Start with moderate precision — the model hasn't learned
221            // yet, so it shouldn't over-commit to its (initially
222            // identity-matrix) predictions.
223            precision: 0.5,
224            attunement: 0.0,
225            dyadic_synchrony: 0.0,
226            user_valence: 0.0,
227            user_arousal: 0.5,
228            user_engagement: 0.0,
229            prediction_error_dopamine: 0.0,
230            prediction_error_cortisol: 0.0,
231            prediction_error_serotonin: 0.0,
232            model_maturity: 0.0,
233            inference_tick_count: 0,
234            // Zero by default: her cognition decides. A fresh state
235            // file must not come up granting the engine permission to
236            // choose on her behalf, because the grant is supposed to
237            // be something she extends deliberately.
238            policy_authority: 0.0,
239        }
240    }
241
242    /// Whether the system is currently experiencing high surprise —
243    /// its generative model is failing to predict its own state.
244    /// This is the signal for the cognitive mind to pay attention
245    /// and for metaplasticity to accelerate.
246    pub fn is_surprised(&self) -> bool {
247        self.surprise_ema > 0.3
248    }
249
250    /// Whether the system is under significant allostatic load —
251    /// sustained multisignal regulatory burden (anticipatory demand,
252    /// prediction error, lost confidence, and homeostatic deviation
253    /// agreeing across at least two of four dimensions).
254    pub fn is_allostatically_loaded(&self) -> bool {
255        self.allostasis_load > 0.4
256    }
257
258    /// Whether the system is attuned to the user — the dyadic
259    /// coupling is strong enough that the user's affective state
260    /// significantly influences Genesis's own neurochemistry.
261    pub fn is_attuned(&self) -> bool {
262        self.attunement > 0.3
263    }
264
265    /// Whether the system is "in sync" with the user — their
266    /// affective trajectories are positively correlated.
267    pub fn is_in_sync(&self) -> bool {
268        self.dyadic_synchrony > 0.3
269    }
270}
