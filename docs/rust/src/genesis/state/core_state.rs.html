1//! Genesis core state — the single memory-mapped structure that holds
2//! Genesis's entire runtime state.
3//!
4//! This is the hub of the brain. Every module reads from and writes to
5//! this structure. It is designed to be:
6//!
7//! - **Memory-mapped**: lives in a single contiguous file, mmap'd into
8//!   all Genesis processes.
9//! - **Fixed-size**: no heap allocations, no pointers, no variable-length
10//!   data. The entire struct is `#[repr(C)]` with a stable binary layout.
11//! - **Lock-free readable**: uses a sequence lock in the header so
12//!   readers never block writers and vice versa.
13//! - **Versioned**: magic bytes + schema version detect format mismatches.
14//! - **Checksummed**: CRC32 detects corruption from crashes mid-write.
15//!
16//! ## Schema v5 layout (3480 bytes)
17//!
18//! ```text
19//! offset  field             type                size
20//! ------  -----             ----                ----
21//!   0     header            CoreStateHeader      56
22//!  56     neurochemicals    NeurochemicalVector 2416
23//! 2472    zones             ActiveZones          96
24//! 2568    memory            MemoryPointers      120
25//! 2688    manifest          RuntimeManifest     536
26//! 3224    sleep_network     SleepState           64
27//! 3288    ions              IonState            124
28//! 3412    checksum          u32                   4
29//! 3416    inference_signals InferenceSignals      64
30//! 3480    TOTAL                                  3480 bytes
31//! ```
32//!
33//! Schema v5 inserted the sleep-wake network ahead of `ions`. Schema
34//! v4 had inserted `ions` ahead of the checksum, so both v3 and v4
35//! files are decoded through their byte-exact legacy types and widened
36//! rather than reinterpreted in place. The sleep network and ion block
37//! sit *inside* the CRC32 region because they are authoritative state,
38//! not derived: dropping them would reset the body's sleep pressure or
39//! the cell's resting state on every restart.
40//!
41//! That's ~3.4 KB — fits in a single 4 KB page with room to spare.
42//!
43//! The tail is `inference_signals`, sized to exactly
44//! `size_of::<InferenceSignals>()` so that adding a signal field
45//! cannot shift anything else. Such a growth is a *size* migration,
46//! not a version one: see [`GenesisCoreState::migrate_layout`].
47//!
48//! ## What's new in v3
49//!
50//! - **6 new neurochemicals**: endocannabinoids (retrograde signaling),
51//!   vasopressin (social bonding, HPA axis), CRH (upstream HPA trigger),
52//!   orexin (hypocretin, arousal promotion), epinephrine (adrenaline,
53//!   fast stress response), melatonin (circadian sleep hormone).
54//!   Total: 18 chemicals (up from 12).
55//! - **Receptor subtype modeling**: D1/D2 for dopamine, 5-HT1A/5-HT2A
56//!   for serotonin, with subtype-specific sensitivities.
57//! - **Split receptor adaptation**: desensitization (fast,
58//!   phosphorylation-based) and internalization (slow, membrane removal)
59//!   as separate mechanisms.
60//! - **Allosteric modulation**: GABA-A allosteric site for
61//!   benzodiazepine-like enhancement.
62//! - **Region-specific serotonin→dopamine coupling**: striatum (5-HT2A,
63//!   inhibitory) vs PFC (5-HT1A, facilitatory) vs default (average).
64//! - **GABA disinhibition**: high GABA + high ACh disinhibits glutamate.
65//! - **BDNF recovery after stress**: serotonin-driven BDNF recovery when
66//!   cortisol drops.
67//! - **Hard clamps**: cortisol max 0.80, NE max 0.90 (safety mechanism).
68//! - **Customizable tick parameters**: NeuroTickParams struct with
69//!   tick_with_params() method.
70//! - **Increased restoring force**: 20% (up from 10%) for faster
71//!   recovery from chronic stress.
72//! - **Version migration**: migrate_state() framework for v2→v3 upgrades.
73//!
74//! ## What's new in v3.1
75//!
76//! - **HPA axis cascade**: CRH → ACTH → cortisol with time delays and
77//!   negative feedback, replacing direct cortisol manipulation.
78//! - **Tonic/phasic distinction**: tonic_level and phasic_level fields
79//!   model sustained vs burst-firing neurotransmission. For dopamine,
80//!   tonic activates D2 (high-affinity) and phasic activates D1
81//!   (low-affinity). For serotonin, tonic activates 5-HT1A and phasic
82//!   activates 5-HT2A.
83//! - **Vesicular pool depletion**: impulses deplete the vesicular pool,
84//!   causing synaptic depression when the pool is low. Synthesis and
85//!   reuptake slowly replenish it.
86//! - **Narcolepsy modeling**: low orexin (<0.10) causes sudden
87//!   histamine drops, modeling cataplexy/sleep attacks.
88//! - **Improved valence equation**: adds NE, endorphin, glutamate
89//!   excess, and DA×SRT nonlinear synergy terms.
90//! - **Improved arousal equation**: adds orexin and epinephrine,
91//!   weights adenosine more heavily for sleep pressure, and models
92//!   the bistable sleep-wake flip-flop with hysteresis.

103/// Size of the [`InferenceSignals`] tail. The field began as the
104/// schema-v3 reserved region (which let it grow without a version
105/// bump), and it still occupies exactly 64 bytes at the end of the
106/// struct.
107///
108/// `inference_signals` now starts at 3416, after the checksum that
109/// follows the schema-v5 sleep network and schema-v4 ion block, and
110/// ends at 3416 + 64 = 3480, which is the struct's size exactly.
111pub const RESERVED_BYTES: usize = 64;
112
113/// The struct size under schema v3 before [`InferenceSignals`] gained
114/// `policy_authority` — that field took the reserve from 60 to 64 bytes
115/// and the struct from 3288 to 3296.
116///
117/// This was a *size* migration, not a version one: the schema label
118/// stayed at 3 deliberately, because the reserve existed precisely so
119/// that growing the signals block would not move any other field. A v3
120/// state file written before the field existed therefore carried
121/// `version = 3` but `state_size = 3288`, and the v3 verifier reported
122/// [`CoreStateError::SizeMismatch`] — a variant that
123/// [`GenesisCoreState::migrate_state`] never sees, because it dispatches
124/// on version. [`GenesisCoreState::migrate_layout`] retains the
125/// same-version growth path.
126pub const LEGACY_SIZE: u32 = 3288;
127
128/// CRC32 polynomial (IEEE 802.3 — same as zlib / PNG).
129const CRC32_POLY: u32 = 0xEDB88320;
130
131/// Pre-computed CRC32 table for fast lookup (8x faster than bit-by-bit).
132/// Built once at startup from the polynomial.
133static CRC32_TABLE: [u32; 256] = {
134    let mut table = [0u32; 256];
135    let mut i = 0;
136    while i < 256 {
137        let mut crc = i as u32;
138        let mut j = 0;
139        while j < 8 {
140            crc = if crc & 1 != 0 {
141                (crc >> 1) ^ CRC32_POLY
142            } else {
143                crc >> 1
144            };
145            j += 1;
146        }
147        table[i] = crc;
148        i += 1;
149    }
150    table
151};
152
153/// CRC32 (IEEE) of `bytes`, with the same table as the core state
154/// checksum. Shared so sidecar files carry the same integrity check.
155pub fn crc32_ieee(bytes: &[u8]) -> u32 {
156    let mut crc = 0xFFFFFFFFu32;
157    for &byte in bytes {
158        crc = (crc >> 8) ^ CRC32_TABLE[((crc ^ byte as u32) & 0xFF) as usize];
159    }
160    crc ^ 0xFFFFFFFFu32
161}

163/// The complete Genesis core state.
164///
165/// See the [module-level documentation](self) for the full layout.
166#[repr(C)]
167#[derive(Clone, Copy, Debug)]
168pub struct GenesisCoreState {
169    /// Identity and versioning header.
170    pub header: CoreStateHeader,
171    /// 18-chemical coupled neurochemical dynamics.
172    pub neurochemicals: NeurochemicalVector,
173    /// Active task zone, emergent phase, and subcognitive flags.
174    pub zones: ActiveZones,
175    /// Memory store pointers and emotional gating weights.
176    pub memory: MemoryPointers,
177    /// Runtime module manifest table.
178    pub manifest: RuntimeManifest,
179    /// Sleep-wake network state: `[f_lc, f_vlpo, f_r, f_scn, h, c, xc, n]`.
180    /// Authoritative, like the ions: the homeostatic sleep pressure and the
181    /// circadian oscillator are not derivable from anything else. Placed
182    /// after `manifest` so it lands on an 8-byte boundary with no padding
183    /// inside the checksum region. See [`crate::state::sleep_network`].
184    pub sleep_network: SleepState,
185    /// Ion electrochemistry — calcium, chloride, potassium, sodium.
186    /// Sits ahead of the checksum because concentrations, gradients,
187    /// and membrane potential are authoritative persistent state, not
188    /// derived: losing them resets the cell's resting state. See
189    /// [`IonState`].
190    pub ions: IonState,
191    /// CRC32 checksum of all preceding bytes (header.reserved excluded).
192    pub checksum: u32,
193    /// Active inference signals — the generative self-model's
194    /// projection. Lives in the former reserved region (64 bytes).
195    /// Not covered by the CRC32 checksum (derived state, recomputed
196    /// every tick). See [`InferenceSignals`].
197    pub inference_signals: InferenceSignals,
198}

204    /// Create a fresh core state initialised at the current schema version.
205    pub fn new(instance_id: u64, now_ms: u64) -> Self {
206        let mut state = Self {
207            header: CoreStateHeader::new(instance_id, Self::SIZE as u32, now_ms),
208            neurochemicals: NeurochemicalVector::new(now_ms),
209            zones: ActiveZones::new(now_ms),
210            memory: MemoryPointers::new(),
211            manifest: RuntimeManifest::new(),
212            ions: IonState::new(),
213            sleep_network: SLEEP_INITIAL,
214            checksum: 0,
215            inference_signals: InferenceSignals::new(),
216        };
217        // Sync the emergent phase and emotional gating from the
218        // freshly initialised neurochemical system.
219        state.sync_neurochemistry_to_state();
220        state.checksum = state.compute_checksum();
221        state
222    }

224    /// Take the sleep stage from the sleep-wake network and publish it to the
225    /// neurochemical phase and the zones.
226    ///
227    /// The network decides sleep and its stages; the chemistry still names
228    /// the waking phases. No override is applied here: the published phase
229    /// is always the switch's own state. The organism has no "declared
230    /// sleep" — biology has none either; Process S tracks the physiological
231    /// state, not the intention, so a cognitively asleep mind whose body
232    /// could not cross sees the truth (a waking phase) and its desync check
233    /// joins the body in whichever direction it actually went.
234    pub fn apply_network_phase(&mut self) {
235        let phase = super::sleep_network::stage(&self.sleep_network, self.neurochemicals.phase());
236        self.neurochemicals.emergent_phase = phase as u8;
237        self.zones.sync_phase(phase);
238    }

240    /// Propagate the neurochemical system's derived state to the
241    /// zones (emergent phase) and memory pointers (gating weights).
242    ///
243    /// This must be called after every neurochemical tick to keep
244    /// the rest of the state consistent with neurochemistry.
245    pub fn sync_neurochemistry_to_state(&mut self) {
246        // Sync emergent phase. The phase is published exactly as the
247        // chemistry/network computed it — the zone's Sleeping
248        // declaration does not touch it. Sleep stages reach this byte
249        // only via `apply_network_phase` (the classifier abstains on
250        // them), so during real sleep the stamped NREM/REM survives
251        // here; a mind that merely *claims* sleep while its body stays
252        // awake is honestly shown a waking phase.
253        let neuro_phase = self.neurochemicals.phase();
254        self.zones.sync_phase(neuro_phase);
255
256        // Sync emotional gating weights
257        self.memory.update_gating(
258            self.neurochemicals.effective(NeurochemicalId::Dopamine),
259            self.neurochemicals.effective(NeurochemicalId::Serotonin),
260            self.neurochemicals
261                .effective(NeurochemicalId::Norepinephrine),
262            self.neurochemicals
263                .effective(NeurochemicalId::Acetylcholine),
264            self.neurochemicals.effective(NeurochemicalId::Cortisol),
265            self.neurochemicals.effective(NeurochemicalId::BDNF),
266            self.inference_signals.allostasis_load,
267        );
268
269        // Calcium is the membrane-level plasticity signal: resting Ca²⁺
270        // modestly gates learning, while bounded Ca²⁺ influx restores the
271        // neurochemical gate. This keeps ion dynamics below the abstract
272        // neurotransmitter layer without duplicating BDNF/cortisol logic.
273        self.memory.plasticity_gate = crate::state::sanitize::finite_clamp(
274            self.memory.plasticity_gate * self.ions.plasticity_modulator(),
275            0.0,
276            1.0,
277        );
278    }

280    /// Advance the neurochemical system by one tick and propagate
281    /// the derived state to zones and memory.
282    ///
283    /// This is the main "heartbeat" of the affective system. It should
284    /// be called by the dynamics engine at regular intervals (~100ms).
285    pub fn neuro_tick(&mut self) {
286        self.neurochemicals.tick_default();
287        self.sync_neurochemistry_to_state();
288    }

290    /// Advance the neurochemical system with full custom params and
291    /// propagate the derived state.
292    pub fn neuro_tick_with_params(&mut self, params: &NeuroTickParams) {
293        // Region-specific SRT→DA coupling follows the cognitive zone:
294        // deliberative zones drive the PFC (5-HT1A facilitatory) path,
295        // idle/sleep fall back to the averaged default. Striatum
296        // remains reachable for direct callers (e.g. a future
297        // action-execution channel via set_active_region).
298        self.neurochemicals
299            .set_active_region(if self.zones.zone().is_cognitive() {
300                ActiveRegion::Pfc
301            } else {
302                ActiveRegion::Default
303            });
304        self.neurochemicals.tick_with_params(params);
305        self.ions.tick(&self.neurochemicals, params.dt);
306        self.sync_neurochemistry_to_state();
307    }

311    /// Migrate a state from an older schema version to the current one.
312    ///
313    /// This function provides the framework for upgrading state files
314    /// when the schema changes. Currently, v2→v3 migration initializes
315    /// the 6 new chemicals and fills the expanded coupling matrix.
316    ///
317    /// # Migration strategy
318    ///
319    /// When the schema version changes (e.g., v2 → v3):
320    /// 1. Read the old state from disk
321    /// 2. Create a new state at the current version
322    /// 3. Copy over all fields that haven't changed
323    /// 4. Initialize new fields with defaults
324    /// 5. Recompute checksum
325    ///
326    /// # Parameters
327    /// - `from_version`: the schema version of the source state
328    ///
329    /// # Returns
330    /// - `Ok(())` if migration succeeded (or was a no-op)
331    /// - `Err(CoreStateError)` if migration is not supported
332    pub fn migrate_state(&mut self, from_version: u32) -> Result<(), CoreStateError> {
333        match from_version {
334            // v2 → v3: initialize the 6 new chemicals (endocannabinoid,
335            // vasopressin, CRH, orexin, epinephrine, melatonin) at their
336            // genetic defaults, fill the new coupling matrix rows/columns
337            // with the default values, and recompute derived fields.
338            //
339            // The struct size does not change: the v2 binary was
340            // already compiled with the full 18-chemical layout. (It was
341            // 3288 bytes then; see `migrate_layout` for the later
342            // reserve growth that took it to 3296.)
343            // The 6 new chemicals may be zeroed (if written by an older
344            // binary that didn't initialize them) or may have valid data
345            // (if written by the current binary with a stale version
346            // label). We initialize them unconditionally to ensure
347            // consistency.
348            2 => {
349                let new_chemicals = [
350                    NeurochemicalId::Endocannabinoid,
351                    NeurochemicalId::Vasopressin,
352                    NeurochemicalId::CRH,
353                    NeurochemicalId::Orexin,
354                    NeurochemicalId::Epinephrine,
355                    NeurochemicalId::Melatonin,
356                ];
357
358                for &id in &new_chemicals {
359                    // Use `get_mut_by_index` instead of `get_mut`: when
360                    // an older binary zeroed the slot, `chem.id` is 0
361                    // (Dopamine's discriminant), not the expected `id`.
362                    // `get_mut`'s id-guard would return `None`, leaving
363                    // the chemical uninitialised and mis-classified.
364                    // `get_mut_by_index` trusts the array position,
365                    // which is correct because `NeurochemicalId` is
366                    // `#[repr(u8)]` with stable discriminants and the
367                    // `chemicals` array is ordered by discriminant.
368                    let idx = id as usize;
369                    if let Some(chem) = self.neurochemicals.get_mut_by_index(idx) {
370                        let default_baseline = id.default_baseline();
371                        // Always restore the correct `id` field — it
372                        // may be 0 (zeroed by an old binary) or already
373                        // correct (written by current code). Setting it
374                        // unconditionally is idempotent and ensures
375                        // `get_mut` / `from_u8` work correctly after
376                        // migration.
377                        chem.id = id as u8;
378                        // Only reinitialize the dynamic fields if the
379                        // level is 0.0 (zeroed by an old binary). If
380                        // the level is non-zero, the data was written
381                        // by current code and we preserve it.
382                        if chem.level == 0.0 && chem.baseline == 0.0 {
383                            chem.level = default_baseline;
384                            chem.baseline = default_baseline;
385                            chem.tonic_level = default_baseline;
386                            chem.receptor_sensitivity = id.default_sensitivity();
387                            chem.receptor_subtypes = id.default_receptor_subtypes();
388                            chem.desensitization_factor = 1.0;
389                            chem.internalization_factor = 1.0;
390                            chem.vesicular_pool = 1.0;
391                            chem.velocity = 0.0;
392                        }
393                    }
394                }
395
396                // Only fill the new coupling matrix rows/columns when at
397                // least one of the new chemicals looked uninitialized
398                // (zeroed levels). If the state was written by the
399                // current binary with a stale version label, the coupling
400                // matrix already holds learned (metaplasticity-adapted)
401                // values that must be preserved.
402                let new_slots_uninit = new_chemicals.iter().any(|&id| {
403                    let idx = id as usize;
404                    // A zeroed slot has all-zero coupling row/col; a live
405                    // slot preserves whatever the dynamics learned.
406                    self.neurochemicals.coupling_matrix[idx]
407                        .iter()
408                        .all(|&v| v == 0.0)
409                });
410                if new_slots_uninit {
411                    for (dst_row, src_row) in self
412                        .neurochemicals
413                        .coupling_matrix
414                        .iter_mut()
415                        .zip(crate::state::neurochemical::DEFAULT_COUPLING_MATRIX.iter())
416                    {
417                        for (dst, src) in dst_row.iter_mut().skip(12).zip(src_row.iter().skip(12)) {
418                            *dst = *src;
419                        }
420                    }
421                    for (dst_row, src_row) in
422                        self.neurochemicals.coupling_matrix.iter_mut().skip(12).zip(
423                            crate::state::neurochemical::DEFAULT_COUPLING_MATRIX
424                                .iter()
425                                .skip(12),
426                        )
427                    {
428                        dst_row.copy_from_slice(src_row);
429                    }
430                }
431
432                // Update version
433                self.header.version = SCHEMA_VERSION;
434                self.header.state_size = Self::SIZE as u32;
435
436                // Recompute derived fields and checksum — on the
437                // network's own arousal readout, same as live ticks.
438                self.neurochemicals
439                    .recompute_derived_with_network(super::sleep_network::levels(
440                        &self.sleep_network,
441                    ));
442                self.sync_neurochemistry_to_state();
443                self.checksum = self.compute_checksum();
444
445                Ok(())
446            }
447            // v3 → v4: the ion layer was inserted ahead of the
448            // checksum, so a v3 file cannot be reinterpreted in place
449            // and `ions` has to be seeded. Every other field carries
450            // across unchanged — nothing before `manifest` moved, and
451            // `inference_signals` is derived state the v3 layout
452            // already carried. This arm only runs on a struct that has
453            // already been widened to the current layout (see
454            // `MmapState::open`, which decodes through
455            // `legacy_v3::GenesisCoreStateV3` first), so the field
456            // starts at its default rather than at whatever the
457            // widened bytes happened to contain.
458            3 => {
459                self.ions = IonState::new();
460                self.header.version = SCHEMA_VERSION;
461                self.header.state_size = Self::SIZE as u32;
462                // Deliberately not ticking the ions here: migration
463                // seeds the resting state, and the next real tick evolves
464                // it. Running one now would invent a tick of history
465                // for a body that was never stepped.
466                self.sync_neurochemistry_to_state();
467                self.checksum = self.compute_checksum();
468                Ok(())
469            }
470            // v4 → v5: the sleep network was inserted ahead of the checksum.
471            // The caller widened the v4 layout (see
472            // `GenesisCoreStateV4::into_current`), which seeds the network at
473            // its source initial conditions. Here we restamp the version and
474            // size and recompute the checksum over the widened state.
475            4 => {
476                self.header.version = SCHEMA_VERSION;
477                self.header.state_size = Self::SIZE as u32;
478                self.checksum = self.compute_checksum();
479                Ok(())
480            }
481            // Unknown version: cannot migrate
482            v => Err(CoreStateError::VersionMismatch {
483                expected: SCHEMA_VERSION,
484                found: v,
485            }),
486        }
487    }

489    /// Migrate a state written under a *different struct size* but the
490    /// same schema version.
491    ///
492    /// [`Self::migrate_state`] dispatches on `header.version`, so it
493    /// cannot help a file whose version label is already correct but
494    /// whose `header.state_size` predates a same-version layout growth.
495    /// This preserves the path the schema-v3 reserve was designed for:
496    /// adding a field at the end of [`InferenceSignals`] grew only the
497    /// signals tail, so no earlier field moved and the version stayed
498    /// unchanged.
499    ///
500    /// The one historical layout change handled here is the 3288 →
501    /// 3296 growth from `InferenceSignals::policy_authority`. Because
502    /// every [`InferenceSignals`] field kept its offset and only one was
503    /// appended at the end, the migration is: zero the new tail, record
504    /// the current size, and recompute the checksum. Nothing before
505    /// `inference_signals` is touched, so the header, neurochemicals,
506    /// zones, memory pointers, manifest, sleep network, and ions all
507    /// survive intact in a same-version snapshot.
508    ///
509    /// Zeroing is the correct value rather than merely a safe one:
510    /// `policy_authority` is the authority cognition grants the
511    /// inference engine to act on its own policy choice, and it must not
512    /// come up non-zero from a file that predates the field. The signals
513    /// block is derived state excluded from the CRC and recomputed each
514    /// tick, so the new field is zero again on the first tick either
515    /// way — this just means the file is not carrying a grant nobody
516    /// made.
517    ///
518    /// The caller must hold the flock and publish the write; see the
519    /// call site in `crate::store::mmap_state::open`.
520    pub fn migrate_layout(&mut self, from_size: u32) -> Result<(), CoreStateError> {
521        if from_size == Self::SIZE as u32 {
522            // Already the current layout — nothing to do.
523            return self.verify();
524        }
525        if from_size != LEGACY_SIZE {
526            return Err(CoreStateError::SizeMismatch {
527                expected: Self::SIZE as u32,
528                found: from_size,
529            });
530        }
531
532        // Appended at the tail of the signals block, so every existing
533        // field keeps its offset and value. The trailing bytes past the
534        // new field are alignment padding that the CRC does not cover;
535        // `write_end_tail` zeroes them in the mapping so the file stays
536        // byte-deterministic rather than carrying whatever the previous
537        // binary left in the slack space of the 4 KB page.
538        self.inference_signals.policy_authority = 0.0;
539
540        self.header.state_size = Self::SIZE as u32;
541        self.checksum = self.compute_checksum();
542        Ok(())
543    }

545    /// Zero the padding, if any, between the end of
546    /// `inference_signals` and [`Self::SIZE`].
547    ///
548    /// The CRC covers offsets 0..40 and 48..`checksum`, so such padding
549    /// is outside every integrity check — but it is inside `SIZE`, and
550    /// `open()` copies the whole struct out of the mapping with
551    /// `read_volatile`. Leaving it stale would make a migrated file
552    /// differ byte-for-byte between machines for no reason. Under the
553    /// current layout the signals block ends exactly at `SIZE`, so
554    /// this is a no-op retained for same-version tail growth.
555    ///
556    /// # Panics
557    ///
558    /// Debug builds only: if the signals block no longer ends at or
559    /// before [`Self::SIZE`], the tail and the struct have drifted
560    /// apart and the range computed below would be meaningless.
561    pub fn write_end_tail(&mut self) {
562        let base = self as *mut Self as *mut u8;
563        let signals_end = core::mem::offset_of!(Self, inference_signals) + RESERVED_BYTES;
564        debug_assert!(signals_end <= Self::SIZE);
565        // SAFETY: `base` is derived from a unique `&mut Self`, so this
566        // is the only live pointer to the object and no other reference
567        // can alias it. The range is `signals_end..SIZE`, pinned inside
568        // the object by the debug_assert above; the caller obtained the
569        // mapping at ≥ `SIZE` bytes. The bytes written are alignment
570        // padding, which belongs to no field, so no field's value is
571        // invalidated.
572        unsafe {
573            core::ptr::write_bytes(base.add(signals_end), 0, Self::SIZE - signals_end);
574        }
575    }
576
577    // ─── Checksum ────────────────────────────────────────────────
578
579    /// Compute the CRC32 checksum over the struct, excluding the
580    /// `checksum` field itself and `header.reserved`.
581    ///
582    /// The checksum covers two regions:
583    /// 1. offset 0..40 (magic through heartbeat)
584    /// 2. offset 48..`checksum` (instance_id through the field before
585    ///    the checksum)
586    ///
587    /// `header.reserved` (offset 40..48) is excluded — it was the
588    /// sequence-lock counter, which changed on every write and made
589    /// the checksum unstable. The lock is gone; the exclusion is kept
590    /// so the checksum stays byte-compatible with existing files.
591    /// `checksum` and `inference_signals` at the end are excluded.
592    pub fn compute_checksum(&self) -> u32 {
593        let ptr = self as *const Self as *const u8;
594        // Anchor to the field's actual offset rather than deriving it
595        // from `SIZE - RESERVED_BYTES - 4`. That derivation assumed the
596        // struct ends exactly at the reserve with no padding, so
597        // growing the reserve by 4 moved the derived offset to 3228
598        // while the checksum field stayed at 3224 — and region 2 then
599        // covered the checksum itself, which can never verify. Reading
600        // the offset from the layout removes that coupling entirely.
601        let checksum_offset = core::mem::offset_of!(Self, checksum);
602
603        let (region1, region2) = unsafe {
604            // SAFETY: `ptr` is `self as *const Self as *const u8`, pointing to
605            // a valid `GenesisCoreState` (repr(C)). The two
606            // regions are within-bounds non-overlapping sub-slices:
607            //   r1: offset 0..40  (40 bytes, before reserved)
608            //   r2: offset 48..checksum_offset (ends at the checksum,
609            //       which is 4 bytes before inference_signals)
610            // Both lengths are ≥ 0 and their end offsets are ≤ SIZE.
611            // Region 1: offset 0..40 (magic through heartbeat, before reserved)
612            let r1 = core::slice::from_raw_parts(ptr, 40);
613            // Region 2: offset 48..checksum_offset (instance_id through
614            // the fields before the checksum)
615            let r2 = core::slice::from_raw_parts(ptr.add(48), checksum_offset - 48);
616            (r1, r2)
617        };
618
619        let mut crc = 0xFFFFFFFFu32;
620        for &byte in region1.iter().chain(region2.iter()) {
621            // Table-driven CRC32 — 8x faster than bit-by-bit
622            let idx = ((crc ^ byte as u32) & 0xFF) as usize;
623            crc = (crc >> 8) ^ CRC32_TABLE[idx];
624        }
625        crc ^ 0xFFFFFFFFu32
626    }
627
628    // ─── Verification ────────────────────────────────────────────
629
630    /// Verify the magic bytes and schema version.
631    pub fn verify(&self) -> Result<(), CoreStateError> {
632        if !self.header.verify_magic() {
633            return Err(CoreStateError::BadMagic);
634        }
635        if self.header.version != SCHEMA_VERSION {
636            return Err(CoreStateError::VersionMismatch {
637                expected: SCHEMA_VERSION,
638                found: self.header.version,
639            });
640        }
641        if self.header.state_size != Self::SIZE as u32 {
642            return Err(CoreStateError::SizeMismatch {
643                expected: Self::SIZE as u32,
644                found: self.header.state_size,
645            });
646        }
647        Ok(())
648    }
649
650    /// Verify the checksum matches.
651    pub fn verify_checksum(&self) -> Result<(), CoreStateError> {
652        let computed = self.compute_checksum();
653        if computed != self.checksum {
654            return Err(CoreStateError::ChecksumMismatch {
655                expected: computed,
656                found: self.checksum,
657            });
658        }
659        Ok(())
660    }
661
662    // ─── Write bookkeeping ───────────────────────────────────────
663
664    /// Begin a write transaction — stamps `last_updated` and bumps
665    /// `heartbeat`. There is no sequence lock; the caller's own
666    /// synchronization (MmapState's mutex + flock, or single-threaded
667    /// test code) is responsible for excluding concurrent writers.
668    ///
669    /// # Safety
670    /// The caller must ensure no other writer is active simultaneously.
671    pub unsafe fn write_begin(&mut self, now_ms: u64) {
672        self.header.last_updated = now_ms;
673        self.header.heartbeat = self.header.heartbeat.wrapping_add(1);
674    }
675
676    /// End a write transaction — recomputes the checksum over the
677    /// final bytes.
678    pub fn write_end(&mut self) {
679        self.checksum = self.compute_checksum();
680    }
681
682    /// Replace every non-finite float in persisted state with a
683    /// documented default. Returns `true` if anything was changed.
684    ///
685    /// The per-tick circuit breaker in
686    /// `NeurochemicalVector::sanitize_and_validate` already covers each
687    /// chemical's fields, the coupling matrix, the effective levels and
688    /// the vector-level scalars. What it does not reach is the memory
689    /// gating weights and the manifest aggregates — and a tick-level
690    /// breaker only runs once the loop is going, so between `open` and
691    /// the first tick a CRC-valid but non-finite state file can still be
692    /// published to lock-free readers over IPC. `open` is the last place
693    /// that can catch it.
694    ///
695    /// Note the CRC cannot detect this: a state file that legitimately
696    /// contains NaN is byte-exact, so both `verify` and
697    /// `verify_checksum` pass it.
698    pub fn scrub_non_finite(&mut self) -> bool {
699        let mut scrubbed = false;
700        let mut fix = |v: &mut f32, default: f32| {
701            if !v.is_finite() {
702                *v = default;
703                scrubbed = true;
704            }
705        };
706
707        // Neurochemical vector scalars not covered above.
708        // `bdnf_recovery_rate` is a reserved schema field (the
709        // dynamics read it from `NeuroTickParams`), so 0.0 is correct.
710        fix(&mut self.neurochemicals.bdnf_recovery_rate, 0.0);
711
712        // Memory gating weights. 0.5 = neutral.
713        fix(&mut self.memory.encoding_weight, 0.5);
714        fix(&mut self.memory.consolidation_weight, 0.5);
715        fix(&mut self.memory.retrieval_weight, 0.5);
716        fix(&mut self.memory.plasticity_gate, 0.5);
717
718        // Manifest aggregates and per-module telemetry.
719        fix(&mut self.manifest.total_cpu_load, 0.0);
720        fix(&mut self.manifest.total_mem_mb, 0.0);
721        for m in &mut self.manifest.modules {
722            fix(&mut m.cpu_share, 0.0);
723            fix(&mut m.mem_usage_mb, 0.0);
724        }
725
726        scrubbed
727    }
728
729    /// Take a volatile snapshot of the state.
730    ///
731    /// There is no sequence lock: this is a single `read_volatile`
732    /// copy of the whole struct. If a writer is mid-publish the copy
733    /// may be torn — callers that care can verify the CRC on the
734    /// snapshot. The `Option` return is kept for call-site
735    /// compatibility with the former sequence-lock protocol; it now
736    /// always yields `Some`.
737    ///
738    /// **When to use this vs [`MmapState::read_consistent`](crate::MmapState::read_consistent):**
739    ///
740    /// - This method is for **stack-allocated** `GenesisCoreState`
741    ///   values (e.g. in unit tests) where there is no aliasing
742    ///   concern — the caller owns the value exclusively.
743    /// - For **mmap'd** state (the production daemon, IPC handler,
744    ///   tick loop), use [`MmapState::read_consistent`](crate::MmapState::read_consistent) instead.
745    ///   That method operates on the raw mmap pointer and never
746    ///   creates a `&GenesisCoreState` reference to the mmap'd
747    ///   memory, eliminating the aliasing UB that would occur if a
748    ///   `&` from `MmapState::state()` coexisted with a `&mut` from
749    ///   `MmapState::modify()` on another thread.
750    ///
751    /// # Safety
752    /// The caller must ensure that `self` is not being deallocated or
753    /// remapped while this function runs, and that no `&mut` reference
754    /// to the same memory coexists with the `&self` used to call this
755    /// method. For mmap'd state, use [`MmapState::read_consistent`](crate::MmapState::read_consistent)
756    /// instead.
757    pub unsafe fn read_consistent(&self) -> Option<GenesisCoreState> {
758        // SAFETY: `self` is a valid `GenesisCoreState` (caller guarantees it
759        // is not being deallocated or remapped — see the function-level
760        // `# Safety` doc). `read_volatile` copies `size_of::<Self>()` bytes
761        // without creating a reference, avoiding aliasing issues with a
762        // concurrent writer.
763        Some(unsafe { core::ptr::read_volatile(self) })
764    }
765}
766
767/// Errors that can occur when verifying the core state.
768#[derive(Debug, Clone, PartialEq, Eq)]
769pub enum CoreStateError {
770    /// The state's magic bytes did not match `b"GNSX"`.
771    BadMagic,
772    /// The state's schema version did not match the expected one.
773    VersionMismatch {
774        /// The version the code expected.
775        expected: u32,
776        /// The version found in the state.
777        found: u32,
778    },
779    /// The state's byte size did not match the expected size.
780    SizeMismatch {
781        /// The size the code expected.
782        expected: u32,
783        /// The size found in the state.
784        found: u32,
785    },
786    /// The state's checksum did not match the recomputed value.
787    ChecksumMismatch {
788        /// The checksum the code expected.
789        expected: u32,
790        /// The checksum found in the state.
791        found: u32,
792    },
793}
794
795impl core::fmt::Display for CoreStateError {
796    fn fmt(&self, f: &mut core::fmt::Formatter<'_>) -> core::fmt::Result {
797        match self {
798            Self::BadMagic => write!(f, "bad magic bytes (expected b\"GNSX\")"),
799            Self::VersionMismatch { expected, found } => {
800                write!(
801                    f,
802                    "schema version mismatch (expected {expected}, found {found})"
803                )
804            }
805            Self::SizeMismatch { expected, found } => {
806                write!(
807                    f,
808                    "state size mismatch (expected {expected}, found {found})"
809                )
810            }
811            Self::ChecksumMismatch { expected, found } => {
812                write!(
813                    f,
814                    "checksum mismatch (expected {expected:#010x}, found {found:#010x})"
815                )
816            }
817        }
818    }
819}

825const _: () = {
826    use core::mem::offset_of;
827    // InferenceSignals grew by 4 bytes (policy_authority) and the
828    // reserved region is defined as exactly its size, so the reserve
829    // grew with it. Nothing before the signals block moved: the
830    // reserve exists so a new signal field cannot shift the rest of
831    // the wire layout. Schema v4 then inserted `ions` ahead of the
832    // checksum, which moved the signals block to 3352. Schema v5 inserted
833    // the 64-byte sleep network ahead of the checksum, so the signals block
834    // now sits at 3416 and ends at 3416 + 64 = 3480, the struct's size.
835    assert!(core::mem::size_of::<GenesisCoreState>() <= 4096);
836    assert!(offset_of!(GenesisCoreState, header) == 0);
837    assert!(offset_of!(GenesisCoreState, neurochemicals) == 56);
838    assert!(offset_of!(GenesisCoreState, zones) == 2472);
839    assert!(offset_of!(GenesisCoreState, memory) == 2568);
840    assert!(offset_of!(GenesisCoreState, manifest) == 2688);
841    assert!(offset_of!(GenesisCoreState, sleep_network) == 3224);
842    assert!(offset_of!(GenesisCoreState, ions) == 3288);
843    assert!(offset_of!(GenesisCoreState, checksum) == 3412);
844    assert!(core::mem::size_of::<GenesisCoreState>() == 3480);
845    assert!(offset_of!(GenesisCoreState, inference_signals) == 3416);
846    // `compute_checksum` locates the checksum field with
847    // `offset_of!(Self, checksum)` and region 2 as `48..<that offset>`
848    // — it no longer derives either from `RESERVED_BYTES`. What
849    // `RESERVED_BYTES` must still satisfy is that the reserve is
850    // exactly the signals block: too large and the signals block would
851    // leave a hole (harmless but pointless), too small and the struct
852    // would carry unowned bytes the signals do not account for.
853    // `write_end_tail` zeroes whatever gap that leaves between the end
854    // of the signals and `SIZE`.
855    // ...and the checksum must sit exactly 4 bytes below the signals,
856    // which is what makes region 2 end immediately before the checksum.
857    assert!(
858        offset_of!(GenesisCoreState, inference_signals)
859            == offset_of!(GenesisCoreState, checksum) + 4
860    );
861    assert!(
862        core::mem::size_of::<InferenceSignals>() == RESERVED_BYTES,
863        "InferenceSignals must exactly fill the reserved region"
864    );
865    // The signals block must end inside the struct, or `write_end_tail`
866    // would compute a range outside it. Under schema v5 it ends exactly
867    // at `SIZE`, leaving no padding tail.
868    assert!(
869        offset_of!(GenesisCoreState, inference_signals) + RESERVED_BYTES <= GenesisCoreState::SIZE
870    );
871};
