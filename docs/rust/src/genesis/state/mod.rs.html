1//! Genesis core state — the memory-mapped hub of the brain.
2//!
3//! This module defines the single fixed-layout structure that holds
4//! Genesis's entire runtime state. See [`core_state::GenesisCoreState`].
5//!
6//! ## Schema v5 architecture
7//!
8//! ```text
9//! ┌──────────────────────────────────────────────────────────────┐
10//! │                  GenesisCoreState (3480 bytes)                │
11//! │  memory-mapped, lock-free readable, CRC32 checksummed         │
12//! │                                                               │
13//! │  ┌──────────────┐  ┌────────────────────────────────────────┐ │
14//! │  │   Header      │  │  NeurochemicalVector (2416 bytes)      │ │
15//! │  │  magic, ver,  │  │  18 chemicals × 56 bytes = 1008        │ │
16//! │  │  reserved, hb  │  │  18×18 coupling matrix = 1296          │ │
17//! │  └──────────────┘  │  effective levels, arousal, valence     │ │
18//! │                    │  plasticity gate, emergent phase        │ │
19//! │                    │  ACTH (HPA cascade), tonic/phasic       │ │
20//! │                    │  circadian oscillator (SCN model)       │ │
21//! │  ┌──────────────┐  └────────────────────────────────────────┘ │
22//! │  │ ActiveZones   │  ┌────────────────────────────────────────┐│
23//! │  │  task zone    │  │  MemoryPointers (120 bytes)             ││
24//! │  │  + emergent   │  │  STM/LTM/proc/sem pointers              ││
25//! │  │    phase      │  │  + emotional gating weights             ││
26//! │  │  + subconsc.  │  │    encoding, consolidation,             ││
27//! │  │    flags      │  │    retrieval, plasticity                ││
28//! │  └──────────────┘  └────────────────────────────────────────┘ │
29//! │  ┌──────────────┐  ┌────────────────────────────────────────┐ │
30//! │  │ Manifest      │  │  Sleep network + ions + checksum       │ │
31//! │  │  16 modules   │  │  + 64 bytes active inference           │ │
32//! │  └──────────────┘  └────────────────────────────────────────┘ │
33//! └──────────────────────────────────────────────────────────────┘
34//! ```
35//!
36//! ## What's novel in v3.2
37//!
38//! - **18 coupled neurochemicals** (up from 17): added melatonin
39//!   (circadian hormone, sleep promotion via SCN oscillator).
40//! - **Circadian oscillator**: SCN-model phase oscillator drives
41//!   melatonin secretion and diurnal modulation of cortisol, dopamine,
42//!   serotonin, and histamine baselines. Cortisol awakening response
43//!   (CAR), daytime dopamine/histamine elevation, and night-time
44//!   serotonin-to-melatonin conversion are all emergent.
45//! - **NREM/REM sleep phases**: the single Sleeping phase is split
46//!   into NREM (slow-wave, glymphatic clearance) and REM (dreaming,
47//!   emotional processing), driven by the cholinergic/aminergic
48//!   flip-flop (Hobson & McCarley reciprocal interaction model).
49//! - **HPA axis redesign**: cortisol and CRH are stress hormones with
50//!   a zero resting baseline (leaky integrators), produced only by the
51//!   maturation-gated CRH → ACTH → cortisol cascade.
