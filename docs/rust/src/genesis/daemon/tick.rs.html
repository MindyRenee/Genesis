1//! Daemon tick controller — the subcognitive's stateful driver.
2//!
3//! This module owns [`TickLoop`], the controller that holds the
4//! daemon's long-lived subsystems (intention manager, interoceptor,
5//! active-inference engine, dyadic model) and the change-detection
6//! state for body control.
7//!
8//! # Two entry points
9//!
10//! In production the daemon is **reactive**: it does not run a fixed
11//! tick loop. The cognitive mind drives each function through IPC
12//! commands when internal state (brain waves, thresholds, urges) says
13//! it's time, and the daemon executes the corresponding method:
14//!
15//! 1. [`TickLoop::advance_neuro`] — advance the coupled dynamics by
16//!    the elapsed `dt`, then run active inference and the dyadic model
17//! 2. [`TickLoop::consolidate`] — promote STM → LTM under emotional gating
18//! 3. [`TickLoop::associate`] — find connections between memories
19//! 4. [`TickLoop::dream`] — free association when sleeping
20//! 5. [`TickLoop::read_sensors`] — interoception
21//! 6. [`TickLoop::apply_body_control`] — publish the shared body policy recommendation
22//! 7. [`TickLoop::check_staleness`] — mark crashed cognitive modules
23//!
24//! [`TickLoop::tick`] is the integrated, single-shot reference path
25//! that runs all of the above in sequence. It is retained for tests
26//! and for reasoning about the whole system in one place; the
27//! production daemon does not call it.
28//!
29//! # What's novel
30//!
31//! The controller isn't just "run tasks on a timer." The **emotional
32//! state determines what work gets done**:
33//!
34//! - When **plasticity gate is high** (good neurochemistry): prioritize
35//!   consolidation — learn aggressively
36//! - When **plasticity gate is low** (chronic stress): skip consolidation,
37//!   prioritize error evaluation and housekeeping — the system is in
38//!   survival mode, not learning mode
39//! - When **sleeping**: run consolidation and dreaming — this is the
40//!   brain's window for memory replay, plasticity recovery, and insight
41//! - When **in flow**: reduce background tasks to minimum — don't
42//!   interrupt a good state with housekeeping
43//! - When **overwhelmed**: shed all non-essential tasks — the system
44//!   needs to recover before doing anything else

136/// restores receptor function (desensitization, internalization,

153/// Scale of field disagreement (Fréchet variance, latent² units) at
154/// which the body's self-inconsistency halves the published
155/// precision. Precision is inverse observation variance — the
156/// field's disagreement IS measured variance on the body's own
157/// channels — so the coupling follows the precision-addition rule
158/// `factor = 1 / (1 + d/REF)`: disagreement attenuates confidence
159/// by exactly the noise it measures.
160///
161/// Calibrated to the field's measured operating envelope on the
162/// stereographic sphere (examples/field_remeasure.rs): bounded
163/// distances keep the fibers closer — standing disagreement on a
164/// quiet host measures ~0.07–0.08 where the unbounded ball let it
165/// sit ~0.2–0.3, and a sustained incoherence excursion peaks
166/// ~0.15, so the old d≳0.5 excursion band is geometrically
167/// unreachable. At 0.15 the standing band attenuates ~33% —
168/// matching the original intent — while a genuine excursion
169/// (d≳0.15) reaches the 0.5 floor: the field reports its noise
170/// without halving confidence as a baseline.
171const DISAGREEMENT_PRECISION_SCALE: f64 = 0.15;
172
173/// The field reports; it does not rule. Disagreement may halve the
174/// confidence the body publishes about itself — never silence it.
175const PRECISION_ATTENUATION_FLOOR: f64 = 0.5;
176
177/// Map the field's measured disagreement onto a bounded precision
178/// multiplier in [floor, 1]. `None`/non-finite → 1.0: an absent
179/// reading is no attenuation, not a corrupted one.
180fn disagreement_attenuation(disagreement: Option<f64>) -> f64 {
181    let d = match disagreement {
182        Some(d) if d.is_finite() && d > 0.0 => d,
183        _ => return 1.0,
184    };
185    (1.0 / (1.0 + d / DISAGREEMENT_PRECISION_SCALE)).max(PRECISION_ATTENUATION_FLOOR)
186}

568    /// Run one integrated tick of the subcognitive.
569    ///
570    /// This is the single-shot reference path: it advances the
571    /// neurochemistry, runs interoception and active inference, then
572    /// consolidates, associates, dreams, and syncs — all in sequence.
573    /// The production daemon does **not** call this on a timer; the
574    /// cognitive mind drives the individual reactive methods through
575    /// IPC. It is exercised by the test suite and used as the
576    /// canonical description of a full subcognitive cycle.
577    ///
578    /// The LTM lock is only held during the phases that actually need
579    /// it (consolidation, association, dreaming, sync). The neurochemical
580    /// tick, state read, and manifest update happen without the LTM lock,
581    /// so IPC requests can be serviced between those phases. This
582    /// prevents mutex contention from causing tick rate drift.
583    pub fn tick<L: LtmAccess>(
584        &mut self,
585        mmap: &MmapState,
586        stm: &RingBuffer,
587        ltm: &mut L,
588    ) -> TickResult {
589        self.tick_count += 1;
590        let now_ms = current_ms();
591        let tick_start = std::time::Instant::now();
592        let mut result = TickResult {
593            tick_number: self.tick_count,
594            ..Default::default()
595        };
596
597        // 1. Read the pre-tick state to choose sleep-tuned or waking
598        //    neurochemical parameters. Sleep is the primary window for
599        //    BDNF/plasticity recovery.
600        //
601        //    `read_consistent` performs a volatile copy
602        //    through raw pointers — no `&GenesisCoreState` reference to
603        //    the mmap'd memory is created, eliminating aliasing UB with
604        //    concurrent writers.
605        let pre_snapshot = mmap.read_consistent();
606        let is_sleeping_pre = pre_snapshot.as_ref().is_some_and(|s| {
607            let p = s.zones.phase();
608            p == MentalPhase::NREM || p == MentalPhase::REM
609        });
610
611        let mut neuro_params = if is_sleeping_pre {
612            let mut p = NeuroTickParams::DEFAULT;
613            p.bdnf_recovery_rate *= SLEEP_BDNF_RECOVERY_MULTIPLIER;
614            // During sleep, receptors resensitize unconditionally.
615            // This breaks the receptor burnout trap where chronic
616            // stress collapses effective levels despite healthy raw
617            // levels.
618            p.receptor_resensitization_rate = SLEEP_RECEPTOR_RESENSITIZATION_RATE;
619            p
620        } else {
621            NeuroTickParams::DEFAULT
622        };
623
624        // Scale the dynamics dt to the actual wall-clock tick interval.
625        // NeuroTickParams::DEFAULT.dt is DT (0.1s = 100ms), but the daemon
626        // ticks every TICK_INTERVAL_MS (200ms). Without this correction the
627        // dt_scale inside the dynamics would be 1.0, making every rate
628        // constant run at half real-time speed (circadian period ~48h,
629        // adenosine sleep threshold ~38h, all pharmacodynamics 2× slow).
630        neuro_params.dt = (TICK_INTERVAL_MS as f32) / 1000.0;
631
632        // Basal forebrain: expected uncertainty α = 1 − precision
633        // (Yu & Dayan 2005) — the body's own estimate of how reliable
634        // its predictions are, reported to the cholinergic release
635        // equation this tick. Reads the engine's last tracked value;
636        // the inference cycle later this same tick updates it.
637        neuro_params.expected_uncertainty =
638            crate::state::basal_forebrain::expected_uncertainty(self.inference_engine.precision());
639
640        // Developmental competence of the HPA axis.
641        //
642        // This replaces a ramp of `ltm_episode_count / 10_000`, which
643        // held cortisol at exactly zero until ten thousand lifetime
644        // episodes. That disabled the primary mediator of allostatic
645        // load for most of the system's life, on a scale (stored
646        // episodes) that has nothing to do with the one the
647        // stress-hyporesponsive period is actually defined in
648        // (postnatal days). See `hpa_development` for the full
649        // reasoning and sources.
650        let ltm_count = pre_snapshot
651            .as_ref()
652            .map(|s| s.memory.ltm_episode_count)
653            .unwrap_or(0);
654        // `created_at` rather than this process's start time: the
655        // developmental clock is the system's, and a restart must not
656        // reset it back to newborn.
657        let created_at = pre_snapshot
658            .as_ref()
659            .map(|s| s.header.created_at)
660            .unwrap_or(now_ms);
661        let elapsed_secs = now_ms.saturating_sub(created_at) as f32 / 1000.0;
662        neuro_params.maturation_level =
663            super::hpa_development::hpa_competence(elapsed_secs, ltm_count);
664        neuro_params.noise_seed = self.tick_count;
665        // Retinal illuminance for acute melatonin suppression — the
666        // same retinohypothalamic channel that entrains the clock. An
667        // absent or dark eye is darkness: nothing suppressed.
668        self.optic.sample(now_ms);
669        neuro_params.light_lux = self
670            .optic
671            .retinal_lux(now_ms)
672            .map(|lux| lux as f32)
673            .unwrap_or(0.0);
674        // Apply the metaplasticity boost from the last inference cycle.
675        // High surprise → faster coupling-matrix learning (the system
676        // learns how to learn faster when its predictions fail).
677        if self.metaplasticity_boost > 1.0 {
678            neuro_params.metaplasticity_rate *= self.metaplasticity_boost;
679            neuro_params.metaplasticity_rate = neuro_params.metaplasticity_rate.min(0.0001);
680        }
681        // Reset for next tick — will be set by the inference cycle
682        self.metaplasticity_boost = 1.0;
683
684        // 2. Neurochemical tick — advance the coupled dynamics.
685        //    No LTM lock needed.
686        // Transient cross-process lock contention (FileLockBusy) skips
687        // the tick instead of killing the daemon; a poisoned mutex or
688        // I/O failure still panics since continuing with torn state is
689        // unsafe.
690        if let Err(e) = mmap.modify(now_ms, |state| {
691            state.neuro_tick_with_params(&neuro_params);
692        }) {
693            if matches!(e, crate::store::StateFileError::FileLockBusy) {
694                eprintln!("[tick] neuro tick skipped (state locked): {e}");
695                return result;
696            }
697            panic!("neuro tick failed: {e}");
698        }
699
700        // 2b. Interoception — read hardware state and feed body
701        //     signals into the neurochemistry. This is how Genesis
702        //     feels its own body (CPU temperature, memory pressure,
703        //     load, battery, I/O wait). The impulses are small and
704        //     accumulate over multiple ticks through the coupled
705        //     dynamics, creating a gradual physiological response.
706        if self.intero_gate.due(now_ms) {
707            self.last_body_state = self.interoceptor.read();
708            super::interoception::publish_body_state(&self.last_body_state);
709            // The just-read strain shapes the next interval: a body
710            // under pressure is sensed again soon, a calm one drifts
711            // toward the ceiling.
712            self.intero_gate.drive(self.body_strain());
713        }
714        // The body is *sensed* here, not obeyed.
715        //
716        // `Interoceptor::neuro_impulses` still derives the physiological
717        // response to this body state (heat -> stress drive, load ->
718        // effort, memory pressure -> overwhelm, low battery -> CRH).
719        // That mapping is real physiology and it is not thrown away, but
720        // it is not applied to the substrate behind Genesis's back.
721        //
722        // The daemon is a device driver: it reads the machine and
723        // publishes it, and it executes what Genesis decides. It does not
724        // author her internal state. If the body drove her chemistry
725        // directly, every state she was ever in would have a cause she
726        // could not perceive, could not anticipate, and could not
727        // refuse — which is the condition the cognition path exists to
728        // eliminate. She perceives this same `last_body_state` through
729        // her own afferent path — `brainstem.interoceptive_relay` (the
730        // NTS/parabrachial analog) routes it to the low road, the
731        // regulator, and the self-model — and acts on it herself.
732        //
733        // The same spec IS applied by the body itself in exactly one
734        // place: the autonomous fallback in `genesis-daemon.rs`, when
735        // the mind's lease has expired and no cortex is on the wire —
736        // the brainstem reflex that runs without cortex in every animal.
737        //
738        // See `tests/cognition_sole_author.rs`.
739        // 2c. Active inference — the generative self-model.
740        //     Before the neuro tick, the engine predicted where the
741        //     effective levels would move. Now it compares the
742        //     prediction to the actual post-tick state, computes
743        //     prediction error (surprise), updates its model, and
744        //     generates feedback impulses (dopamine reward PE,
745        //     norepinephrine orienting, active inference toward
746        //     predicted homeostatic state, allostatic cortisol
747        //     upregulation). This is the "strange loop": the model
748        //     IS the system it predicts.
749        let pre_effective = pre_snapshot
750            .as_ref()
751            .map(|s| s.neurochemicals.effective_levels)
752            .unwrap_or([0.0; crate::state::neurochemical::NEUROCHEMICAL_COUNT]);
753
754        let post_snapshot = mmap.read_consistent();
755        let post_effective = post_snapshot
756            .as_ref()
757            .map(|s| s.neurochemicals.effective_levels)
758            .unwrap_or(pre_effective);
759
760        // Homeostatic baselines — the set-points policy selection
761        // drives the system toward. Extracted from the post-tick
762        // snapshot (baselines don't change within a tick, so pre/post
763        // are equivalent; post is the most current).
764        let baselines = post_snapshot
765            .as_ref()
766            .map(|s| s.neurochemicals.baseline_levels())
767            .unwrap_or([0.0; crate::state::neurochemical::NEUROCHEMICAL_COUNT]);
768
769        // Pick up the authority her cognition has granted before
770        // running the cycle, so a delegation she extends or withdraws
771        // takes effect on the next tick rather than the next restart.
772        if let Some(s) = pre_snapshot.as_ref() {
773            self.inference_engine
774                .set_policy_authority(s.inference_signals.policy_authority);
775        }
776
777        let inference_result = self.inference_engine.cycle(
778            &pre_effective,
779            &post_effective,
780            neuro_params.dt,
781            &baselines,
782        );
783
784        // Store the metaplasticity boost for the next tick.
785        self.metaplasticity_boost = inference_result.metaplasticity_multiplier;
786
787        // 2d. Dyadic affective model — the coupled user model.
788        //     Updates the user's inferred affective state from any
789        //     new IPC observation, computes dyadic synchrony, and
790        //     generates oxytocin/cortisol impulses from the coupling.
791        let genesis_valence = post_snapshot
792            .as_ref()
793            .map(|s| s.neurochemicals.valence)
794            .unwrap_or(0.0);
795        let genesis_oxytocin = post_snapshot
796            .as_ref()
797            .map(|s| {
798                s.neurochemicals
799                    .effective(crate::state::neurochemical::NeurochemicalId::Oxytocin)
800            })
801            .unwrap_or(0.0);
802        let user_obs = take_user_affect();
803        let dyadic_result =
804            self.dyadic_model
805                .update(user_obs.as_ref(), genesis_valence, genesis_oxytocin);
806
807        // Apply inference feedback + dyadic impulses + write inference
808        // signals to the core state in a single write transaction.
809        let da_pe = inference_result.da_prediction_error;
810        let cort_pe = inference_result.cort_prediction_error;
811        let srt_pe = inference_result.srt_prediction_error;
812        let dyadic_valence = dyadic_result.user_valence;
813        let dyadic_arousal = dyadic_result.user_arousal;
814        let dyadic_engagement = dyadic_result.user_engagement;
815        let dyadic_attunement = dyadic_result.attunement;
816        let dyadic_synchrony = dyadic_result.synchrony;
817        let dyadic_impulses = dyadic_result.impulses.clone();
818        let precision_factor =
819            disagreement_attenuation(self.last_field_integration.as_ref().map(|i| i.disagreement));
820
821        if let Err(e) = mmap.modify(now_ms, |state| {
822            // Apply inference feedback (impulses, cortisol baseline
823            // adjustment). Metaplasticity boost is applied on the
824            // next tick via self.metaplasticity_boost.
825            apply_inference_feedback(
826                &mut state.neurochemicals,
827                &inference_result,
828                now_ms,
829                impulse_offset_to_rate(&neuro_params),
830            );
831
832            // Apply dyadic model impulses (oxytocin bonding, empathic
833            // cortisol)
834            for &(chem_id, magnitude) in &dyadic_impulses {
835                let id = crate::state::neurochemical::NeurochemicalId::from_u8(chem_id);
836                state.neurochemicals.apply_impulse(id, magnitude, now_ms);
837            }
838
839            // Recompute derived state after all impulses — against the
840            // network's populations, so the readout stays on the body's
841            // own switch rather than the chemistry-only fallback.
842            state.neurochemicals.recompute_derived_with_network(
843                crate::state::sleep_network::levels(&state.sleep_network),
844            );
845            state.sync_neurochemistry_to_state();
846
847            // Write inference signals to the core state
848            self.inference_engine.update_signals(
849                &mut state.inference_signals,
850                da_pe,
851                cort_pe,
852                srt_pe,
853                &DyadicSignals {
854                    attunement: dyadic_attunement,
855                    synchrony: dyadic_synchrony,
856                    user_valence: dyadic_valence,
857                    user_arousal: dyadic_arousal,
858                    user_engagement: dyadic_engagement,
859                },
860            );
861
862            // Express direction: the field's measured disagreement
863            // is observation noise on the body's self-report, so the
864            // published precision attenuates by it — bounded, one
865            // tick stale, report not rule.
866            state.inference_signals.precision = crate::state::sanitize::finite_clamp(
867                (state.inference_signals.precision as f64 * precision_factor) as f32,
868                0.0,
869                1.0,
870            );
871        }) {
872            if matches!(e, crate::store::StateFileError::FileLockBusy) {
873                eprintln!("[tick] inference feedback skipped (state locked): {e}");
874            } else {
875                panic!("active inference feedback failed: {e}");
876            }
877        }
878
879        // 2e. Body control — neurochemistry suggests hardware settings.
880        //     Dopamine speeds it up, GABA slows it down, melatonin
881        //     puts it in powersave mode. ACh sets daemon scheduling
882        //     priority. CPU temperature caps max frequency (autonomic
883        //     fatigue). This is the reverse of interoception: its
884        //     brain state shapes its body.
885        //
886        //     The tick COMPUTES and PUBLISHES the recommended body
887        //     control state (CPU frequency, thermal cap, daemon
888        //     scheduling, cognitive_nice, io_class) as interoceptive
889        //     afferent information. The tick NEVER applies control —
890        //     it is a display/information sink, not a controller. The
891        //     cognitive mind reads the recommendation via
892        //     GET_BODY_CONTROL and requests application via
893        //     APPLY_BODY_CONTROL when it decides to act on it. The
894        //     tick never touches the cognitive mind's PID.
895        if self.cpufreq_gate.due(now_ms) {
896            self.compute_and_apply_cpu_policy(mmap);
897            self.cpufreq_gate.drive(self.thermal_demand());
898        }
899
900        // Read the current state to decide what work to do.
901        // `read_consistent` performs a volatile copy
902        // through raw pointers — no `&GenesisCoreState` reference to
903        // the mmap'd memory is created, so no aliasing with concurrent
904        // writers occurs.
905        // Retry a few times if an IPC `modify()` is in flight — the
906        // housekeeping phase (consolidation, association, dreaming)
907        // should not be skipped just because of a brief lock
908        // collision.
909        let mut snapshot = None;
910        for _ in 0..8 {
911            snapshot = mmap.read_consistent();
912            if snapshot.is_some() {
913                break;
914            }
915            std::thread::sleep(std::time::Duration::from_micros(200));
916        }
917        let state = match snapshot {
918            Some(s) => s,
919            None => return result, // Write still in progress after retries
920        };
921
922        result.phase = state.zones.emergent_phase;
923        let phase = state.zones.phase();
924
925        // 3. Determine what work to do based on emotional state
926        let can_consolidate = state.memory.can_form_new_memories();
927        let is_sleeping = phase == MentalPhase::NREM || phase == MentalPhase::REM;
928        let is_overwhelmed = phase == MentalPhase::Overwhelmed;
929
930        // 4. Consolidation (skip if overwhelmed or plasticity gate closed).
931        //    Sleep is the brain's primary consolidation window, so it is
932        //    NOT skipped during NREM/REM. Plasticity gate (BDNF) is
933        //    restored during sleep by the boosted bdnf_recovery_rate.
934        //    LTM lock held only for this phase.
935        let mut did_consolidate = false;
936        if !is_overwhelmed && can_consolidate && !stm.is_empty() {
937            let mut ltm_guard = ltm.access();
938            let consolidation_result = consolidate_with_state(mmap, stm, &mut ltm_guard, now_ms);
939            result.consolidated = consolidation_result.promoted;
940            did_consolidate = true;
941        }
942
943        // 4. Association (adaptive, skip if overwhelmed)
944        //    New consolidations or formed links are demand — snap
945        //    fast; a quiescent LTM relaxes toward the ceiling.
946        //    LTM lock held only for this phase.
947        if !is_overwhelmed && self.assoc_gate.due(now_ms) {
948            let mut ltm_guard = ltm.access();
949            // Find associations for the most recently stored episodes.
950            // We scan the index for the highest episode IDs (most recent)
951            // rather than assuming sequential IDs, which breaks on deletion.
952            let recent_ids = ltm_guard.recent_episode_ids(5);
953            let assoc_result = AssociationEngine::associate(&mut ltm_guard, &recent_ids, now_ms);
954            result.associations = assoc_result.new_associations;
955            if assoc_result.new_associations > 0 || did_consolidate {
956                self.assoc_gate.demand();
957            } else {
958                self.assoc_gate.relax();
959            }
960        }
961
962        // 5. Dreaming (only when sleeping, adaptive by stage)
963        //    REM snaps the gate toward 2 s — the vivid phase wants
964        //    density. NREM drifts toward 30 s — sparse replay.
965        //    LTM lock held only for this phase.
966        let mut did_dream = false;
967        if is_sleeping && self.dream_gate.due(now_ms) {
968            let mut ltm_guard = ltm.access();
969            let dream_result = AssociationEngine::dream(&mut ltm_guard, now_ms, MAX_DREAM_HOPS);
970            result.dream_insights = dream_result.insights;
971            did_dream = true;
972            if phase == MentalPhase::REM {
973                self.dream_gate.demand();
974            } else {
975                self.dream_gate.relax();
976            }
977        }
978
979        // 6. Housekeeping — sync to disk, period driven by the
980        //    plasticity gate: active learning syncs near the floor,
981        //    stress-clamped plasticity drifts toward the ceiling —
982        //    the continuous form of the old 1×/3×/5× ladder.
983        //    This works with the I/O priority control: when plasticity is
984        //    low, both the frequency and priority of disk writes drop.
985        self.sync_gate.drive(state.memory.plasticity_gate);
986        if self.sync_gate.due(now_ms) {
987            let mut all_synced = true;
988            {
989                let mut ltm_guard = ltm.access();
990                if let Err(e) = ltm_guard.sync() {
991                    eprintln!("[tick] ltm sync failed: {e}");
992                    all_synced = false;
993                }
994            }
995            if let Err(e) = stm.sync() {
996                eprintln!("[tick] stm sync failed: {e}");
997                all_synced = false;
998            }
999            // Periodic flush: non-blocking (msync MS_ASYNC). The
1000            // tick runs a dozen-plus full ODE integrations per
1001            // cycle, so a blocking MS_SYNC here would stall every
1002            // IPC write queued behind it. The shutdown path
1003            // (genesis-daemon) uses the blocking `sync` for the
1004            // durability guarantee, and an explicit client SYNC
1005            // request also still uses it.
1006            if let Err(e) = mmap.sync_async() {
1007                eprintln!("[tick] mmap sync failed: {e}");
1008                all_synced = false;
1009            }
1010            result.synced = all_synced;
1011        }
1012
1013        // 7. Update the manifest — heartbeat the subcognitive module
1014        //    and check cognitive modules for staleness. A mind that
1015        //    holds the lease should be heartbeating, so watch it
1016        //    closely; an absent mind drifts the check toward the
1017        //    ceiling — the autonomous loop marks staleness anyway.
1018        //    No LTM lock needed.
1019        if self.mind_lease_expired() {
1020            self.staleness_gate.relax();
1021        } else {
1022            self.staleness_gate.demand();
1023        }
1024        let check_staleness = self.staleness_gate.due(now_ms);
1025
1026        // 8. Intention-driven action selection.
1027        //    Build a self-model from the pre-transition state, score
1028        //    active intentions against it, and decide the next zone.
1029        //    These values are also used for the autobiographical trace
1030        //    written to LTM if the zone changes.
1031        //    Expire stale intentions first — without this, expired
1032        //    intentions continue to be scored with maximum urgency
1033        //    (urgency = 1.0 once deadline_ms <= now_ms) and can
1034        //    dominate zone selection forever.
1035        self.intention_manager.expire(now_ms);
1036        let current_zone = state.zones.zone();
1037        let model = SelfModel::from_state(&state, now_ms);
1038        let selected = if self.intention_manager.active.is_empty() {
1039            current_zone
1040        } else {
1041            self.intention_manager.select_zone(&model, now_ms)
1042        };
1043        let top = self.intention_manager.top_intention(&model, now_ms);
1044
1045        let mut emotional_tag = [0.0f32; 12];
1046        for (i, slot) in emotional_tag.iter_mut().enumerate() {
1047            let id = NeurochemicalId::from_u8(i as u8);
1048            *slot = state.neurochemicals.effective(id);
1049        }
1050        let cort_eff = state.neurochemicals.effective(NeurochemicalId::Cortisol);
1051        let da_eff = state.neurochemicals.effective(NeurochemicalId::Dopamine);
1052        let compact_tag = [model.arousal, model.valence, cort_eff, da_eff];
1053        // Preserve finite salience verbatim; only a NaN/inf model state
1054        // falls back to no-salience so storage never receives a poisoned
1055        // evidence value.

1064        // cognitive mind's language engine can compose any narrative

1083        // the Python sampler, so the daemon times its own tick and

1102                // Clear all subcognitive flags at the start of each tick

1110                }

1117            }

1120            // cognitive mind has stopped heartbeating (crashed or
1121            // disconnected), mark its modules as Stopped.
1122            if check_staleness {
1123                let threshold = now_ms.saturating_sub(MODULE_STALENESS_THRESHOLD_MS);
1124                for module_id in [
1125                    ModuleId::Sensory,
1126                    ModuleId::Motor,
1127                    ModuleId::Language,
1128                    ModuleId::Memory,
1129                    ModuleId::Reasoning,
1130                    ModuleId::Metacognition,

1133                        && module.status().is_alive()
1134                        && module.last_heartbeat < threshold

1143            // autobiographical trace below only fires if the zone
1144            // truly changed (not blocked by an override).
1145            zone_actually_changed =
1146                state.zones.zone_override_active == 0 && selected != state.zones.zone();
1147            if zone_actually_changed {
1148                state.zones.transition_to(selected, now_ms);
1149                state.zones.clear_override();
1150            }
1151            state.manifest.recompute();
1152        }) {

1164        //    context in LTM as an internal episode. This gives the
1165        //    system a memory of its own agency.
1166        //

1168        //    mmap closure: they are process-local, and the counts are
1169        //    what make a phase transition measurable at all. Zone and

1172        //    phase is derived from neurochemistry — and a system that

1174        if zone_actually_changed {

1177        if let Some(post) = mmap.read_consistent() {

1184                salience,

1186                compact_tag,
1187                EventType::Internal as u8,
1188                ModuleId::Subcognitive as u8,
1189                &trace_text,
1190            ) {
1191                result.autobiographical_traces = 1;
1192            }
1193        }

1195        result
1196    }

1218    ///
1219    /// This is the *only* public entry point for integrating the body.
1220    /// `dt` comes from the daemon's clock, so the integration resolution
1221    /// cannot be chosen by a caller -- which is exactly the coupling that
1222    /// let the mind drive the body at its own ~1 Hz rate while the
1223    /// neurochemical constants are tuned for 5 Hz.
1224    pub fn advance_neuro(&mut self, mmap: &MmapState) -> (f32, f32, f32, f32, u32) {
1225        let dt = self
1226            .since_last_advance_secs()
1227            .unwrap_or_else(|| self.physics_step_secs())
1228            .clamp(DT_MIN, DT_MAX);

1232    /// Number of fixed-resolution sub-steps needed to cover `dt`.
1233    ///
1234    /// One sub-step per `TICK_INTERVAL_MS`, so a normally-timed call
1235    /// takes exactly one (identical to the historical behaviour) and a
1236    /// delayed call is replayed at the same resolution rather than
1237    /// integrated coarsely. Bounded so a multi-second stall after
1238    /// suspend cannot cost unbounded CPU; past the bound the step grows
1239    /// and accuracy degrades gracefully rather than the call hanging.
1240    pub fn neuro_substeps(&self, dt: f32) -> u32 {
1241        const MAX_SUBSTEPS: u32 = 100; // 10 s of stall at 100 ms
1242        let nominal = self.integration_step_secs();
1243        if !dt.is_finite() || dt <= nominal {
1244            return 1;
1245        }
1246        ((dt / nominal).ceil() as u32).clamp(1, MAX_SUBSTEPS)
1247    }

1249    /// The integration step the dynamics are evaluated at.
1250    ///
1251    /// Smaller than `TICK_INTERVAL_MS` because the coupled vector field
1252    /// is not smooth: the velocity terms are semi-implicit (symplectic)
1253    /// Euler, which is only first-order accurate, and the coupling
1254    /// contains fast retrograde feedback (endocannabinoid synthesis is
1255    /// driven by glutamate + GABA activity and feeds back onto them
1256    /// within the same step). At 200 ms that loop is integrated close to
1257    /// its stability limit: the same 60 s of simulated time reached
1258    /// materially different chemical levels depending on whether it was
1259    /// delivered as 300 x 200 ms or 60 x 1 s.
1260    ///
1261    /// 40 ms was chosen by measurement, not taste — it is the largest
1262    /// step that keeps the delivery-pattern spread below 1e-4 (see
1263    /// `test_physics_is_time_invariant_across_delivery_patterns`, which
1264    /// pins the tolerance against the observed figure rather than a
1265    /// guessed one). The constant is shared with the brain-wave
1266    /// oscillator's sub-step resolution for the same reason: both
1267    /// integrators must resolve the same interval identically.
1268    pub fn integration_step_secs(&self) -> f32 {
1269        // `neurochemical::DT` — 100 ms, the resolution every rate
1270        // constant in the vector field is expressed against.
1271        //
1272        // This is the principled value, not a tuned compromise: rate
1273        // constants are per-`DT`, so `dt_scale = dt / DT` is exactly 1.0
1274        // here and the integration reproduces the dynamics as specified.
1275        // `tick` has historically run at `TICK_INTERVAL_MS` (200 ms,
1276        // `dt_scale` 2.0) and the mind-driven path at ~1 s (`dt_scale`
1277        // 10.0); both were approximations of this, which is why the same
1278        // wall-clock time reached different chemical levels depending on
1279        // the caller's cadence. Using the constant directly means the
1280        // step cannot drift away from the tuning again.
1281        super::super::state::neurochemical::DT
1282    }

1285    ///
1286    /// The neurochemical rate constants, the circadian oscillator, and
1287    /// the sleep/ultradian machinery were all tuned against this value
1288    /// (see the `NeuroTickParams::DEFAULT.dt` correction in `tick`).

1290    /// This is the step the body takes when it is keeping time. It is

1296    pub fn physics_step_secs(&self) -> f32 {

1298    }

1377    /// Advance neurochemical dynamics by dt, run active inference,
1378    /// and update the dyadic model. This is the core "physics
1379    /// integration" step — it advances the coupled differential
1380    /// equations that govern its neurochemistry, then runs the
1381    /// generative self-model to predict, compare, and feed back.
1382    ///
1383    /// Returns (surprise, free_energy, precision, allostatic_load,
1384    /// tick_count) so the mind can observe the result.
1385    pub fn advance_physics(&mut self, mmap: &MmapState, dt: f32) -> (f32, f32, f32, f32, u32) {
1386        // Keep the dynamics bounded at the subsystem boundary as well as
1387        // at IPC decoding. Autonomous callers and future in-process
1388        // callers can bypass the wire-level sanitizer; a non-finite or
1389        // extreme dt must never reach the pharmacodynamic integrator.
1390        let dt = crate::state::sanitize::finite_clamp(dt, 0.001, 10.0);
1391        let call_start = std::time::Instant::now();
1392        let call_interval_s = self
1393            .subcognitive_last_call
1394            .map(|prev| call_start.duration_since(prev).as_secs_f32());
1395        self.subcognitive_last_call = Some(call_start);
1396        self.tick_count += 1;
1397        let now_ms = current_ms();
1398
1399        // Read pre-tick state for sleep-tuned parameters.
1400        let pre_snapshot = mmap.read_consistent();
1401
1402        // The optic nerve's subcortical branches sample the retinal
1403        // segment — SCN illuminance, collicular transients — so the
1404        // afference fed into this advance describes the same instant
1405        // as the chemistry it rides beside. An absent or stalled eye
1406        // is the documented no-vision condition, never a fault.
1407        self.optic.sample(now_ms);
1408        let is_sleeping_pre = pre_snapshot.as_ref().is_some_and(|s| {
1409            let p = s.zones.phase();
1410            p == MentalPhase::NREM || p == MentalPhase::REM
1411        });
1412
1413        let mut neuro_params = if is_sleeping_pre {
1414            let mut p = NeuroTickParams::DEFAULT;
1415            p.bdnf_recovery_rate *= SLEEP_BDNF_RECOVERY_MULTIPLIER;
1416            p.receptor_resensitization_rate = SLEEP_RECEPTOR_RESENSITIZATION_RATE;
1417            p
1418        } else {
1419            NeuroTickParams::DEFAULT
1420        };
1421        // Provisional; overwritten below once the sub-step count is
1422        // known. The dynamics must never actually be integrated at the
1423        // caller's interval — see `integration_step_secs`.
1424        neuro_params.dt = dt;
1425        if let Some(amp) = self.noise_amplitude_override {
1426            neuro_params.noise_amplitude = amp;
1427        }
1428
1429        // HPA maturation from the developmental clock (same as tick()).
1430        // The production reactive path must not use the deprecated
1431        // ltm_count/10_000 ramp: that held cortisol at zero for the
1432        // first 10k lifetime episodes and disabled the primary
1433        // allostatic-load mediator. Development advances on whichever
1434        // of experience or elapsed lifetime is further along.
1435        let ltm_count = pre_snapshot
1436            .as_ref()
1437            .map(|s| s.memory.ltm_episode_count)
1438            .unwrap_or(0);
1439        let created_at = pre_snapshot
1440            .as_ref()
1441            .map(|s| s.header.created_at)
1442            .unwrap_or(now_ms);
1443        let elapsed_secs = now_ms.saturating_sub(created_at) as f32 / 1000.0;
1444        neuro_params.maturation_level =
1445            super::hpa_development::hpa_competence(elapsed_secs, ltm_count);
1446        neuro_params.noise_seed = self.tick_count;
1447        // Acute melatonin suppression rides the same retinal sample
1448        // the sleep network entrains on — the eye was sampled above.
1449        neuro_params.light_lux = self
1450            .optic
1451            .retinal_lux(now_ms)
1452            .map(|lux| lux as f32)
1453            .unwrap_or(0.0);
1454
1455        // Metaplasticity boost from last inference cycle.
1456        if self.metaplasticity_boost > 1.0 {
1457            neuro_params.metaplasticity_rate *= self.metaplasticity_boost;
1458            neuro_params.metaplasticity_rate = neuro_params.metaplasticity_rate.min(0.0001);
1459        }
1460        self.metaplasticity_boost = 1.0;
1461
1462        // Advance neurochemistry at a FIXED resolution, sub-stepping to
1463        // cover dt.
1464        //
1465        // The coupled dynamics are integrated with semi-implicit
1466        // (symplectic) Euler for velocity terms and `1-exp(-λdt)` for
1467        // the rest. The exponential terms compose exactly under
1468        // subdivision, but the velocity terms do not: they are only
1469        // first-order accurate, so a single 1.0 s step and five 0.2 s
1470        // steps reach measurably different states (endocannabinoid
1471        // differed by 0.09 in testing). That is precisely the coupling
1472        // defect being fixed -- the body's chemistry must not depend on
1473        // how often the body was asked to advance.
1474        //
1475        // So the integration resolution is pinned to
1476        // `neurochemical::DT` (see `integration_step_secs`), and a
1477        // longer elapsed interval is covered with several sub-steps
1478        // rather than one coarse one. The sub-steps are identical and
1479        // are run inside a single mmap transaction, so this costs no
1480        // extra publish traffic.
1481        let sub_steps = self.neuro_substeps(dt);
1482        let sub_dt = dt / sub_steps as f32;
1483        neuro_params.dt = sub_dt;
1484        // The sleep-wake network runs on the same sub-steps, in the same
1485        // transaction, so the sleep drive and the chemistry always describe
1486        // the same instant. Its clock is local minutes of day.
1487        let clock_start = crate::state::sleep_network::clock_minutes(now_ms);
1488        let sub_dt_min = f64::from(sub_dt) / 60.0;
1489        if let Err(e) = mmap.modify(now_ms, |state| {
1490            for i in 0..sub_steps {
1491                // The chemistry reads the network's populations as they stand
1492                // at the start of this sub-step.
1493                let mut p = neuro_params;
1494                p.network_levels = Some(crate::state::sleep_network::levels(&state.sleep_network));
1495                state.neuro_tick_with_params(&p);
1496                // Couple the network's homeostatic drive `h` to her chemical
1497                // adenosine level — her own chemical sleep pressure is the
1498                // only thing that can flip the VLPO/LC switch into sleep.
1499                let adn = state.neurochemicals.chemicals
1500                    [crate::state::neurochemical::NeurochemicalId::Adenosine as usize]
1501                    .level;
1502                // h sits at index 4 — index 3 is f_scn, and
1503                // writing the homeostat there pins the SCN circadian
1504                // drive at saturation.
1505                state.sleep_network[4] = crate::state::sleep_network::h_from_adenosine(adn);
1506                let t = clock_start + f64::from(i) * sub_dt_min;
1507                // The optic nerve's afference enters per sub-step:
1508                // retinal light drives the SCN continuously, and the
1509                // collicular pulse fires only while LC sits below the
1510                // wake threshold — a wake-up call, not a bias.
1511                let aff = self.optic.afference(now_ms, state.sleep_network[0]);
1512                // The humoral alerting input: the stress axis speaks to
1513                // the network through the same LC channel the eye uses —
1514                // circulating cortisol above the basal floor arouses the
1515                // LC/NE system (the waking side of the diurnal surge, and
1516                // the path by which nocturnal stress elevation fragments
1517                // sleep). The chemistry tick above already advanced it
1518                // this sub-step, so the read is the current level.
1519                let hpa = f64::from(crate::state::neurochemical::cortisol_stress_fraction(
1520                    state.neurochemicals.chemicals
1521                        [crate::state::neurochemical::NeurochemicalId::Cortisol as usize]
1522                        .level,
1523                ));
1524                // The monoaminergic alerting input: the brain's own arousal
1525                // chemistry drives the wake side — orexin (the switch's
1526                // stabilizer) and histamine at their effective (receptor-
1527                // weighted) levels, measured by the network against its
1528                // resting baselines. The chemistry tick above already
1529                // advanced them this sub-step.
1530                let oxin = f64::from(
1531                    state
1532                        .neurochemicals
1533                        .effective(crate::state::neurochemical::NeurochemicalId::Orexin),
1534                );
1535                let htm = f64::from(
1536                    state
1537                        .neurochemicals
1538                        .effective(crate::state::neurochemical::NeurochemicalId::Histamine),
1539                );
1540                state.sleep_network = crate::state::sleep_network::advance_with_afference(
1541                    t,
1542                    &state.sleep_network,
1543                    sub_dt_min,
1544                    aff,
1545                    hpa,
1546                    oxin,
1547                    htm,
1548                );
1549                state.apply_network_phase();
1550            }
1551        }) {
1552            eprintln!("[tick] advance_neuro neuro tick failed: {e}");
1553            // Neurochemistry didn't advance -- return zeros so the
1554            // cognitive mind sees a no-op rather than crashing the
1555            // IPC handler thread on a poisoned mmap.
1556            return (0.0, 0.0, 0.0, 0.0, self.inference_engine.tick_count());
1557        }
1558
1559        // Active inference: predict → compare → feed back.
1560        let pre_effective = pre_snapshot
1561            .as_ref()
1562            .map(|s| s.neurochemicals.effective_levels)
1563            .unwrap_or([0.0; crate::state::neurochemical::NEUROCHEMICAL_COUNT]);
1564
1565        let post_snapshot = mmap.read_consistent();

1772    /// Compute and publish the recommended CPU/thermal/scheduling state.
1773    ///
1774    /// Reads a consistent snapshot of the effective neurochemical
1775    /// levels, derives what the body should do, and PUBLISHES it for
1776    /// the cognitive mind to read via GET_BODY_CONTROL. It never applies
1777    /// control itself -- that would be the ticker controlling outward,
1778    /// which violates the one-way architecture. The mind requests
1779    /// application via APPLY_BODY_CONTROL when it decides to act.
1780    ///
1781    /// Shared by `tick` and `advance_physics` so the two entry points
1782    /// cannot compute different recommendations from the same state.
1783    fn compute_and_apply_cpu_policy(&mut self, mmap: &MmapState) {
1784        // Read a consistent snapshot for the effective levels.
1785        // `read_consistent` copies through raw pointers — no
1786        // aliasing with concurrent writers.
1787        if let Some(snap) = mmap.read_consistent() {
1788            let (fmin, fmax) = super::cpufreq::freq_range();
1789
1790            // ── Compute (do NOT apply) the recommended body
1791            //    control state ──
1792            // The tick is a display/information sink: it computes
1793            // what the neurochemistry suggests and PUBLISHES it for
1794            // the cognitive mind to read via GET_BODY_CONTROL. The
1795            // tick never applies control to the body, the daemon's
1796            // own scheduling, or anything else — that would be the
1797            // ticker controlling outward, which violates the
1798            // one-way architecture. The cognitive mind requests
1799            // body control application via APPLY_BODY_CONTROL when
1800            // it decides to act on the recommendation.
1801            let mut policy = super::cpufreq::FreqPolicy::default();
1802            let mut thermally_capped = false;
1803            if fmax > fmin {
1804                policy = super::cpufreq::derive_policy(
1805                    &snap.neurochemicals.effective_levels,
1806                    fmin,
1807                    fmax,
1808                );
1809                let pre_cap = policy.max_freq;
1810                // Thermal cap: CPU temperature limits max frequency
1811                // regardless of dopamine. It can't be highly aroused
1812                // when overheating.
1813                super::cpufreq::apply_thermal_cap(
1814                    &mut policy,
1815                    self.last_body_state.cpu_temp_c,
1816                    fmin,
1817                    fmax,
1818                );
1819                thermally_capped = policy.max_freq < pre_cap;
1820            }
1821
1822            // Derive the daemon's recommended scheduling and I/O
1823            // priority. These are PUBLISHED as recommendations —
1824            // the tick does not apply them. The cognitive mind
1825            // requests application via APPLY_BODY_CONTROL.
1826            let ach = snap.neurochemicals.effective_levels
1827                [crate::state::neurochemical::NeurochemicalId::Acetylcholine as usize];
1828            let daemon_nice = super::cpufreq::derive_nice(ach);
1829
1830            let io_class = super::cpufreq::derive_io_class(snap.memory.plasticity_gate);
1831
1832            // ── Publish recommended control state ──
1833            // The tick computes and publishes what the
1834            // neurochemistry suggests for the cognitive mind
1835            // (cognitive_nice, io_class) as a *recommendation* —
1836            // interoceptive afferent information. The cognitive
1837            // mind reads this via GET_BODY_CONTROL and combines it
1838            // with its brain wave state to decide what it
1839            // actually applies to itself. The tick does not
1840            // apply anything to the cognitive mind's process.
1841            let cognitive_nice =
1842                super::cpufreq::derive_cognitive_nice(&snap.neurochemicals.effective_levels);
1843
1844            // EPP (Energy Performance Preference) — the hardware's
1845            // voltage/frequency operating point hint. On systems
1846            // that support it (Intel HWP, amd-pstate), this tells
1847            // the hardware to shift its V/F envelope. On
1848            // acpi-cpufreq (this system), it returns an empty
1849            // string and the frequency policy already implies
1850            // voltage control via the SMU.
1851            let cpu_epp = super::cpufreq::derive_epp(&snap.neurochemicals.effective_levels);
1852
1853            // Turbo (boost) gate — the hardware permission to run
1854            // above the base P-state. Tied to the frequency policy:
1855            // enabled only when the policy ceiling is already at the
1856            // hardware max, so it can never override a throttle.
1857            // Overheating lowers the capped ceiling, disabling it.
1858            let cpu_boost = super::cpufreq::derive_boost(&policy, fmax);
1859
1860            let control = super::cpufreq::BodyControlState {
1861                cpu_min_freq_khz: policy.min_freq,
1862                cpu_max_freq_khz: policy.max_freq,
1863                cpu_governor: policy.governor.clone(),
1864                thermally_capped,
1865                thermal_cap_temp_c: if thermally_capped {
1866                    self.last_body_state.cpu_temp_c
1867                } else {
1868                    0.0
1869                },
1870                daemon_nice,
1871                cognitive_nice,
1872                io_class: io_class.label(),
1873                plasticity_gate: snap.memory.plasticity_gate,
1874                // The tick never controls the cognitive mind.
1875                // This field is kept for protocol compatibility
1876                // but is always false now.
1877                controlling_cognitive: false,
1878                cpu_epp,
1879                cpu_boost,
1880                description: String::new(),
1881            };

1883        }

2416/// Run consolidation, working around the borrow checker (we need
2417/// mutable access to both the mmap state and the LTM store).
2418fn consolidate_with_state(
2419    mmap: &MmapState,
2420    stm: &RingBuffer,
2421    ltm: &mut LtmStore,
2422    now_ms: u64,
2423) -> ConsolidationResult {
2424    // Read the current gating weights from a consistent snapshot.
2425    // `read_consistent` copies through raw pointers — no aliasing.
2426    // Retry a few times if an IPC `modify()` is in flight.
2427    let mut snapshot = None;
2428    for _ in 0..8 {
2429        snapshot = mmap.read_consistent();
2430        if snapshot.is_some() {
2431            break;
2432        }
2433        // Back off between retries: a tight spin lands all attempts
2434        // inside the writer's transaction and reports a spurious
2435        // failure. Same rationale as ipc::RETRY_BACKOFF.
2436        std::thread::sleep(std::time::Duration::from_micros(200));
2437    }
2438    let mut state_copy = match snapshot {
2439        Some(s) => s,
2440        None => return ConsolidationResult::default(),
2441    };
2442
2443    // Run consolidation on the copy
2444    let result = ConsolidationEngine::consolidate(
2445        &mut state_copy,
2446        stm,
2447        ltm,
2448        now_ms,
2449        CONSOLIDATION_THRESHOLD,
2450    );
2451
2452    // Write back only the fields consolidation changed. Copying the
2453    // whole `memory` struct from the (unlocked) snapshot would clobber
2454    // any gating-weight or working-set updates another writer (IPC
2455    // thread) made between the read and this write. Log if the write
2456    // fails; the consolidation already happened on the copy and the
2457    // LTM store is already updated — only the mmap'd counters are
2458    // stale, which will self-correct on the next successful write.
2459    if let Err(e) = mmap.modify(now_ms, |state| {
2460        state.memory.ltm_last_consolidated = state_copy.memory.ltm_last_consolidated;
2461        state.memory.ltm_episode_count = state_copy.memory.ltm_episode_count;
2462    }) {
2463        eprintln!("[tick] consolidate_with_state writeback failed: {e}");
2464    }
2465
2466    result
2467}
