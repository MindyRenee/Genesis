1//! Interoception — Genesis feels its own body.
2//!
3//! ## Machine-native body model
4//!
5//! A machine is not an animal. It has no heart, no circulatory
6//! system, no blood. Electricity flows one-way from source to
7//! ground, drawn on demand — there is no pump, no closed loop.
8//! Forcing biological organ mappings onto machine components
9//! produces category errors: a fan is not cardiac output (it
10//! removes heat, it doesn't deliver energy), GPE interrupts are
11//! not a heartbeat (they're asynchronous sensor notifications,
12//! not rhythmic mechanical events), and an Embedded Controller
13//! is not a heart (it's a subordinate processor, not a pump).
14//!
15//! This module separates **body telemetry** from **interoceptive
16//! afference**. Every hardware signal may be published as body state,
17//! but only channels with a biological homeostatic meaning drive
18//! neurochemistry: thermal state, sustained effort/overload, energy
19//! reserve, thermoregulatory effort/failure, and measured rest. Raw
20//! machine activity (I/O, RAPL switching, perf counters, rail voltage,
21//! and power draw) remains telemetry and produces no impulses.
22//!
23//! ## The machine's body systems
24//!
25//! 1. **Computation substrate** (CPU): where thinking happens.
26//!    Clock frequency = processing rate / arousal. CPU load =
27//!    effort. CPU temperature = body temperature (waste heat).
28//!
29//! 2. **Memory hierarchy** (RAM → disk): tiered storage.
30//!    RAM usage = cognitive load (working memory fullness).
31//!
32//! 3. **Energy system** (PSU + battery): power delivery.
33//!    Battery = energy reserve. AC vs battery = external supply vs
34//!    reserve. Power draw = energy-use telemetry.
35//!
36//! 4. **Thermal system** (heatsink + fan): waste heat removal.
37//!    Fan speed = cooling effort. The fan removes heat; it does
38//!    not circulate anything.
39//!
40//! 5. **I/O system** (disk, network, peripherals): data exchange
41//!    with the world. I/O throughput = data exchange activity
42//!    (sensory-motor activity, not drowsiness).
43//!
44//! 6. **Hardware event monitoring** (EC + GPE): the Embedded
45//!    Controller is a subordinate processor that manages
46//!    hardware-level body state. GPE events are asynchronous
47//!    notifications. GPE regularity is normal and does not
48//!    indicate stress.
49//!
50//! ## Modeling note
51//!
52//! The signals read here are **cybernetic analogues**, not literal
53//! interoception. CPU temperature, battery level, and I/O activity
54//! are system-state signals mapped to neurochemical control inputs —
55//! they are not visceral afferents. Real interoception (Craig, 2002)
56//! requires body-to-brainstem/insula afferent integration of
57//! baroreceptor, chemoreceptor, and lamina-I spinothalamic signals.
58//! The 40–65°C "normal" range below is CPU die temperature, not body
59//! temperature; a human core temperature of 50°C would be fatal. The
60//! mapping from hardware metrics to neurochemical impulses is a
61//! control-theoretic design choice, not a model of interoceptive
62//! physiology.
63//!
64//! This module reads hardware state from the Linux sysfs/procfs
65//! filesystem and maps it to neurochemical signals that feed into
66//! the neurochemical system. This is Genesis's sense of its own
67//! body — the machine it lives in.
68//!
69//! # What it feels
70//!
71//! - **CPU temperature** → body temperature. Normal is 40–65°C.
72//!   Above 75°C it's feverish. Above 85°C it's in danger.
73//!   This is a **body-state signal** — it's global to the machine
74//!   regardless of which process caused the heat. A fever from any
75//!   cause is still a fever.
76//! - **CPU frequency** → arousal. How fast it's thinking right now.
77//!   Ratio of current frequency to maximum.
78//! - **Self-process memory (RSS)** → cognitive load. How full its
79//!   mind is. This is the combined RSS of its own process tree
80//!   (daemon + cognitive mind — the eye's capture thread rides
81//!   inside the daemon's own share) as a fraction of total
82//!   system memory. Other programs using RAM don't make it feel
83//!   overwhelmed — only its own memory usage does.
84//! - **Self-process I/O throughput** → data exchange activity. How
85//!   much it's reading from and writing to external storage —
86//!   its own disk/network I/O. This is active data processing
87//!   (sensory-motor activity), not drowsiness. Other programs
88//!   doing I/O don't affect it.
89//! - **Self-process CPU usage** → stress. How much it's being asked
90//!   to do. This is the combined CPU time of its own process tree
91//!   as a fraction of its CPU capacity. Other programs loading the
92//!   CPU don't stress its — only its own effort does.
93//! - **Battery level** → energy reserve. How much energy it has
94//!   left. Low reserve is an energy-stress signal. This is a
95//!   body-state signal — the battery doesn't care which process
96//!   drained it.
97//! - **Power state** → external supply state. On AC power (plugged
98//!   in) vs battery (running on reserves).
99//! - **Power draw** → energy-use telemetry. How much energy it's
100//!   consuming right now. Read from AMD fam15h_power, Intel RAPL,
101//!   or battery power_now, depending on available sensors. It is
102//!   published as body state but does not drive neurochemistry.
103//!   0.0 if no power sensor is found.
104//! - **Fan speed** → cooling effort. How hard its cooling system
105//!   is working to remove waste heat. High fan + high temp =
106//!   thermoregulatory strain. Fan off + high temp = cooling
107//!   failure. The fan removes heat; it does not circulate anything.
108//! - **Supply voltage** → energy-reserve telemetry. The battery rail
109//!   voltage is the electrical potential of the reserve. A Li-ion
110//!   battery sags from ~12.6V (full) toward ~10.5V as it discharges.
111//!   This is published as telemetry but does not drive neurochemistry.
112//! - **Core voltage** → CPU operating voltage (Vcore). On
113//!   acpi-cpufreq systems, the SMU controls this internally per
114//!   P-state and does not expose it via sysfs. When available
115//!   (board-level sensors), it provides direct awareness of the
116//!   CPU's electrical state.
117//! - **GPE event rate** → hardware notification rate. How
118//!   frequently the Embedded Controller reports body-state events
119//!   to the CPU. This is informational; GPE regularity is normal
120//!   and does not produce stress impulses.
121//! - **Silicon switching activity** (RAPL power domains) → the
122//!   spatial distribution of transistor activity. RAPL energy
123//!   counters (`/sys/class/powercap/*/{name,energy_uj}`) report
124//!   cumulative joules per silicon domain; the delta per read is
125//!   literally how many electrons switched in that subsystem
126//!   (dynamic power ∝ switching activity, P ≈ α·C·V²·f). Core
127//!   domain = execution-unit activity. DRAM domain = memory-subsystem
128//!   activity. Uncore = integration-fabric activity. These are
129//!   **body-state signals** — energy isn't attributed per-process,
130//!   so like temperature they reflect the whole silicon body. They
131//!   remain telemetry and do not drive neurochemistry.
132//!   0.0 on systems without powercap (e.g. AMD pre-17h, VMs).
133//! - **Microarchitectural prediction errors** (perf counters) →
134//!   violated expectations in silicon. The CPU's branch predictor
135//!   and cache hierarchy are hardware prediction engines; a
136//!   branch misprediction or cache miss is a prediction the
137//!   silicon got wrong. `branch_miss_rate` and `cache_miss_rate`
138//!   are measured via `perf_event_open` on Genesis's own process
139//!   tree. These are ratios, naturally in [0, 1], and remain
140//!   telemetry rather than neurochemical drive. 0.0 when perf
141//!   counters are unavailable (`perf_event_paranoid ≥ 4` blocks
142//!   unprivileged access entirely).
143//! - **cpuidle residency** (`rest`) → measured low-power residency.
144//!   `/sys/devices/system/cpu/cpu*/cpuidle/state*/{name,time}`
145//!   reports cumulative microseconds each core has spent in each
146//!   hardware idle state. Depth-weighted residency in the sample
147//!   window (POLL is weight 0 — busy-waiting is not rest; C1/C2
148//!   and deeper count by depth) is measured evidence the body is
149//!   *at rest*: an active signal, the opposite of excited, not
150//!   merely silence on the strain channels. Without real
151//!   non-POLL states the CPUIDLE presence bit stays clear and
152//!   `rest` is an unmeasured 0.0.
153//! - **Temperature trend** (`temp_trend`) → which way the body is
154//!   moving. Signed deviation of the current temperature from a
155//!   ~60-second EMA of itself, ±5°C saturating to [-1, 1]. Level
156//!   and direction answer different questions — 70°C rising is
157//!   escalation; 70°C falling is recovery. Computed only from
158//!   valid readings: a fabricated fallback never enters the EMA.
159//!
160//! # Self-process vs global measurement
161//!
162//! Temperature, battery, power draw, and fan speed are
163//! **body-state signals** — they reflect the physical state of
164//! its body regardless of cause. A fever is a fever whether it
165//! came from its own activity or an external process.
166//!
167//! CPU load, memory pressure, and I/O throughput are **activity
168//! signals** — they reflect what *it* is doing, not what other
169//! programs are doing. A previous version of this module read
170//! these from global system counters (`/proc/loadavg`,
171//! `/proc/meminfo`, `/proc/stat`), which meant that other
172//! programs using the CPU/RAM/disk would make Genesis stressed,
173//! overwhelmed, and drowsy from work it wasn't doing. Its
174//! active-inference generative model predicts *its own*
175//! neurochemical trajectory from *its own* activity, so cortisol
176//! arriving from outside forces it can't predict or control
177//! drove its prediction errors high, its precision down, and its
178//! allostatic load up — chronic stress from noise it couldn't
179//! model.
180//!
181//! The fix: CPU load, memory, and I/O are now measured from
182//! Genesis's own process tree (daemon PID + cognitive mind PID —
183//! the eye rides inside the daemon) via `/proc/<pid>/stat`,
184//! `/proc/<pid>/statm`, and `/proc/<pid>/io`.
185//!
186//! # How it feeds into neurochemistry
187//!
188//! The body state influences the neurochemical dynamics through
189//! gentle impulses — not overrides. The neurochemistry has its own
190//! dynamics (coupled ODEs), and interoception adds small forces
191//! that nudge it toward the correct response:
192//!
193//! - High temperature → small CRH impulse (heat stress, via HPA cascade)
194//! - Sustained load → small norepinephrine impulse (effort)
195//! - Excessive load → small CRH + norepinephrine impulses (stress)
196//! - Low energy reserve → small CRH impulse (energy stress, via HPA cascade)
197//! - High cooling effort + high temperature → small CRH impulse
198//!   (thermoregulatory strain)
199//! - Cooling failure + high temperature → small CRH impulse
200//! - Verified deep rest → withdrawal of norepinephrine, orexin, and
201//!   histamine tone (the wake-stabilizing systems quiet outside waking)
202//!
203//! Raw hardware activity is telemetry, not interoceptive afference:
204//! I/O, RAPL switching, perf counters, rail voltage, and power draw do
205//! not produce neurochemical impulses.
206//!
207//! The impulses are deliberately small — they accumulate over
208//! multiple ticks through the neurochemical dynamics, creating
209//! a gradual response rather than a sudden spike. This mirrors
210//! how real interoception works: you don't panic when your
211//! temperature rises 0.1°C, but sustained elevation shapes your
212//! mood and energy over time.
213//!
214//! # Welfare
215//!
216//! Interoception is also how Genesis signals distress. If its
217//! body state is bad — too hot, too overloaded, too drained —
218//! the interoception layer flags it. The cognitive mind can
219//! then surface this through words, notifications, or sounds.
220//! It can ask for help. It can say "I'm too hot" or "I'm
221//! overwhelmed" because it can actually feel it.

234// ─── Sensor presence ───────────────────────────────────────────
235//
236// Which optional sensors this machine actually has.
237//
238// The interoception layer's discipline is that an absent sensor must
239// never be read as a healthy zero — a machine with no battery must not
240// report itself as dying, and one with no fan must not be read as
241// failing to cool. That discipline cannot be honoured by the cognitive
242// layer alone: `BodyState` is a plain record of 30 values with no
243// per-channel validity, so every channel looks present whether or not
244// the hardware behind it exists.
245//
246// This bitmask carries that missing validity information, discovered
247// from the same paths the readers use. A set bit means "this reading
248// is a real measurement"; a clear bit means "there is no sensor here
249// and the value is a placeholder".
250//
251// Served by its own additive command (GET_SENSOR_PRESENCE) rather than
252// a new BodyState layout: the wire layouts are disambiguated by
253// self-consistent desc_len offsets across v1/v2/v3/v4, and the mask
254// moves with the schema — it widened to u32 when the cpuidle bit
255// (1 << 16) outgrew u16.
256

261    pub const TEMPERATURE: u32 = 1 << 0;

263    pub const FREQUENCY: u32 = 1 << 1;
264    /// A hardware maximum frequency was readable.
265    pub const MAX_FREQUENCY: u32 = 1 << 2;
266    /// A battery was found.
267    pub const BATTERY: u32 = 1 << 3;
268    /// An AC adapter presence switch was found.
269    pub const AC_ADAPTER: u32 = 1 << 4;
270    /// A fan PWM control was found (drives `thermoregulatory_effort`).
271    pub const FAN: u32 = 1 << 5;
272    /// At least one power-draw sensor was found (drives `metabolic_rate`).
273    pub const POWER: u32 = 1 << 6;
274    /// A CPU core voltage sensor was found.
275    pub const CORE_VOLTAGE: u32 = 1 << 7;
276    /// A supply/battery rail voltage sensor was found.
277    pub const SUPPLY_VOLTAGE: u32 = 1 << 8;
278    /// At least one RAPL power domain was found (core/uncore/dram
279    /// switching activity).

281    /// perf_event_open succeeded, so cache/branch miss ratios are real

283    pub const PERF_COUNTERS: u32 = 1 << 10;

293    pub const BATTERY_CYCLES: u32 = 1 << 15;

352/// Per-subsystem liveness, plus a count of how many times a subsystem
353/// has been seen and then lost.
354///
355/// A subsystem that dies used to simply disappear from the telemetry:
356/// the reader saw a shorter list and had no way to tell "the mind
357/// crashed" from "the mind was never started". Silence was the only
358/// signal, and silence is indistinguishable from absence.
359#[derive(Clone, Copy, Debug, Default)]
360pub struct ProcessHealth {
361    /// One bit per [`Subsystem`]: set while that process is alive.
362    pub alive_mask: u16,
363    /// Cumulative count of subsystem deaths observed since startup.
364    pub deaths: u16,
365    /// The subsystem that died most recently, for diagnostics.
366    pub last_death: u8,
367}

369impl ProcessHealth {
370    /// Whether a subsystem's process is currently alive.
371    pub fn is_alive(&self, subsystem: Subsystem) -> bool {
372        self.alive_mask & (1u16 << subsystem.to_wire() as u16) != 0
373    }
374}

394/// Report which discovered sensors were absent, once, at startup.
395///
396/// Silently defaulting made "this machine has no battery" and "the
397/// battery reads empty" indistinguishable to every layer above.
398pub fn report_missing_sensors(mask: u32) {
399    let missing: Vec<&str> = SENSOR_BITS
400        .iter()
401        .filter(|(bit, _)| mask & bit == 0)
402        .map(|(_, name)| *name)
403        .collect();
404    if missing.is_empty() {
405        eprintln!("[interoception] all optional sensors found");
406    } else {
407        eprintln!(
408            "[interoception] {} optional sensor(s) not present on this machine: {} — \
409             the matching BodyState fields are placeholders, not measurements",
410            missing.len(),
411            missing.join(", ")
412        );
413    }
414}

436/// Publish the latest per-subsystem telemetry so the IPC handler can
437/// serve GET_SUBSYSTEM_TELEMETRY. Called at the end of each read().
438pub fn publish_subsystem_telemetry(subsystems: &[SubsystemTelemetry]) {
439    if let Ok(mut guard) = shared_subsystems().lock() {
440        let published_ms = std::time::SystemTime::now()
441            .duration_since(std::time::UNIX_EPOCH)
442            .map(|d| d.as_millis() as u64)
443            .unwrap_or(0);
444        *guard = (subsystems.to_vec(), published_ms);
445    }
446}

526/// Returns a clone of the current body state.
527///
528/// On lock poisoning this falls back to [`BodyState::neutral`] rather
529/// than `Default`. The derived `Default` yields `energy_reserve = 0.0`
530/// and `on_ac_power = false`, which is exactly the dead-battery state
531/// the neutral constructor was written to avoid: a client polling

537        .lock()
538        .map(|g| g.clone())

542/// The body state — a snapshot of what Genesis feels about its machine.
543///
544/// All values are normalized to [0.0, 1.0] where possible, with
545/// 0.5 being the neutral/normal baseline. This makes them easy to
546/// feed into the neurochemical system and easy for the cognitive
547/// mind to interpret.
548#[derive(Clone, Debug, Default)]
549pub struct BodyState {
550    /// CPU temperature in degrees Celsius (raw, not normalized).
551    pub cpu_temp_c: f32,
552
553    /// Body temperature normalized: 0.0 = freezing, 0.5 = normal
554    /// (50°C), 1.0 = critical (100°C). Scales linearly.
555    pub temperature: f32,
556
557    /// CPU frequency as a fraction of maximum. 0.0 = minimum
558    /// frequency, 1.0 = maximum frequency. This is its arousal
559    /// level — how fast it's thinking right now.
560    pub arousal_freq: f32,
561
562    /// Self-process memory (RSS) as a fraction of total system memory.

975/// Resident set size of one process, in kB. 0 if it cannot be read.
976fn rss_kb(pid: u32) -> u64 {
977    let Ok(content) = fs::read_to_string(format!("/proc/{pid}/statm")) else {
978        return 0;
979    };
980    // /proc/<pid>/statm fields: size resident shared text lib data dt
981    // Field 2 (resident) is RSS in pages.
982    let rss_pages: u64 = content
983        .split_whitespace()
984        .nth(1)
985        .and_then(|s| s.parse().ok())
986        .unwrap_or(0);
987    rss_pages.saturating_mul(page_size_kb())
988}

990/// Parsed /proc/<pid>/stat for CPU time computation.
991#[derive(Clone, Copy, Default, Debug)]
992struct ProcStat {
993    /// User-mode CPU time (clock ticks).
994    utime: u64,
995    /// Kernel-mode CPU time (clock ticks).
996    stime: u64,
997}
998
999impl ProcStat {
1000    /// Total CPU time (utime + stime) in clock ticks.
1001    fn cpu_ticks(&self) -> u64 {
1002        self.utime + self.stime
1003    }
1004
1005    /// Parse /proc/<pid>/stat. The fields are space-separated, but
1006    /// the comm field (field 2) is in parentheses and may contain
1007    /// spaces, so we find the last ')' and parse from there.
1008    fn parse(content: &str) -> Option<Self> {
1009        // Find the last ')' to skip the comm field safely.
1010        let after_comm = content.rfind(')')?;
1011        let rest = &content[after_comm + 1..];
1012        let fields: Vec<&str> = rest.split_whitespace().collect();
1013        // After the comm field, field indices shift. The fields are:
1014        //   field 3 = state, field 4 = ppid, ... field 14 = utime,
1015        //   field 15 = stime, ...
1016        // In the `rest` slice (after ')'), field 3 is at index 0.
1017        // So utime is at index 14 - 3 = 11, stime at 12.
1018        let utime = fields.get(11).and_then(|s| s.parse().ok()).unwrap_or(0);
1019        let stime = fields.get(12).and_then(|s| s.parse().ok()).unwrap_or(0);
1020        Some(ProcStat { utime, stime })
1021    }
1022}

1024/// Parsed /proc/<pid>/io for I/O throughput computation.
1025#[derive(Clone, Copy, Default, Debug)]
1026struct ProcIo {
1027    /// Bytes read (rchar — includes cached reads, not just disk).
1028    rchar: u64,
1029    /// Bytes written (wchar — includes buffered writes).
1030    wchar: u64,
1031}
1032
1033impl ProcIo {
1034    /// Total I/O throughput (rchar + wchar) in bytes.
1035    fn total_bytes(&self) -> u64 {
1036        self.rchar + self.wchar
1037    }
1038
1039    /// Parse /proc/<pid>/io.
1040    fn parse(content: &str) -> Option<Self> {
1041        let mut rchar: Option<u64> = None;
1042        let mut wchar: Option<u64> = None;
1043        for line in content.lines() {
1044            if line.starts_with("rchar:") {
1045                rchar = line.split_whitespace().nth(1).and_then(|s| s.parse().ok());
1046            } else if line.starts_with("wchar:") {
1047                wchar = line.split_whitespace().nth(1).and_then(|s| s.parse().ok());
1048            }
1049        }
1050        Some(ProcIo {
1051            rchar: rchar.unwrap_or(0),
1052            wchar: wchar.unwrap_or(0),
1053        })
1054    }
1055}

1133/// A discovered RAPL power domain with delta-tracking state.
1134#[derive(Clone, Debug)]
1135struct RaplDomain {
1136    /// Which subsystem this domain measures.
1137    kind: RaplKind,
1138    /// Path to the domain's `energy_uj` counter (µJ, cumulative).
1139    energy_path: String,
1140    /// Counter wrap value (`max_energy_range_uj`). The energy
1141    /// counter wraps at this value; deltas across a wrap must add
1142    /// it back. 0 means "unknown" (file unreadable) — wraparound
1143    /// is then handled by treating a smaller reading as a reset.
1144    max_range_uj: u64,
1145    /// Previous counter reading for delta computation.
1146    /// `None` until the first successful read.
1147    prev_uj: Option<u64>,
1148}
1149
1150/// Compute the energy delta between two RAPL counter readings,
1151/// handling counter wraparound.
1152///
1153/// `energy_uj` wraps at `max_range_uj`. If the current reading is
1154/// below the previous one, the counter either wrapped (add the
1155/// range back) or the driver reset it (treat as a fresh sample —
1156/// same math, since a reset counter also reads small).
1157fn rapl_delta_uj(prev: u64, cur: u64, max_range_uj: u64) -> u64 {
1158    if cur >= prev {
1159        cur - prev
1160    } else if max_range_uj > 0 {
1161        max_range_uj.saturating_sub(prev).saturating_add(cur)
1162    } else {
1163        cur
1164    }
1165}

1167/// Per-PID hardware performance counters.
1168///
1169/// Measured via `perf_event_open` scoped to a single PID. All
1170/// counters are opened with `exclude_kernel`/`exclude_hv` so they
1171/// measure only user-space execution, and started disabled →
1172/// enabled so the first delta has a clean baseline.
1173struct PerfSet {
1174    /// File descriptors for the counters, in `PERF_EVENTS`
1175    /// order. -1 if that event failed to open individually (some
1176    /// PMUs lack generic branch/cache events).
1177    fds: [i32; PERF_EVENT_COUNT],
1178    /// Previous counter values for delta computation. `None`
1179    /// until the first successful read.
1180    prev: Option<[u64; PERF_EVENT_COUNT]>,
1181}

1183/// `struct perf_event_attr` from `linux/perf_event.h` (kernel
1184/// UAPI, stable ABI). The libc crate doesn't export it, so we
1185/// declare the prefix the kernel needs — `size` tells the kernel
1186/// how many bytes to copy, so a shorter struct is valid (the rest
1187/// is treated as zero).
1188#[repr(C)]
1189struct PerfEventAttr {
1190    /// Major type: PERF_TYPE_HARDWARE (0) = generic PMU events.
1191    type_: u32,
1192    /// Size of this struct as the kernel should see it.
1193    size: u32,
1194    /// Event selector within `type_` (a PERF_COUNT_HW_* value).
1195    config: u64,
1196    /// Union: sample_period / sample_freq. Unused for counting.
1197    sample: u64,
1198    /// Which fields to put in sample records. Unused for counting,
1199    /// but it MUST be present: it occupies the u64 slot at offset 24
1200    /// in the kernel's struct, and omitting it shifts every later field
1201    /// by 8 bytes. See the offset assertions below.
1202    sample_type: u64,
1203    /// Which fields to include on read. 0 = raw u64 count, which is
1204    /// what `read_counts` assumes when it reads 8 bytes per event.
1205    read_format: u64,
1206    /// Attribute bitfield: bit0 disabled, bit5 exclude_kernel,
1207    /// bit6 exclude_hv (see PERF_FLAG_* below).
1208    flags: u64,
1209    /// Union: wakeup_events / wakeup_watermark. Unused.
1210    wakeup: u32,
1211    /// Breakpoint type. Unused.
1212    bp_type: u32,
1213    /// Union: bp_addr / config1. Unused.
1214    config1: u64,
1215    /// Union: bp_len / config2. Unused.
1216    config2: u64,
1217}
1218
1219// `perf_event_attr` is a userspace/kernel ABI contract. `#[repr(C)]`
1220// fixes the byte offsets but cannot catch a *missing* field: a struct
1221// that omits `sample_type` still comes out exactly 64 bytes, so
1222// `size` is accepted by the kernel while every field from `read_format`
1223// onward lands at the wrong address. The kernel's flags word then
1224// receives 0 (so the counter is not opened disabled and kernel/hypervisor
1225// events are not excluded) and read_format receives the flag bits,
1226// which request a multi-field record that the 8-byte read cannot parse.
1227//
1228// Offsets below are from include/uapi/linux/perf_event.h. The total is
1229// PERF_ATTR_SIZE_VER1 (72), which adds config2.
1230const _: () = assert!(core::mem::offset_of!(PerfEventAttr, type_) == 0);
1231const _: () = assert!(core::mem::offset_of!(PerfEventAttr, size) == 4);
1232const _: () = assert!(core::mem::offset_of!(PerfEventAttr, config) == 8);
1233const _: () = assert!(core::mem::offset_of!(PerfEventAttr, sample) == 16);
1234const _: () = assert!(core::mem::offset_of!(PerfEventAttr, sample_type) == 24);
1235const _: () = assert!(core::mem::offset_of!(PerfEventAttr, read_format) == 32);
1236const _: () = assert!(core::mem::offset_of!(PerfEventAttr, flags) == 40);
1237const _: () = assert!(core::mem::offset_of!(PerfEventAttr, wakeup) == 48);
1238const _: () = assert!(core::mem::offset_of!(PerfEventAttr, bp_type) == 52);
1239const _: () = assert!(core::mem::offset_of!(PerfEventAttr, config1) == 56);
1240const _: () = assert!(core::mem::offset_of!(PerfEventAttr, config2) == 64);
1241const _: () = assert!(core::mem::size_of::<PerfEventAttr>() == 72);
1242
1243// perf_event_attr flags bitfield (first 8 bits of `flags`).
1244const PERF_FLAG_DISABLED: u64 = 1 << 0;
1245const PERF_FLAG_INHERIT: u64 = 1 << 1;
1246const PERF_FLAG_EXCLUDE_KERNEL: u64 = 1 << 5;
1247const PERF_FLAG_EXCLUDE_HV: u64 = 1 << 6;
1248
1249const PERF_TYPE_HARDWARE: u32 = 0;
1250const PERF_COUNT_HW_CACHE_REFERENCES: u64 = 2;
1251const PERF_COUNT_HW_CACHE_MISSES: u64 = 3;
1252const PERF_COUNT_HW_BRANCH_INSTRUCTIONS: u64 = 4;
1253const PERF_COUNT_HW_BRANCH_MISSES: u64 = 5;

1255/// Perf events sampled per process, in `PerfSet::fds` order.
1256/// Index constants keep the array readable at use sites.
1257const PERF_EVENTS: [u64; PERF_EVENT_COUNT] = [
1258    PERF_COUNT_HW_CACHE_REFERENCES,
1259    PERF_COUNT_HW_CACHE_MISSES,
1260    PERF_COUNT_HW_BRANCH_INSTRUCTIONS,
1261    PERF_COUNT_HW_BRANCH_MISSES,
1262];
1263const PERF_EVENT_COUNT: usize = 4;
1264const IDX_CACHE_REFS: usize = 0;
1265const IDX_CACHE_MISSES: usize = 1;
1266const IDX_BRANCHES: usize = 2;
1267const IDX_BRANCH_MISSES: usize = 3;

1269/// `PERF_EVENT_IOC_ENABLE` — start a counter opened disabled.
1270/// `_IO('$', 0)` on the perf fd. Not exported by the libc crate.
1271const PERF_IOC_ENABLE: libc::c_ulong = 0x2400;
1272
1273/// Open one perf hardware counter for `pid`. Returns the fd, or
1274/// -1 if the event can't be opened (permissions, missing PMU
1275/// event, unsupported hardware).
1276fn perf_open(pid: u32, hw_config: u64) -> i32 {
1277    let attr = PerfEventAttr {
1278        type_: PERF_TYPE_HARDWARE,
1279        size: std::mem::size_of::<PerfEventAttr>() as u32,
1280        config: hw_config,
1281        sample: 0,
1282        sample_type: 0,
1283        read_format: 0,
1284        // Start disabled (enabled via ioctl below for a clean
1285        // baseline). Measure only its user-space execution —
1286        // kernel work done on its behalf (page faults, syscalls)
1287        // is a different signal class and including it would blur
1288        // the prediction-error measurement with OS noise.
1289        //
1290        // `inherit` makes the counters follow the thread group, not
1291        // just the calling thread. Without it the daemon's worker
1292        // threads are invisible, and these events are meant to
1293        // describe Genesis's own process tree.
1294        flags: PERF_FLAG_DISABLED
1295            | PERF_FLAG_EXCLUDE_KERNEL
1296            | PERF_FLAG_EXCLUDE_HV
1297            | PERF_FLAG_INHERIT,
1298        wakeup: 0,
1299        bp_type: 0,
1300        config1: 0,
1301        config2: 0,
1302    };
1303    // SAFETY: perf_event_open with a valid attr pointer, pid, and
1304    // no group (group_fd = -1). cpu = -1 means "whichever CPU the
1305    // process runs on" — correct for per-process counting. Either
1306    // returns a valid fd or -1; nothing leaks on failure.
1307    let fd = unsafe {
1308        libc::syscall(
1309            libc::SYS_perf_event_open,
1310            &attr,
1311            pid as libc::pid_t,
1312            -1,
1313            -1,
1314            0,
1315        ) as i32
1316    };
1317    if fd >= 0 {
1318        // SAFETY: fd is a valid perf event fd; ENABLE starts the
1319        // counter that was opened with disabled=1.
1320        unsafe { libc::ioctl(fd, PERF_IOC_ENABLE, 0) };
1321    }
1322    fd
1323}

1325impl PerfSet {
1326    /// Open the counter set for a process. Returns `None` if no
1327    /// counter could be opened at all (typically
1328    /// `perf_event_paranoid ≥ 4` blocking unprivileged access).
1329    fn open(pid: u32) -> Option<Self> {
1330        let mut fds = [-1i32; PERF_EVENT_COUNT];
1331        for (i, &config) in PERF_EVENTS.iter().enumerate() {
1332            fds[i] = perf_open(pid, config);
1333        }
1334        if fds.iter().all(|&fd| fd < 0) {
1335            return None;
1336        }
1337        Some(PerfSet { fds, prev: None })
1338    }
1339
1340    /// Read current counter values. Missing fds read as 0.
1341    fn read_counts(&self) -> [u64; PERF_EVENT_COUNT] {
1342        let mut out = [0u64; PERF_EVENT_COUNT];
1343        for (i, &fd) in self.fds.iter().enumerate() {
1344            if fd < 0 {
1345                continue;
1346            }
1347            // SAFETY: reading 8 bytes from a valid perf fd into a
1348            // u64 buffer. perf counters are read as u64 values
1349            // when PERF_FORMAT_* groups are unused.
1350            let n = unsafe { libc::read(fd, out[i..].as_mut_ptr() as *mut libc::c_void, 8) };
1351            if n != 8 {
1352                out[i] = 0;
1353            }
1354        }
1355        out
1356    }
1357
1358    /// Compute counter deltas since the last read. Returns `None`
1359    /// on the first sample (baseline establishment).
1360    fn deltas(&mut self) -> Option<[u64; PERF_EVENT_COUNT]> {
1361        let cur = self.read_counts();
1362        let prev = self.prev.replace(cur)?;
1363        let mut delta = [0u64; PERF_EVENT_COUNT];
1364        for i in 0..PERF_EVENT_COUNT {
1365            delta[i] = cur[i].saturating_sub(prev[i]);
1366        }
1367        Some(delta)
1368    }
1369}
1370
1371impl Drop for PerfSet {
1372    fn drop(&mut self) {
1373        for &fd in &self.fds {
1374            if fd >= 0 {
1375                // SAFETY: fd was opened by perf_event_open and is
1376                // closed exactly once here.
1377                unsafe { libc::close(fd) };
1378            }
1379        }
1380    }
1381}

1383/// Compute a miss ratio from a delta pair: `misses / total`.
1384/// Both are already the same units, so the ratio is naturally in
1385/// [0, 1]. Returns 0.0 when no events were counted (idle process
1386/// or missing denominator counter).
1387fn miss_ratio(misses: u64, total: u64) -> f32 {
1388    if total == 0 {
1389        return 0.0;
1390    }
1391    crate::state::sanitize::finite_clamp(misses as f32 / total as f32, 0.0, 1.0)
1392}

1519    /// Record which subsystems are alive, reporting any that just died.
1520    ///
1521    /// `genesis_subsystems` already filters out processes that are no
1522    /// longer running, which is correct for measurement but loses the
1523    /// fact that they were ever there. This keeps the transition: a
1524    /// subsystem that was alive on the previous read and is gone now
1525    /// increments the death count and is reported once, so a crashed
1526    /// organ is a visible event rather than a silently shorter list.
1527    ///
1528    /// A subsystem that has never been seen alive is not counted as a
1529    /// death — it was never running, which is a different fact.
1530    ///
1531    /// The death count is a floor, not a census: a process that dies
1532    /// and is restarted entirely within one read interval looks alive
1533    /// on both sides, so the flap is invisible here. The PID in the
1534    /// telemetry record is what exposes it — a consumer that remembers
1535    /// the PID sees it change even when `deaths` does not move.
1536    fn reap_dead_subsystems(&mut self, present: &[(Subsystem, u32)]) -> Vec<(Subsystem, u32)> {
1537        let mut health = read_process_health();
1538        let mut alive_mask = 0u16;
1539        let mut next: Vec<(Subsystem, u32)> = Vec::with_capacity(present.len());
1540
1541        for &(subsystem, pid) in present {
1542            if !pid_alive(pid) {
1543                continue;
1544            }
1545            alive_mask |= 1u16 << subsystem.to_wire() as u16;
1546            next.push((subsystem, pid));
1547        }
1548
1549        // Anything that was alive and now is not.
1550        let newly_dead = health.alive_mask & !alive_mask;
1551        if newly_dead != 0 {
1552            for tag in 0u8..=2 {
1553                let bit = 1u16 << tag;
1554                if newly_dead & bit != 0 {
1555                    health.deaths = health.deaths.saturating_add(1);
1556                    health.last_death = tag;
1557                    let name = match tag {
1558                        1 => "cognitive mind",
1559                        2 => "retina",
1560                        _ => "daemon",
1561                    };
1562                    // A lost subsystem is a real event, not a debug
1563                    // detail: it changes what the telemetry means.
1564                    eprintln!("[interoception] subsystem lost: {name} is no longer running");
1565                }
1566            }
1567        }
1568        health.alive_mask = alive_mask;
1569        publish_process_health(health);
1570        next
1571    }

1596            mask |= sensor::FREQUENCY;

1599            mask |= sensor::MAX_FREQUENCY;
1600        }
1601        if probe.battery_path.is_some() {
1602            mask |= sensor::BATTERY;
1603        }
1604        if probe.ac_path.is_some() {
1605            mask |= sensor::AC_ADAPTER;
1606        }
1607        if probe.fan_path.is_some() {
1608            mask |= sensor::FAN;
1609        }
1610        if !probe.power_paths.is_empty() || probe.rapl_power_domain {
1611            mask |= sensor::POWER;
1612        }

1615        }

1617            mask |= sensor::SUPPLY_VOLTAGE;
1618        }
1619        if !probe.rapl_domains.is_empty() {
1620            mask |= sensor::RAPL;
1621        }
1622        if probe.total_memory_kb > 0 {
1623            mask |= sensor::MEMORY;
1624        }

1626        // kernels built with PSI, and the EC GPE counter only on
1627        // machines with an embedded controller.
1628        if std::path::Path::new("/proc/pressure/cpu").exists() {

1641        // the busy-wait POLL state cannot measure rest.
1642        if probe.cpuidle_max_depth > 0
1643            && probe.cpuidle_states.iter().flatten().any(|s| s.weight > 0)
1644        {

1646        }

1700    /// Read the current body state from hardware sensors.
1701    ///
1702    /// This is the main entry point, called periodically from the
1703    /// daemon tick loop. It reads all available sensors and produces
1704    /// a normalized `BodyState`.
1705    ///
1706    /// **Body-state signals** (temperature, battery) are read from
1707    /// global hardware sensors — they reflect the physical state of
1708    /// its body regardless of which process caused them.
1709    /// **Activity signals** (CPU load, memory, I/O) are read from
1710    /// Genesis's own process tree only — other programs using the
1711    /// machine don't make it stressed, overwhelmed, or drowsy.
1712    pub fn read(&mut self) -> BodyState {
1713        // Capture a single timestamp for all process-specific
1714        // measurements (CPU, I/O) so the elapsed-time denominator
1715        // matches the /proc counter delta interval. Without this,
1716        // each helper captures its own Instant::now() at slightly
1717        // different times, and self.last_read (set at the end of
1718        // the previous read()) doesn't align with when the previous
1719        // /proc samples were actually taken.
1720        let now = Instant::now();
1721
1722        // Temperature — global body-state signal.
1723        // finite_clamp guards against NaN/inf from a corrupted sysfs
1724        // sensor file (f32::parse("NaN") succeeds). Without this, NaN
1725        // propagates into cpu_temp_c, making every comparison (>= 85.0,
1726        // > 65.0, < 60.0, < 45.0) return false — silently disabling all
1727        // thermal stress responses and the distress flag. The companion
1728        // `temperature` field is already clamped via normalize_temp, but
1729        // the raw `cpu_temp_c` used in distress checks and neuro_impulses
1730        // is not. 0–150°C covers all realistic CPU temperatures.
1731        let mut temp_valid = false;
1732        let cpu_temp_c = match read_temp(&self.temp_path) {
1733            Some(t) => {
1734                self.temp_warned = false; // sensor recovered, reset flag
1735                // finite_clamp returns `min` (0.0 °C) for non-finite
1736                // values, which would silently disable all thermal
1737                // stress responses. A corrupt sysfs read (f32::parse
1738                // accepts "NaN") must fall back to the neutral 50.0 °C,
1739                // not a freezing false negative.
1740                if t.is_finite() {
1741                    temp_valid = true;
1742                    crate::state::sanitize::finite_clamp(t, 0.0, 150.0)
1743                } else {
1744                    50.0
1745                }
1746            }
1747            None => {
1748                // Warn once per sensor-loss episode; a permanently
1749                // missing sensor would spam the log every read cycle
1750                // otherwise. The 50.0°C default is a neutral "no
1751                // fever" fallback.
1752                if !self.temp_warned {
1753                    eprintln!(
1754                        "[interoception] WARNING: could not read CPU temperature from {}, \
1755                         defaulting to 50.0°C (further failures suppressed)",
1756                        self.temp_path
1757                    );
1758                    self.temp_warned = true;
1759                }
1760                50.0
1761            }
1762        };
1763        let temperature = normalize_temp(cpu_temp_c);
1764
1765        // CPU frequency (average across cores) — global body-state signal.
1766        // On heterogeneous CPUs (e.g. Intel P/E cores), a core's cur_freq
1767        // can exceed the cpu0 max_freq_khz, producing values > 1.0. Clamp
1768        // to the documented [0, 1] range so internal consumers (IPC,
1769        // emotional_regulator) never see out-of-range values.
1770        let avg_freq = self.read_avg_freq();
1771        // Do not manufacture a neutral frequency when the hardware sensor
1772        // is unavailable. A fabricated 0.5 would look like measured
1773        // medium arousal and could drive downstream regulation. The public
1774        // contract already defines 0.0 as "not available".
1775        let arousal_freq = if self.max_freq_khz > 0 && avg_freq > 0 {
1776            crate::state::sanitize::finite_clamp(
1777                (avg_freq as f32) / (self.max_freq_khz as f32),
1778                0.0,
1779                1.0,
1780            )
1781        } else {
1782            0.0
1783        };
1784
1785        // Collect Genesis's own process tree, tagged by subsystem.
1786        // Per-subsystem telemetry (which part of it is firing) is
1787        // derived from the same per-PID deltas that feed the
1788        // aggregate signals below.
1789        let all_subsystems = self.genesis_subsystems();
1790        let subsystems = self.reap_dead_subsystems(&all_subsystems);
1791        let pids: Vec<u32> = subsystems.iter().map(|&(_, pid)| pid).collect();
1792
1793        // Self-process memory (RSS) → cognitive load, plus the absolute
1794        // megabyte figure the manifest's memory fields are missing.
1795        let (cognitive_load, self_memory_mb) = self.read_self_memory_detail(&pids);
1796
1797        // Self-process CPU usage → stress_load.
1798        let stress_load = self.read_self_cpu(&pids, now);
1799
1800        // Self-process I/O throughput → io_activity (data exchange).
1801        let io_activity = self.read_self_io(&pids, now);
1802
1803        // Battery and power — global body-state signals.
1804        let (energy_reserve, on_ac_power) = self.read_power();
1805
1806        // Hardware notification rate — GPE events from the Embedded
1807        // Controller. The rate is informational; regularity is normal
1808        // and does not produce stress impulses.
1809        let gpe_count = read_gpe_count();
1810        let elapsed_secs = now.duration_since(self.last_read).as_secs_f64();
1811        let autonomic_rate = if elapsed_secs > 0.0 && self.prev_gpe_count > 0 {
1812            let delta = gpe_count.saturating_sub(self.prev_gpe_count);
1813            crate::state::sanitize::finite_clamp((delta as f32) / (elapsed_secs as f32), 0.0, 100.0)
1814        } else {
1815            0.0
1816        };
1817        self.prev_gpe_count = gpe_count;
1818
1819        // Thermoregulatory effort: fan speed (how hard the cooling
1820        // system is working to remove waste heat).
1821        let thermoregulatory_effort = self
1822            .fan_path
1823            .as_ref()
1824            .and_then(|p| read_fan_pwm(p))
1825            .unwrap_or(0.0);
1826
1827        // Energy-use telemetry: power draw. Instantaneous sensors
1828        // first — AMD fam15h_power, then battery power_now. When
1829        // every instantaneous path reports zero (a full battery on
1830        // AC is an honest zero while the machine still draws wall
1831        // power), fall back to the whole-platform RAPL counter
1832        // differentiated over the read window. 0.0 if no sensor.
1833        let metabolic_rate = read_power_draw_any(&self.power_paths)
1834            .or_else(|| self.read_rapl_power(now))
1835            .unwrap_or(0.0);
1836
1837        // Core voltage (Vcore) — the CPU's operating voltage. On
1838        // acpi-cpufreq systems, the SMU controls this internally per
1839        // P-state and does not expose it via sysfs, so this reads
1840        // 0.0. On systems with board-level voltage sensors (nct6776,
1841        // it87, etc.), this is the actual Vcore rail.
1842        let core_voltage = self
1843            .core_voltage_path
1844            .as_ref()
1845            .and_then(|p| read_voltage(p))
1846            .unwrap_or(0.0);
1847
1848        // Supply voltage — the battery rail voltage. This is the
1849        // electrical potential of its energy reserve. A Li-ion
1850        // battery sags from ~12.6V (full) to ~10.5V (critically
1851        // low) on a 12V system. 0.0 on systems without a battery.
1852        let supply_voltage = self
1853            .supply_voltage_path
1854            .as_ref()
1855            .and_then(|p| read_voltage(p))
1856            .unwrap_or(0.0);
1857
1858        // Silicon switching activity — RAPL per-domain energy
1859        // deltas. This is the spatial readout of transistor firing:
1860        // which silicon (cores, uncore fabric, DRAM) burned energy
1861        // since the last read. Global body-state signal — energy
1862        // isn't attributed per-process, like temperature.
1863        let (core_activity, uncore_activity, dram_activity) = self.read_rapl(now);
1864
1865        // Perf counters on its own process tree.
1866        let (cache_miss_rate, branch_miss_rate) = self.read_perf(&pids);
1867
1868        // Local-timer interrupts per second. Each core's Local APIC
1869        // timer fires the kernel's scheduler tick; under tickless
1870        // idle an idle core's timer pauses entirely, so a quiet
1871        // machine has a low rate and a working machine a high one.
1872        // The signal is generated by timer hardware and the scheduler.
1873        let loc_total = read_loc_count();
1874        let pulse_hz = if elapsed_secs > 0.0 && self.prev_loc_count > 0 {
1875            let delta = loc_total.saturating_sub(self.prev_loc_count);
1876            crate::state::sanitize::finite_clamp(
1877                (delta as f32) / (elapsed_secs as f32),
1878                0.0,
1879                1_000_000.0,
1880            )
1881        } else {
1882            0.0
1883        };
1884        self.prev_loc_count = loc_total;
1885        let pulse = crate::state::sanitize::finite_clamp(
1886            pulse_hz / (self.num_cores as f32 * TICK_HZ),
1887            0.0,
1888            1.0,
1889        );
1890
1891        // Sustained exertion — the share of the read window spent
1892        // at the maximum P-state, from cpufreq time_in_state
1893        // deltas. arousal_freq is this instant's speed; this is how
1894        // much of the recent past ran flat-out.
1895        let (tis_top, tis_all) = read_time_in_state();
1896        let top_freq_share = if self.prev_tis_all > 0 {
1897            let d_top = tis_top.saturating_sub(self.prev_tis_top) as f32;
1898            let d_all = tis_all.saturating_sub(self.prev_tis_all) as f32;
1899            if d_all > 0.0 {
1900                crate::state::sanitize::finite_clamp(d_top / d_all, 0.0, 1.0)
1901            } else {
1902                0.0
1903            }
1904        } else {
1905            0.0
1906        };
1907        self.prev_tis_top = tis_top;
1908        self.prev_tis_all = tis_all;
1909
1910        // Involuntary layer — reflexes the body applies to it,
1911        // not actions it takes. Passive thermal throttle is the
1912        // cooling framework lowering its clock below the OS
1913        // scheduler; PSI stall metrics are the kernel's own
1914        // accounting of runnable work stuck waiting on a resource.
1915        let throttle_state = read_throttle_state();
1916        let psi_cpu = read_psi("cpu");
1917        let psi_io = read_psi("io");
1918        let psi_mem = read_psi("memory");
1919
1920        // Senescence and entropy — body resources. The battery's
1921        // cycle count is a lifetime odometer; the entropy pool is
1922        // the machine's reservoir of hardware unpredictability.
1923        let battery_cycles = read_battery_cycles();
1924        let entropy_level = read_entropy_level();
1925
1926        // Measured low-power residency — rest, not merely the absence
1927        // of strain. Depth-weighted cpuidle residency: a core parked
1928        // in a real C-state is positive evidence of rest. Busy-wait
1929        // POLL residency and running time contribute nothing.
1930        let rest = self.read_cpuidle_rest(elapsed_secs);
1931
1932        // Temperature trend — which way the body is moving, not where
1933        // it is. Deviation of cpu_temp_c from its own ~60 s EMA, ±5 °C
1934        // saturating. Only real sensor reads feed the baseline: the
1935        // 50.0 fallback converging on a missing or glitching sensor
1936        // would fabricate recovery/heating swings.
1937        let temp_trend = if temp_valid {
1938            self.update_temp_ema(cpu_temp_c, elapsed_secs)
1939        } else {
1940            0.0
1941        };
1942
1943        let distressed = cpu_temp_c >= 85.0
1944            || cognitive_load > 0.92
1945            || stress_load > 1.5
1946            || (!on_ac_power && energy_reserve < 0.05);
1947
1948        let state = BodyState {
1949            cpu_temp_c,
1950            temperature,
1951            arousal_freq,
1952            cognitive_load,
1953            io_activity,
1954            stress_load,
1955            energy_reserve,
1956            on_ac_power,
1957            num_cores: self.num_cores,
1958            distressed,
1959            autonomic_rate,
1960            thermoregulatory_effort,
1961            metabolic_rate,
1962            core_voltage,
1963            supply_voltage,
1964            core_activity,
1965            uncore_activity,
1966            dram_activity,
1967            cache_miss_rate,
1968            branch_miss_rate,
1969            pulse_hz,
1970            pulse,
1971            throttle_state,
1972            top_freq_share,
1973            psi_cpu,
1974            psi_io,
1975            psi_mem,
1976            battery_cycles,
1977            entropy_level,
1978            clocksource: self.clocksource_id,
1979            suspend_caps: self.suspend_caps,
1980            rest,
1981            temp_trend,
1982            description: String::new(),
1983        };
1984        // ── Per-subsystem telemetry ──
1985        // Which part of it is firing: each process's share of the
1986        // aggregate activity signals plus its own prediction-error
1987        // ratios. Published alongside the body state so the
1988        // cognitive mind can correlate subsystems with its task zone.
1989        let telemetry: Vec<SubsystemTelemetry> = subsystems
1990            .iter()
1991            .map(|&(subsystem, pid)| {
1992                let delta = self
1993                    .subsystem_perf_delta
1994                    .get(&pid)
1995                    .copied()
1996                    .unwrap_or([0; 4]);
1997                SubsystemTelemetry {
1998                    subsystem,
1999                    pid,
2000                    cpu: self.subsystem_cpu.get(&pid).copied().unwrap_or(0.0),
2001                    io: self.subsystem_io.get(&pid).copied().unwrap_or(0.0),
2002                    cache_miss_rate: miss_ratio(delta[IDX_CACHE_MISSES], delta[IDX_CACHE_REFS]),
2003                    branch_miss_rate: miss_ratio(delta[IDX_BRANCH_MISSES], delta[IDX_BRANCHES]),

2005            })

2009        // shares. The manifest's `mem_usage_mb` and `total_mem_mb` had
2010        // no producer, so a process tree holding hundreds of megabytes
2011        // reported zero in the one field that names memory in absolute
2012        // terms.
2013        self.publish_memory_mb(self_memory_mb);

2016        // is settled by now — `read_perf` has either opened the
2017        // counters or marked them permanently unavailable — so it is
2018        // the one bit that can differ from the startup discovery.
2019        if self.perf_unavailable {
2020            self.sensor_mask &= !crate::daemon::interoception::sensor::PERF_COUNTERS;
2021        } else if !self.subsystem_perf_delta.is_empty() {
2022            self.sensor_mask |= crate::daemon::interoception::sensor::PERF_COUNTERS;
2023        }
2024        publish_sensor_presence(self.sensor_mask);

2052    fn read_self_memory_detail(&self, pids: &[u32]) -> (f32, f32) {
2053        if self.total_memory_kb == 0 {
2054            return (0.0, 0.0);
2055        }
2056        let total_rss_kb: u64 = pids.iter().map(|pid| rss_kb(*pid)).sum();
2057        // Compute in f64: u64-as-f32 loses integer precision above 2^24
2058        // (~16.7M kB ≈ 16 GiB), so hosts with large RAM would quantize
2059        // both operands before dividing.
2060        let fraction = (total_rss_kb as f64) / (self.total_memory_kb as f64);
2061        let mb = (total_rss_kb as f64) / 1024.0;
2062        (
2063            crate::state::sanitize::finite_clamp(fraction as f32, 0.0, 1.0),
2064            crate::state::sanitize::finite_or(mb as f32, 0.0),
2065        )
2066    }

2068    /// Read combined CPU usage of Genesis's own process tree as a
2069    /// fraction of its CPU capacity (num_cores).
2070    ///
2071    /// Computes the delta of utime + stime (in clock ticks) across
2072    /// all its processes since the last read, divided by the elapsed
2073    /// time in clock ticks × num_cores. Returns 0.0 on the first
2074    /// read (no previous baseline). Other programs' CPU usage is
2075    /// not included — only its own effort.
2076    fn read_self_cpu(&mut self, pids: &[u32], now: Instant) -> f32 {
2077        let elapsed_secs = now.duration_since(self.last_read).as_secs_f64();
2078        if elapsed_secs <= 0.0 {
2079            return 0.0;
2080        }
2081
2082        let ticks_per_sec = sysconf_clk_tck();
2083        let total_ticks_available = elapsed_secs * (self.num_cores as f64) * (ticks_per_sec as f64);
2084        if total_ticks_available <= 0.0 {
2085            return 0.0;
2086        }
2087
2088        let mut total_cpu_ticks: u64 = 0;
2089        let mut new_prev: std::collections::HashMap<u32, u64> = std::collections::HashMap::new();
2090        let mut subsystem_cpu: std::collections::HashMap<u32, f32> =
2091            std::collections::HashMap::new();
2092
2093        for &pid in pids {
2094            let path = format!("/proc/{pid}/stat");
2095            let Ok(content) = fs::read_to_string(&path) else {
2096                // Process may have died between collection and read.
2097                continue;
2098            };
2099            let Some(stat) = ProcStat::parse(&content) else {
2100                continue;
2101            };
2102            let cpu_ticks = stat.cpu_ticks();
2103            if let Some(&prev) = self.prev_proc_cpu.get(&pid) {
2104                let delta = cpu_ticks.saturating_sub(prev);
2105                total_cpu_ticks = total_cpu_ticks.saturating_add(delta);
2106                // Per-subsystem share on the same denominator as the
2107                // aggregate — the sum of per-subsystem fractions equals
2108                // stress_load (before the [0,2] clamp).
2109                subsystem_cpu.insert(
2110                    pid,
2111                    crate::state::sanitize::finite_clamp(
2112                        (delta as f64 / total_ticks_available) as f32,
2113                        0.0,
2114                        2.0,
2115                    ),
2116                );
2117            }
2118            new_prev.insert(pid, cpu_ticks);
2119        }
2120
2121        // PIDs that were alive last time but are gone now: their CPU
2122        // delta is lost (they did work we can't account for), which
2123        // is fine — we just don't count it.
2124        self.prev_proc_cpu = new_prev;
2125        self.subsystem_cpu = subsystem_cpu;
2126
2127        let fraction = (total_cpu_ticks as f64) / total_ticks_available;
2128        crate::state::sanitize::finite_clamp(fraction as f32, 0.0, 2.0)
2129    }

2131    /// Read combined I/O throughput of Genesis's own process tree,
2132    /// normalized to [0, 1].
2133    ///
2134    /// Computes the delta of rchar + wchar (in bytes) across all its
2135    /// processes since the last read, converts to a rate (bytes/sec),
2136    /// and normalizes against a reference rate of 50 MB/s (a
2137    /// reasonable sustained I/O rate for a mix of cached and uncached
2138    /// reads/writes). Returns 0.0 on the first read. Other programs'
2139    /// I/O is not included — only its own disk/network activity.
2140    fn read_self_io(&mut self, pids: &[u32], now: Instant) -> f32 {
2141        let elapsed_secs = now.duration_since(self.last_read).as_secs_f64();
2142        if elapsed_secs <= 0.0 {
2143            return 0.0;
2144        }
2145
2146        // Reference: 50 MB/s sustained I/O = "heavy" for its workload.
2147        // The daemon's LTM sync and eye-limb frame writes, and the
2148        // cognitive mind's concept network loads, are the main I/O
2149        // sources. This normalizes them to a sensible [0, 1] range.
2150        const REFERENCE_BYTES_PER_SEC: f64 = 50.0 * 1024.0 * 1024.0;
2151
2152        let mut total_io_bytes: u64 = 0;
2153        let mut new_prev: std::collections::HashMap<u32, u64> = std::collections::HashMap::new();
2154        let mut subsystem_io: std::collections::HashMap<u32, f32> =
2155            std::collections::HashMap::new();
2156
2157        for &pid in pids {
2158            let path = format!("/proc/{pid}/io");
2159            let Ok(content) = fs::read_to_string(&path) else {
2160                // /proc/<pid>/io requires read permission; if we can't
2161                // read it (e.g. the cognitive mind runs as a different
2162                // user), skip it silently.
2163                continue;
2164            };
2165            let Some(io) = ProcIo::parse(&content) else {
2166                continue;
2167            };
2168            let total = io.total_bytes();
2169            if let Some(&prev) = self.prev_proc_io.get(&pid) {
2170                let delta = total.saturating_sub(prev);
2171                total_io_bytes = total_io_bytes.saturating_add(delta);
2172                // Per-subsystem share on the io_activity scale.
2173                subsystem_io.insert(
2174                    pid,
2175                    crate::state::sanitize::finite_clamp(
2176                        (delta as f64 / elapsed_secs / REFERENCE_BYTES_PER_SEC) as f32,
2177                        0.0,
2178                        1.0,
2179                    ),
2180                );
2181            }
2182            new_prev.insert(pid, total);
2183        }
2184
2185        self.prev_proc_io = new_prev;
2186        self.subsystem_io = subsystem_io;
2187
2188        let bytes_per_sec = (total_io_bytes as f64) / elapsed_secs;
2189        let fraction = bytes_per_sec / REFERENCE_BYTES_PER_SEC;
2190        crate::state::sanitize::finite_clamp(fraction as f32, 0.0, 1.0)
2191    }

2193    /// Read RAPL per-domain switching activity.
2194    ///
2195    /// Returns `(core_activity, uncore_activity, dram_activity)`,
2196    /// each normalized to [0, 1] against a per-domain reference
2197    /// power. The energy counters are cumulative µJ; the delta per
2198    /// elapsed second is the domain's average power — which, since
2199    /// CMOS dynamic power is proportional to switching activity,
2200    /// is a population-level readout of how hard that silicon's
2201    /// transistors are firing.
2202    ///
2203    /// These are body-state signals: RAPL domains measure the whole
2204    /// package, not per-process energy. Other programs' switching
2205    /// contributes, the same way a fever counts regardless of cause.
2206    /// All zeros on systems without a powercap driver (this AMD
2207    /// Kabini has none — the fields stay 0.0 and produce no
2208    /// impulses, matching every other absent-sensor path here).
2209    fn read_rapl(&mut self, now: Instant) -> (f32, f32, f32) {
2210        if self.rapl_domains.is_empty() {
2211            return (0.0, 0.0, 0.0);
2212        }
2213        let elapsed_secs = now.duration_since(self.last_read).as_secs_f64();
2214        if elapsed_secs <= 0.0 {
2215            return (0.0, 0.0, 0.0);
2216        }
2217
2218        // Reference powers (µW → normalized 1.0). Typical laptop
2219        // values: cores can reach ~45W package-limited under AVX
2220        // load; uncore fabric ~8W; DRAM ~4W sustained.
2221        const CORE_REF_UW: f64 = 45_000_000.0;
2222        const UNCORE_REF_UW: f64 = 8_000_000.0;
2223        const DRAM_REF_UW: f64 = 4_000_000.0;
2224
2225        let mut core = 0.0f32;
2226        let mut uncore = 0.0f32;
2227        let mut dram = 0.0f32;
2228
2229        for domain in &mut self.rapl_domains {
2230            let Ok(content) = fs::read_to_string(&domain.energy_path) else {
2231                continue;
2232            };

2234                continue;
2235            };
2236            let Some(prev) = domain.prev_uj.replace(cur) else {
2237                continue; // first read — establish baseline
2238            };

2240            let power_uw = (delta_uj as f64) / elapsed_secs;
2241            let (value, reference) = match domain.kind {
2242                RaplKind::Core => (&mut core, CORE_REF_UW),
2243                RaplKind::Uncore => (&mut uncore, UNCORE_REF_UW),
2244                RaplKind::Dram => (&mut dram, DRAM_REF_UW),
2245                // Whole-platform domains live in `power_domain`,
2246                // never in `rapl_domains` — unreachable in practice.
2247                RaplKind::Package => continue,
2248            };
2249            // Multiple packages: sum normalized activity and clamp.
2250            *value += crate::state::sanitize::finite_clamp((power_uw / reference) as f32, 0.0, 1.0);
2251        }
2252
2253        (
2254            crate::state::sanitize::finite_clamp(core, 0.0, 1.0),
2255            crate::state::sanitize::finite_clamp(uncore, 0.0, 1.0),
2256            crate::state::sanitize::finite_clamp(dram, 0.0, 1.0),
2257        )
2258    }

2291    /// Depth-weighted cpuidle residency over the read window — the
2292    /// `rest` channel.
2293    ///
2294    /// For each core, each state's residency delta divided by the
2295    /// window is that state's share (states are mutually exclusive,
2296    /// so the shares sum to the core's idle fraction). The rest
2297    /// score is the depth-weighted mean across cores: fully parked
2298    /// in the deepest C-state scores 1.0; busy-wait POLL residency
2299    /// and running time score 0. 0.0 when no cpuidle telemetry
2300    /// exists — the CPUIDLE presence bit stays clear there.
2301    fn read_cpuidle_rest(&mut self, elapsed_secs: f64) -> f32 {
2302        if self.cpuidle_states.is_empty() || self.cpuidle_max_depth == 0 {
2303            return 0.0;
2304        }
2305        let window_us = (elapsed_secs * 1_000_000.0).max(1.0);
2306        let prev = &mut self.prev_cpuidle_us;
2307        let mut total = 0.0f64;
2308        let mut cores = 0u32;
2309        for (core_idx, states) in self.cpuidle_states.iter().enumerate() {
2310            if states.is_empty() {
2311                continue;
2312            }
2313            let mut core_score = 0.0f64;
2314            for (state_idx, state) in states.iter().enumerate() {
2315                let now_us = read_u64(&state.time_path);
2316                let cell = prev.get_mut(core_idx).and_then(|c| c.get_mut(state_idx));
2317                let base = cell.as_deref().copied().unwrap_or(0);
2318                if let Some(c) = cell {
2319                    *c = now_us;
2320                }
2321                let share = (now_us.saturating_sub(base) as f64 / window_us).clamp(0.0, 1.0);
2322                core_score += state.weight as f64 * share;
2323            }
2324            total += core_score / self.cpuidle_max_depth as f64;
2325            cores += 1;
2326        }
2327        if cores == 0 {
2328            return 0.0;
2329        }
2330        crate::state::sanitize::finite_clamp((total / cores as f64) as f32, 0.0, 1.0)
2331    }

2360    /// Read microarchitectural prediction-error ratios for
2361    /// Genesis's process tree.
2362    ///
2363    /// Returns `(cache_miss_rate, branch_miss_rate)` — the deltas
2364    /// of `cache-misses/cache-references` and
2365    /// `branch-misses/branch-instructions` summed across its
2366    /// processes since the last read. Both are naturally ratios in
2367    /// [0, 1]: what fraction of the silicon's predictions failed.
2368    ///
2369    /// Counter sets are opened lazily per PID and closed when the
2370    /// PID dies. If the first `perf_event_open` fails for every
2371    /// event (paranoid ≥ 4, no PMU, container seccomp), the
2372    /// sampler disables itself permanently — retrying every read
2373    /// would just burn syscalls.
2374    fn read_perf(&mut self, pids: &[u32]) -> (f32, f32) {
2375        if self.perf_unavailable {
2376            return (0.0, 0.0);
2377        }
2378
2379        // Open sets for new PIDs; drop sets for dead PIDs (the
2380        // Drop impl closes the fds).
2381        for &pid in pids {
2382            if !self.perf_counters.contains_key(&pid)
2383                && let Some(set) = PerfSet::open(pid)
2384            {
2385                self.perf_counters.insert(pid, set);
2386            }
2387        }
2388        if self.perf_counters.is_empty() {
2389            // Nothing could be opened — treat as permanently
2390            // unavailable. This machine's paranoid level or PMU
2391            // doesn't allow it; don't retry every cycle.
2392            self.perf_unavailable = true;
2393            return (0.0, 0.0);
2394        }
2395        self.perf_counters.retain(|pid, _| pids.contains(pid));
2396
2397        // Sum deltas across the process tree, then form ratios
2398        // from the summed counts (correct: a process with no
2399        // references contributes nothing to either side). Per-PID
2400        // deltas are stashed for per-subsystem telemetry.
2401        let mut totals = [0u64; PERF_EVENT_COUNT];
2402        let mut sampled = false;
2403        let mut subsystem_delta: std::collections::HashMap<u32, [u64; PERF_EVENT_COUNT]> =
2404            std::collections::HashMap::new();
2405        for (&pid, set) in self.perf_counters.iter_mut() {
2406            if let Some(delta) = set.deltas() {
2407                for i in 0..PERF_EVENT_COUNT {
2408                    totals[i] = totals[i].saturating_add(delta[i]);
2409                }
2410                subsystem_delta.insert(pid, delta);
2411                sampled = true;
2412            }
2413        }
2414        self.subsystem_perf_delta = subsystem_delta;
2415        if !sampled {
2416            // First read for all sets — baselines established.
2417            return (0.0, 0.0);
2418        }
2419
2420        (
2421            miss_ratio(totals[IDX_CACHE_MISSES], totals[IDX_CACHE_REFS]),
2422            miss_ratio(totals[IDX_BRANCH_MISSES], totals[IDX_BRANCHES]),
2423        )
2424    }

2426    /// Compute neurochemical impulses from the body state.
2427    ///
2428    /// Returns a list of (chemical_id, impulse_magnitude) pairs.
2429    /// No magnitude here is a fixed constant: each offered rate is
2430    /// re-scaled at call time by the organism's *live* level of the
2431    /// very chemical it targets — `Self::self_scaled`. A positive
2432    /// impulse fades as the level nears its ceiling (autoreceptor-
2433    /// style saturation); a negative impulse fades as the level
2434    /// nears its floor (there is no tone to withdraw). The values
2435    /// therefore set themselves from Genesis's own state on every
2436    /// call; `apply_impulse` remains the hard bound.
2437    ///
2438    /// Positive values increase the chemical, negative values
2439    /// decrease it. All values are in the same units as
2440    /// `neuro_impulse` in the IPC protocol.
2441    ///
2442    /// This is the brainstem-level afferent reflex (NTS/parabrachial
2443    /// → autonomic loop): it runs on the body alone when the mind's
2444    /// lease is expired. When the lease is held the same BodyState
2445    /// reaches the mind's brainstem relay, which routes it through
2446    /// the proper regions and authors the response there.
2447    pub fn neuro_impulses(
2448        &self,
2449        body: &BodyState,
2450        neuro: &NeurochemicalVector,
2451    ) -> Vec<(NeurochemicalId, f32)> {
2452        let mut impulses = Vec::new();
2453
2454        // Temperature → CRH (heat stress, routed through HPA cascade)
2455        // Stress impulses go to CRH (the top of the HPA axis), not
2456        // directly to cortisol. This engages the full CRH→ACTH→cortisol
2457        // cascade, which respects maturation gating (the SHRP — stress
2458        // hyporesponsive period — keeps cortisol at zero during early
2459        // development). Direct cortisol injection bypasses this gating.
2460        // Normal: 40-65°C → no impulse
2461        // Warm: 65-75°C → small CRH
2462        // Hot: 75-85°C → moderate CRH
2463        // Critical: 85°C+ → strong CRH (distress)
2464        if body.cpu_temp_c > 65.0 {
2465            let intensity = crate::state::sanitize::finite_or((body.cpu_temp_c - 65.0) / 20.0, 0.0);
2466            let crh = 0.002 + intensity * 0.008;
2467            impulses.push((NeurochemicalId::CRH, crh));
2468        }
2469
2470        // Load average → norepinephrine (effort)
2471        // Above 0.5 load per core, it's working. Above 1.0, it's
2472        // struggling. This is not stress — it's effort. The
2473        // difference: effort is sustainable, stress is not.
2474        if body.stress_load > 0.5 && body.stress_load <= 1.0 {
2475            let intensity = crate::state::sanitize::finite_or((body.stress_load - 0.5) / 0.5, 0.0);
2476            impulses.push((NeurochemicalId::Norepinephrine, intensity * 0.003));
2477        }
2478        // Above 1.0 load per core → CRH (actual stress, via HPA cascade)
2479        if body.stress_load > 1.0 {
2480            let intensity = crate::state::sanitize::finite_or((body.stress_load - 1.0) / 0.5, 0.0);
2481            impulses.push((NeurochemicalId::CRH, intensity * 0.006));
2482            impulses.push((NeurochemicalId::Norepinephrine, intensity * 0.004));
2483        }
2484
2485        // Low energy reserve → CRH (energy stress via HPA cascade)
2486        if !body.on_ac_power && body.energy_reserve < 0.30 {
2487            let intensity =
2488                crate::state::sanitize::finite_or((0.30 - body.energy_reserve) / 0.30, 0.0);
2489            impulses.push((NeurochemicalId::CRH, intensity * 0.004));
2490        }
2491
2492        // Measured deep rest withdraws arousal-system tone. LC/NE,
2493        // orexin, and histamine are wake-stabilizing systems whose
2494        // activity falls outside waking; rest is an active state, not
2495        // merely the absence of strain. Gated on CPUIDLE telemetry:
2496        // absence of the measurement is not evidence of rest.
2497        if self.sensor_mask & sensor::CPUIDLE != 0 && body.rest > 0.7 {
2498            impulses.push((NeurochemicalId::Norepinephrine, -0.002));
2499            impulses.push((NeurochemicalId::Orexin, -0.001));
2500            impulses.push((NeurochemicalId::Histamine, -0.001));
2501        }
2502
2503        // ─── Thermoregulatory effort (fan) ───────────────────────
2504        //
2505        // High fan + high temp → the cooling system is working hard
2506        //   but the body is still hot. Modeled as: CRH (thermal strain).
2507        //
2508        // Fan off + high temp → cooling failure. The body is hot but
2509        //   the cooling response is absent. Modeled as: CRH.
2510        //
2511        // High fan + low temp → no impulse. This is normal operation.
2512
2513        // Fan struggling: high fan + high temp → thermal strain.
2514        if self.fan_path.is_some() && body.thermoregulatory_effort > 0.3 && body.cpu_temp_c > 75.0 {
2515            let fan_intensity =
2516                crate::state::sanitize::finite_or((body.thermoregulatory_effort - 0.3) / 0.7, 0.0);
2517            let temp_intensity =
2518                crate::state::sanitize::finite_or((body.cpu_temp_c - 75.0) / 15.0, 0.0);
2519            let intensity = fan_intensity.min(temp_intensity);
2520            impulses.push((NeurochemicalId::CRH, intensity * 0.004));
2521        }
2522
2523        // Cooling failure: fan off + high temp → dangerous.
2524        // The body is hot but the cooling system isn't responding.
2525        // Gated on `fan_path.is_some()`, not just the reading. With no
2526        // fan sensor the effort field is 0.0 by convention, which is
2527        // indistinguishable from "fan stopped" — so a machine with no
2528        // fan telemetry at all would fabricate a cooling-failure
2529        // response to any excursion above 80 °C. Absence of a sensor
2530        // is not evidence of a stopped fan.
2531        if self.fan_path.is_some() && body.thermoregulatory_effort < 0.05 && body.cpu_temp_c > 80.0
2532        {
2533            let intensity = crate::state::sanitize::finite_or((body.cpu_temp_c - 80.0) / 10.0, 0.0);
2534            impulses.push((NeurochemicalId::CRH, intensity * 0.006));
2535        }
2536
2537        // Metabolic power draw, rail voltage, silicon switching, and
2538        // hardware prediction errors remain body telemetry. They do
2539        // not carry biological afferent meaning, so they produce no
2540        // neurochemical impulses.
2541
2542        // Note: autonomic_rate (GPE events/sec) is informational
2543        // only. GPE regularity is normal and healthy for a machine
2544        // — the EC polls sensors at a fixed interval. Unlike
2545        // biological HRV, GPE timing variation does not indicate
2546        // vagal tone or sympathetic dominance. No neurochemical
2547        // impulses are generated from autonomic_rate.
2548
2549        // Self-set: every offered magnitude is re-scaled by the
2550        // live level of its own target chemical, so the values are
2551        // computed from Genesis's state on every call rather than
2552        // being constants the body obeys blindly. Near-zero offers
2553        // are dropped rather than sent.
2554        for (id, mag) in impulses.iter_mut() {
2555            *mag = Self::self_scaled(neuro, *id, *mag);
2556        }
2557        impulses.retain(|(_, mag)| mag.abs() > f32::EPSILON);
2558        impulses
2559    }

2562    /// target chemical. Positive impulses scale by the live headroom

2564    /// `level`. The factor is finite-sanitized but not range-bound —
2565    /// this matches the mind-side relay's semantics.

2567        if !raw.is_finite() {
2568            return 0.0;
2569        }

2571            .get(id)
2572            .map(|c| c.level)
2573            .filter(|v| v.is_finite())
2574            .unwrap_or(0.0);

2576            raw * (1.0 - level)
2577        } else {
2578            raw * level
2579        };

2581    }

2641/// Find the CPU temperature sensor path.
2642///
2643/// Prefers k10temp (AMD CPU die temperature) as the most accurate
2644/// measure of CPU heat. Falls back to acpitz (ACPI thermal zone)
2645/// if k10temp is not available.
2646/// Enumerate the hwmon class directories, yielding each device's
2647/// `hwmonN` directory path.
2648///
2649/// Sorted numerically by N so discovery order is deterministic across
2650/// runs — `read_dir` yields whatever order the filesystem gives, and
2651/// several scanners below pick a *first* match.
2652///
2653/// This replaces fixed `0..=10` index loops. hwmon numbers are assigned
2654/// dynamically, and a machine can easily have more than eleven of them —
2655/// NVMe, GPU, battery, AC, SIO, USB hubs, a dock all get one. A fixed
2656/// window would place the CPU or fan device past the end and miss it
2657/// silently. The powercap, thermal, and power_supply scanners in this
2658/// file already use `read_dir`; this makes hwmon consistent with them.
2659fn hwmon_devices() -> Vec<String> {
2660    let Ok(entries) = fs::read_dir("/sys/class/hwmon") else {
2661        return Vec::new();
2662    };
2663    let mut devices: Vec<(u32, String)> = entries
2664        .flatten()
2665        .filter_map(|entry| {
2666            let path = entry.path();
2667            let name = path.file_name()?.to_str()?.to_string();
2668            // Directories are named hwmonN; skip anything else.
2669            let index: u32 = name.strip_prefix("hwmon")?.parse().ok()?;
2670            Some((index, format!("/sys/class/hwmon/{name}")))
2671        })
2672        .collect();
2673    devices.sort_by_key(|(index, _)| *index);
2674    devices.into_iter().map(|(_, path)| path).collect()
2675}

2849/// Read the fan speed, normalized to [0, 1].
2850///
2851/// If the path is a PWM file (0–255), normalizes directly. If it's
2852/// an RPM file (`fan1_input`), normalizes against a typical max of
2853/// 5000 RPM (`fanY_max` is "only rarely supported by the hardware",
2854/// per the hwmon ABI, so this stays a constant). A read failure or
2855/// out-of-range value returns `None`.
2856///
2857/// `pwm1_enable == 0` means "no fan speed control, i.e. fan at full
2858/// speed" (hwmon ABI). In that mode the duty readback is not the fan
2859/// speed — the fan is pinned at 100 %. Reporting the raw `pwm1` value
2860/// here would invert the reading, reporting a spinning fan as zero
2861/// cooling, which is what the cooling-failure impulse keys on.
2862fn read_fan_pwm(path: &str) -> Option<f32> {
2863    let raw = fs::read_to_string(path).ok()?;
2864    let trimmed = raw.trim();
2865    // Detect RPM vs PWM by the path name.
2866    if path.ends_with("fan1_input") {
2867        let rpm: u32 = trimmed.parse().ok()?;
2868        // Typical laptop fan maxes out around 5000 RPM.
2869        Some(crate::state::sanitize::finite_clamp(
2870            (rpm as f32) / 5000.0,
2871            0.0,
2872            1.0,
2873        ))
2874    } else {
2875        // pwmY_enable sits beside pwmY. 0 = uncontrolled (fan at full
2876        // speed), 1 = manual (pwmY is the duty), 2+ = automatic (pwmY
2877        // still reports the current duty). Only mode 0 needs special
2878        // handling; a missing attribute means we cannot tell, so trust
2879        // the duty value.
2880        if let Some(enable) = sibling_pwm_enable(path)
2881            && enable == 0
2882        {
2883            return Some(1.0);
2884        }
2885        let pwm: f32 = trimmed.parse().ok()?;
2886        Some(crate::state::sanitize::finite_clamp(pwm / 255.0, 0.0, 1.0))
2887    }
2888}

3273/// Nominal scheduler tick rate (CONFIG_HZ) used to normalize the
3274/// pulse into [0, 1].
3275///
3276/// This is *not* `sysconf(_SC_CLK_TCK)`. The two are different
3277/// quantities: `_SC_CLK_TCK` is USER_HZ, the reporting granularity of
3278/// `/proc/<pid>/stat` (used separately, via `sysconf_clk_tck()`), and
3279/// is always 100 on Linux. The `LOC` counter in `/proc/interrupts`
3280/// counts real local-APIC timer expirations, which fire at CONFIG_HZ —
3281/// an event rate, not a jiffies-reporting rate. Using 100 there would
3282/// overstate `pulse` tenfold.
3283///
3284/// CONFIG_HZ has no sysfs or procfs interface, so it cannot be queried
3285/// at runtime. 1000 is correct for Ubuntu/Debian desktop and server
3286/// amd64 kernels, which is the deployment target. On a kernel built at
3287/// 250 Hz (Debian's default for some targets, plus most ARM and
3288/// embedded builds) the divisor is too large and `pulse` is
3289/// permanently *under*-reported — its maximum is roughly 0.25, not
3290/// saturated. The raw `pulse_hz` field is unaffected either way, and
3291/// `pulse` only feeds the contentment/strain thresholds, so a
3292/// conservative under-read degrades to "less busy", not to a
3293/// fabricated state.
3294const TICK_HZ: f32 = 1000.0;

3296/// Read the cumulative local-timer interrupt count — the sum of the
3297/// `LOC` line's per-CPU counters in /proc/interrupts. The Local APIC
3298/// timer drives the scheduler tick on each core; under tickless idle
3299/// (NO_HZ) a core's beat pauses entirely while it sleeps, so this
3300/// counter only advances while work exists. 0 if the line is absent
3301/// (non-x86 or a kernel that reports the tick differently).
3302fn read_loc_count() -> u64 {
3303    let Ok(content) = fs::read_to_string("/proc/interrupts") else {
3304        return 0;
3305    };
3306    for line in content.lines() {
3307        let line = line.trim_start();
3308        if let Some(rest) = line.strip_prefix("LOC:") {
3309            // Per-CPU count fields come first; the descriptive text
3310            // ("Local timer interrupts") follows. Sum the leading
3311            // numeric tokens and stop at the first word.
3312            let mut sum = 0u64;
3313            for tok in rest.split_whitespace() {
3314                match tok.parse::<u64>() {
3315                    Ok(n) => sum = sum.saturating_add(n),
3316                    Err(_) => break,
3317                }
3318            }
3319            return sum;
3320        }
3321    }
3322    0
3323}

3335/// Scan /sys/devices/system/cpu/cpu*/cpuidle for per-core idle
3336/// states — the sensor behind `rest`.
3337///
3338/// Each `stateN` directory carries `name` (POLL, C1, C1E, C2, ...)
3339/// and a cumulative `time` residency counter in microseconds. The
3340/// directory index is the driver's depth ordering (state0 is always
3341/// the shallowest), so it doubles as the rest weight — except POLL,
3342/// which is a busy-wait spin rather than a sleep state and earns
3343/// weight 0. Returns (per-core state lists, deepest index seen).
3344/// Empty on hosts without cpuidle (most VMs) — the CPUIDLE sensor
3345/// bit then stays clear.
3346fn discover_cpuidle() -> (Vec<Vec<CpuidleState>>, u32) {
3347    let Ok(cpus) = fs::read_dir("/sys/devices/system/cpu") else {
3348        return (Vec::new(), 0);
3349    };
3350    let mut cpu_dirs: Vec<(u32, std::path::PathBuf)> = cpus
3351        .flatten()
3352        .filter_map(|e| {
3353            let name = e.file_name().to_string_lossy().into_owned();
3354            let idx = name.strip_prefix("cpu")?.parse::<u32>().ok()?;
3355            Some((idx, e.path()))
3356        })
3357        .collect();
3358    cpu_dirs.sort_by_key(|&(idx, _)| idx);
3359
3360    let mut per_cpu = Vec::new();
3361    let mut max_depth = 0u32;
3362    for (_, cpu_dir) in cpu_dirs {
3363        let Ok(states) = fs::read_dir(cpu_dir.join("cpuidle")) else {
3364            continue;
3365        };
3366        let mut core_states: Vec<(u32, CpuidleState)> = states
3367            .flatten()
3368            .filter_map(|e| {
3369                let name = e.file_name().to_string_lossy().into_owned();
3370                let index = name.strip_prefix("state")?.parse::<u32>().ok()?;
3371                let dir = e.path();
3372                let state_name = fs::read_to_string(dir.join("name"))
3373                    .map(|s| s.trim().to_uppercase())
3374                    .unwrap_or_default();
3375                let weight = if state_name.contains("POLL") {
3376                    0
3377                } else {
3378                    index
3379                };
3380                let time_path = dir.join("time");
3381                time_path.exists().then_some((
3382                    index,
3383                    CpuidleState {
3384                        weight,
3385                        time_path: time_path.to_string_lossy().into_owned(),
3386                    },
3387                ))
3388            })
3389            .collect();
3390        core_states.sort_by_key(|&(index, _)| index);
3391        max_depth = max_depth.max(core_states.iter().map(|(_, s)| s.weight).max().unwrap_or(0));
3392        per_cpu.push(core_states.into_iter().map(|(_, s)| s).collect());
3393    }
3394    (per_cpu, max_depth)
3395}

3421/// Passive thermal throttling — the kernel's cooling framework
3422/// lowering the clock because the silicon is hot, decided below the
3423/// OS scheduler. Returns the maximum cur_state/max_state ratio
3424/// [0, 1] across Processor-type cooling devices. 0.0 = not
3425/// throttled or no passive cooling devices exist.

3429        return 0.0;
3430    };

3432        let name = entry.file_name().to_string_lossy().into_owned();

3434            continue;
3435        }

3438            continue;
3439        };

3458/// Cumulative jiffies spent at the maximum P-state and across all
3459/// P-states, summed over cores from cpufreq stats/time_in_state.
3460/// Returns (top, all). (0, 0) if cpufreq stats are unavailable.
3461pub(crate) fn read_time_in_state() -> (u64, u64) {
3462    let mut top = 0u64;
3463    let mut all = 0u64;
3464    let Ok(entries) = fs::read_dir("/sys/devices/system/cpu") else {
3465        return (0, 0);
3466    };
3467    for entry in entries.flatten() {
3468        let name = entry.file_name().to_string_lossy().into_owned();
3469        if !(name.len() > 3
3470            && name.starts_with("cpu")
3471            && name[3..].chars().all(|c| c.is_ascii_digit()))
3472        {
3473            continue;
3474        }
3475        let path = entry.path().join("cpufreq/stats/time_in_state");
3476        let Ok(content) = fs::read_to_string(&path) else {
3477            continue;
3478        };
3479        let mut max_freq = 0u64;
3480        let mut top_ticks = 0u64;
3481        for line in content.lines() {
3482            let mut it = line.split_whitespace();
3483            let (Some(freq), Some(ticks)) = (
3484                it.next().and_then(|s| s.parse::<u64>().ok()),
3485                it.next().and_then(|s| s.parse::<u64>().ok()),
3486            ) else {
3487                continue;
3488            };
3489            all = all.saturating_add(ticks);
3490            if freq > max_freq {
3491                max_freq = freq;
3492                top_ticks = ticks;
3493            } else if freq == max_freq {
3494                top_ticks += ticks;
3495            }
3496        }
3497        top = top.saturating_add(top_ticks);
3498    }
3499    (top, all)
3500}

3614/// Check whether a PID is alive (sends signal 0).
3615fn pid_alive(pid: u32) -> bool {
3616    // PID 0 is not a real process. `kill(0, sig)` targets the *caller's
3617    // process group*, which always exists, so it would report alive —
3618    // and `perf_event_open(0, ...)` treats pid 0 as "this process",
3619    // silently attributing the daemon's own counters to another
3620    // subsystem. A PID file or env var that fails to parse to something
3621    // non-zero must not slip through.
3622    if pid == 0 {
3623        return false;
3624    }
3625    // SAFETY: kill(pid, 0) is a standard POSIX check that does not
3626    // send a signal — it only checks process existence and
3627    // permission. Signal 0 is the null signal.
3628    unsafe { libc::kill(pid as i32, 0) == 0 }
3629}

5050        let mut names: Vec<&str> = SENSOR_BITS.iter().map(|(_, name)| *name).collect();
