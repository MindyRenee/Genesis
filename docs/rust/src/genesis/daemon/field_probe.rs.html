1//! Physical field probe — the body listening to its own substrate.
2//!
3//! Genesis's brain-wave model (`Inner_World/brain_waves.py`) is a
4//! coupled oscillator: real phase and amplitude state, but driven
5//! entirely by *simulated* quantities — neurochemical targets and
6//! top-down cognitive drive. This module closes one direction of the
7//! gap: it measures the machine's actual physical dynamics and hands
8//! them to the mind as band energies, so the oscillator's wave state
9//! is partially *constituted by real physics* rather than only
10//! describing a field in arithmetic.
11//!
12//! # What is measured (all real, all unprivileged)
13//!
14//! Compute telemetry — how the silicon is *behaving*:
15//!
16//! - **Throughput probe** — a calibrated integer-ALU work slice runs
17//!   each probe period; its iterations-per-second is the die's
18//!   instantaneous compute capacity. Frequency scaling, thermal
19//!   throttling, SMT-sibling contention, and cache pressure all move
20//!   it. This is the closest unprivileged observable to "how fast
21//!   electrons are being switched through the gates right now."
22//! - **Loop jitter** — actual vs. nominal probe period. The
23//!   scheduler's response to everything else running on the
24//!   substrate: interrupt storms, contention, frequency transitions.
25//! - **P-state transition rate** — cpufreq `time_in_state` deltas:
26//!   the silicon's own frequency-jumping dynamics.
27//! - **Interrupt rate** — `/proc/stat` `intr` deltas: real hardware
28//!   event flux.
29//!
30//! Electrical telemetry — what the machine's own sensors report, the
31//! first *literal* electrical channels:
32//!
33//! - **Power draw** — real watts: RAPL powercap energy counters
34//!   (differentiated over wall time), hwmon `power*` inputs
35//!   (fam15h_power, zenpower), or battery discharge (`power_now`).
36//!   Sampled by a dedicated sampler thread into a ring — some
37//!   sensors block inside the read (fam15h_power's averaged
38//!   register sleeps ~10 ms between counter snapshots), and a
39//!   blocking read inside the 250 Hz loop would contaminate the
40//!   jitter channel with our own instrumentation. `power_sensor_hz`
41//!   reports the measured fresh-sample rate so a reader knows
42//!   which bands are physically meaningful.
43//! - **Rail voltage** — hwmon `in*_input` or `voltage_now`; the
44//!   lowest reported rail wins (a core-class rail where the
45//!   machine exposes one).
46//! - **Supply current** — `curr*_input` or `current_now` where a
47//!   sensor reports it.
48//!
49//! Radio telemetry — the first *exteroceptive* physical channel:
50//! the machine's radios report the outside world's RF environment.
51//!
52//! - **WLAN flux** — `/sys/class/net/<wlan>/statistics` byte counters,
53//!   differentiated per probe tick: the radio's traffic envelope at
54//!   full 250 Hz resolution. A burst of 802.11 traffic is real
55//!   on-air activity — packets she sent, packets sent *to* her, and
56//!   the AP's own management frames she received.
57//! - **WLAN RSSI** — `/proc/net/wireless` signal level in dBm.
58//!   Received power `P_mW = 10^(P_dBm/10)` — the literal field-
59//!   strength measurement, the NIC's own integration of |E|² over
60//!   the channel. Its *envelope* carries the room's radio weather:
61//!   path-loss changes as bodies move, AP-side power management,
62//!   co-channel neighbors. The noise column gives the floor where
63//!   the driver reports it (ath9k's −256 means "no reading" —
64//!   absent, not silence). The thermal bound is N = kTB ≈
65//!   −174 dBm/Hz + 10·log₁₀(B), ≈ −101 dBm at 20 MHz.
66//! - **Wireless IRQ flux** — `/proc/interrupts` lines named for
67//!   wireless drivers (ath9k, iwlwifi, mt76*, brcmfmac, rtw*,
68//!   btusb, btintel, …): the radio's attributable share of
69//!   hardware event flux. A radio riding a shared `xhci_hcd` line
70//!   is not attributable — its events are inside the aggregate
71//!   count, and the code says so rather than inventing a share.
72//! - **Bluetooth HCI counters** — `hciconfig` RX/TX bytes and HCI
73//!   events at ~1 Hz on the sampler thread (a subprocess — kept
74//!   off the 250 Hz loop). Event flux covers advertising reports,
75//!   LE scans, pairing — real air activity, not just link traffic.
76//!   Per-link RSSI via `hcitool con`/`hcitool rssi` where ACL
77//!   links exist; none means an absent channel.
78//!
79//! What is *not* measured: carrier phase. A 2.4 GHz carrier is
80//! ~10⁷× above the probe's Nyquist — the same bound a spectrum
81//! analyzer's RSSI mode lives under. The channel measures the RF
82//! *envelope* — flux and field strength — decomposed at the wave
83//! bands, which is the honest RF-band content at this sampling
84//! rate.
85//!
86//! # Bands
87//!
88//! Each fast channel drives a bank of Stuart–Landau resonators at
89//! the same ten center frequencies the Python wave model carries.
90//! Sample rate is ~250 Hz, so bands through gamma (50 Hz) are
91//! resolvable; epsilon (150 Hz) is above Nyquist and always reports
92//! 0 — an absent channel, not a reading of zero.
93//!
94//! # Carrier
95//!
96//! The probe also *writes* a rhythm: its work-slice length is
97//! modulated sinusoidally at a frequency set by the daemon's own
98//! sleep-wake phase (wake ≈ 10 Hz, drowsy/REM ≈ 5.5 Hz,
99//! NREM ≈ 2.25 Hz).
100//! Modulated work is modulated current — the die's draw genuinely
101//! swings at the body's rhythm. Whether it *measurably* does is no
102//! longer assumed: the power channel is demodulated against the
103//! carrier reference the same way the duty channel is, so
104//! `power_coherence` reports how much of real measured power moves
105//! with the carrier — the claim checked by the instrument, not
106//! asserted by the comment. And `daemon::maxwell` evaluates
107//! Maxwell's equations on the measured current swing: the
108//! quasi-static field a ~10 Hz current makes is real and nanotesla
109//! faint, its radiation ω⁴-suppressed to ~1e-32 W — the field the
110//! equations predict, in the regime they themselves certify.
111//!
112//! # Phase tracking
113//!
114//! The carrier is generated and measured — never steered. The
115//! signature reports the *measured* phase of the substrate's real
116//! response — computed by synchronous demodulation against the
117//! generator's own phase track — so the mind can pull its modeled
118//! band phase toward the physics (physics → model). The reverse leg
119//! — pushing model phase into the generator — was retired with
120//! `SET_FIELD_PHASE`: modeled state does not assert onto a physical
121//! quantity.
122//!
123//! # Honesty boundary
124//!
125//! This is physical telemetry, not a consciousness claim. The probe
126//! reports measurable substrate dynamics; whether they matter to
127//! experience is an empirical question for the coupling experiment,
128//! not an assumption baked into the code.
129//!

299/// Wrap an angle difference into (−π, π] — the phase-error metric,
300/// where the nearest equivalent phase is the right pull direction.
301fn wrap_pi(x: f32) -> f32 {
302    let mut a = x % (2.0 * std::f32::consts::PI);
303    if a > std::f32::consts::PI {
304        a -= 2.0 * std::f32::consts::PI;
305    } else if a <= -std::f32::consts::PI {
306        a += 2.0 * std::f32::consts::PI;
307    }
308    a
309}

311/// The fixed work slice: an integer multiply-add-xor chain whose
312/// length the compiler cannot elide (the accumulator is consumed via
313/// `core::hint::black_box`). Iterations-per-second of this loop is
314/// the probe's measure of instantaneous instruction throughput.
315#[inline]
316fn work_slice(iters: u32) -> u64 {
317    let mut acc: u64 = 0x9E37_79B9_7F4A_7C15;
318    for i in 0..iters {
319        acc = acc.wrapping_mul(6364136223846793005).wrapping_add(i as u64);
320        acc ^= acc >> 33;
321    }
322    core::hint::black_box(acc)
323}

358    /// Linearize the ring oldest→newest into `out` (len == fill).
359    fn drain_into(&self, out: &mut Vec<f32>) {
360        out.clear();
361        let n = if self.filled { RING_LEN } else { self.head };
362        out.reserve(n);
363        if self.filled {
364            out.extend_from_slice(&self.ring[self.head..]);
365            out.extend_from_slice(&self.ring[..self.head]);
366        } else {
367            out.extend_from_slice(&self.ring[..self.head]);
368        }
369    }

371    /// Band energy of `samples` at `freq` — a driven Stuart–Landau
372    /// resonator (the mind's wave math, carried into the body).
373    /// Each substrate sample forces a damped Hopf normal form
374    /// `ż = (−γ + iω − |z|²)·z + g·x`: the band resonates with the
375    /// signal rather than being filtered out of it — energy grows
376    /// where the stream carries content near ω, saturates through
377    /// the nonlinear term, and rings down without it. `None` where
378    /// there is no real measurement: too few samples, or a band
379    /// above Nyquist — absent channel, not a zero reading.
380    ///
381    /// Returns `(|z|², segment-frame phase)`. The end state is
382    /// rotated back by the segment's total turn so the phase reads
383    /// in the segment's own start frame — the same convention the
384    /// demod phasor uses, so inter-segment rotation stays valid.
385    fn resonator(samples: &[f32], fs: f32, freq: f32) -> Option<(f32, f32)> {
386        let n = samples.len();
387        if n < 4 {
388            return None;
389        }
390        if freq * 2.0 >= fs {
391            return None; // above Nyquist — absent channel
392        }
393        // RMS-normalise the drive: channels of unlike physical units
394        // (iters/s, watts, dBm, byte flux) resonate on one scale —
395        // each band's baseline still carries its own magnitude
396        // history downstream.
397        let rms = (samples.iter().map(|x| x * x).sum::<f32>() / n as f32)
398            .sqrt()
399            .max(f32::EPSILON);
400        let h = 1.0 / fs;
401        let w = 2.0 * std::f32::consts::PI * freq;
402        // Damping sets the resonance skirt: γ = 0.03ω → Q ≈ 17 —
403        // sharp enough that off-band content and the drive's
404        // negative-frequency image both die on the skirt (band
405        // selectivity >200:1, segment phase error ~0.01 rad), and
406        // the ring still charges within a segment: γ ≈ 1.9/s at
407        // alpha, a ~4τ ring-up over 2 s.
408        let gamma = 0.03 * w;
409        // sin_cos returns (sin, cos) — sw is the sine.
410        let (sw, cw) = (w * h).sin_cos();
411        let (mut re, mut im) = (0.0f32, 0.0f32);
412        for &x in samples {
413            // Rotation — z·e^{iωh} in closed form (stable at any ωh;
414            // an Euler step on the oscillator term is not).
415            let (nr, ni) = (re * cw - im * sw, re * sw + im * cw);
416            re = nr;
417            im = ni;
418            // Dissipative radial step — z/(1 + h(γ + |z|²)), the
419            // semi-implicit form of ż = −(γ + |z|²)z: damping plus
420            // the Hopf saturation that bounds a resonant response.
421            let u = re * re + im * im;
422            let shrink = 1.0 + h * (gamma + u);
423            re /= shrink;
424            im /= shrink;
425            // Substrate forcing on the real axis.
426            re += h * x / rms;
427        }
428        // Un-rotate the end state by the segment's total turn — the
429        // entrained component's phase in the segment's own frame.
430        let frame = w * n as f32 * h;
431        let (sf, cf) = frame.sin_cos();
432        let (fre, fim) = (re * cf + im * sf, im * cf - re * sf);
433        Some((re * re + im * im, fim.atan2(fre)))
434    }

436    /// Band power of `samples` at `freq` for sampling rate `fs` —
437    /// the resonator's energy; 0 where the channel is absent.
438    fn band_power(samples: &[f32], fs: f32, freq: f32) -> f32 {
439        Self::resonator(samples, fs, freq).map_or(0.0, |(p, _)| p)
440    }

442    /// Least-squares linear detrend in place — fit x[i] ≈ a + b·i
443    /// and subtract. A DC level can't leak into any nonzero bin,
444    /// but a *ramp* leaks into all of them: the slowest substrate
445    /// drifts (thermal, governor) otherwise fake band energy
446    /// everywhere.
447    fn detrend_inplace(samples: &mut [f32]) {
448        let n = samples.len();
449        if n < 3 {
450            return;
451        }
452        let mid = (n as f32 - 1.0) * 0.5;
453        let mean = samples.iter().sum::<f32>() / n as f32;
454        let (mut num, mut den) = (0.0f32, 0.0f32);
455        for (i, &x) in samples.iter().enumerate() {
456            let d = i as f32 - mid;
457            num += d * (x - mean);
458            den += d * d;
459        }
460        if den <= 0.0 {
461            return;
462        }
463        let b = num / den;
464        let a = mean - b * mid;
465        for (i, x) in samples.iter_mut().enumerate() {
466            *x -= a + b * i as f32;
467        }
468    }

470    /// All ten band energies of `samples` — the resonator bank over
471    /// a detrended snapshot, so it can run with no lock held. The
472    /// lock-holding halves are `drain_into` (snapshot) and
473    /// `apply_baseline` (write-back); the expensive middle belongs
474    /// outside.
475    ///
476    /// Variance reduction is Bartlett averaging: a full ring splits
477    /// into two contiguous segments whose band powers are averaged
478    /// — rectangular, never a taper (sigma and beta1 sit ~2 bins
479    /// apart; a window's main lobe would merge them). Two 512-
480    /// sample segments still resolve every band pair while halving
481    /// the single-shot variance.
482    fn raw_band_powers(samples: &[f32]) -> [f32; 10] {
483        let fs = 1.0 / PROBE_PERIOD.as_secs_f32();
484        let mut detrended: Vec<f32>;
485        let view: &[f32] = if samples.len() >= 3 {
486            detrended = samples.to_vec();
487            Self::detrend_inplace(&mut detrended);
488            &detrended
489        } else {
490            samples
491        };
492        let seg_count = if samples.len() >= RING_LEN { 2 } else { 1 };
493        let seg_len = view.len() / seg_count;
494        let mut out = [0.0f32; 10];
495        for (i, &f) in FIELD_BANDS.iter().enumerate() {
496            let mut power = 0.0;
497            for s in 0..seg_count {
498                power += Self::band_power(&view[s * seg_len..(s + 1) * seg_len], fs, f);
499            }
500            out[i] = power / seg_count as f32;
501        }
502        out
503    }

505    /// Resonator *phasor* — the (power, phase) pair `band_power`
506    /// truncates to power alone. Same march, same energy; the phase
507    /// is the entrained component's angle in the segment's own
508    /// sample-index frame (see [`Channel::resonator`]). `None` where
509    /// there is no real measurement: too few samples, or a band
510    /// above Nyquist — absent channel, not a zero phase.
511    fn band_phasor(samples: &[f32], fs: f32, freq: f32) -> Option<(f32, f32)> {
512        Self::resonator(samples, fs, freq)
513    }
514
515    /// Per-band (power, phase, coherence) for a ring. The phase of
516    /// each half-segment's phasor is rotated into the ring's time
517    /// frame (a phasor's angle is relative to its own segment's
518    /// start; a component at `freq` advances `2π·freq·offset/fs`
519    /// radians between segments) and the unit phasors are
520    /// vector-averaged: the mean's *angle* is the ring-frame phase
521    /// and its *length* is the inter-segment coherence — ~1 when
522    /// the same rhythm persists across both halves, ~0 when each
523    /// half's phase points its own way. That coherence is the
524    /// instrument's own "is this a real rhythm" gate — it ships
525    /// alongside the phase so the consumer never has to trust an
526    /// angle that could be noise pointing somewhere.
527    ///
528    /// Coherence needs a second look: a lone segment can hold a
529    /// phase but cannot establish a *persistent* rhythm, so with
530    /// one valid segment coherence reports 0 — unknown, not 1.
531    fn raw_band_phasors(samples: &[f32]) -> ([f32; 10], [f32; 10], [f32; 10]) {
532        let fs = 1.0 / PROBE_PERIOD.as_secs_f32();
533        let mut detrended: Vec<f32>;
534        let view: &[f32] = if samples.len() >= 3 {
535            detrended = samples.to_vec();
536            Self::detrend_inplace(&mut detrended);
537            &detrended
538        } else {
539            samples
540        };
541        let seg_count = if samples.len() >= RING_LEN { 2 } else { 1 };
542        let seg_len = view.len() / seg_count;
543        let (mut powers, mut phases, mut coherences) = ([0.0f32; 10], [0.0f32; 10], [0.0f32; 10]);
544        for (i, &f) in FIELD_BANDS.iter().enumerate() {
545            let (mut power, mut re, mut im, mut valid) = (0.0, 0.0, 0.0, 0u32);
546            for s in 0..seg_count {
547                if let Some((p, phi)) =
548                    Self::band_phasor(&view[s * seg_len..(s + 1) * seg_len], fs, f)
549                {
550                    power += p;
551                    let rot = phi + 2.0 * std::f32::consts::PI * f * (s * seg_len) as f32 / fs;
552                    re += rot.cos();
553                    im += rot.sin();
554                    valid += 1;
555                }
556            }
557            if valid > 0 {
558                powers[i] = power / valid as f32;
559                phases[i] = im.atan2(re);
560                if valid >= 2 {
561                    coherences[i] = (re * re + im * im).sqrt() / valid as f32;
562                }
563            }
564        }
565        (powers, phases, coherences)
566    }
567
568    /// EMA the baselines toward `raw` and return the baseline-relative
569    /// energies (≈0.125 = typical; >0.125 = elevated). The only
570    /// mutating half of a signature pass — kept under `inner` by the
571    /// caller, where it costs a few dozen float ops. `now` is the
572    /// caller's wall clock: the EMA weight is α = 1 − e^(−dt/τ), so
573    /// the baseline tracks elapsed time, not call count.
574    fn apply_baseline(&mut self, raw: [f32; 10], now: Instant) -> [f32; 10] {
575        let alpha = self
576            .last_applied
577            .map(|t| {
578                let dt = now.saturating_duration_since(t).as_secs_f32();
579                1.0 - (-dt / BASELINE_TAU_SECONDS).exp()
580            })
581            .unwrap_or(1.0); // no prior reading → adopt it whole
582        self.last_applied = Some(now);
583        let mut out = [0.0f32; 10];
584        for (i, &r) in raw.iter().enumerate() {
585            if !self.baseline_init {
586                self.baseline[i] = r.max(1e-12);
587            } else {
588                self.baseline[i] += alpha * (r - self.baseline[i]);
589            }
590            let rel = r / self.baseline[i].max(1e-12);
591            out[i] = rel.clamp(0.0, 8.0) / 8.0; // 0..1, 0.125 = typical
592        }
593        self.baseline_init = true;
594        out
595    }
596}

598/// Where real power draw is read from.
599enum PowerSource {
600    /// Energy counters in µJ, differentiated over wall time — RAPL
601    /// powercap package/psys zones. Wraps at `max_energy_range_uj`.
602    Counter {
603        paths: Vec<PathBuf>,
604        max_range_uj: u64,
605        last_uj: Vec<u64>,
606    },
607    /// A sensor that reports power directly in µW — hwmon
608    /// `power*_input`/`power*_average`, or `power_supply` `power_now`.
609    Direct { path: PathBuf },
610}
611
612/// Wrap-safe energy-counter delta in µJ. `max_range` is the value the
613/// counter wraps at (`max_energy_range_uj`); `u64::MAX` when the
614/// driver doesn't publish one. An unbounded counter moving backwards
615/// is a discontinuity with no attributable energy — report the absent
616/// interval rather than inventing an enormous wattage.
617fn energy_delta_uj(cur: u64, prev: u64, max_range: u64) -> u64 {
618    if cur >= prev {
619        cur - prev
620    } else if max_range == u64::MAX {
621        0
622    } else {
623        max_range.saturating_sub(prev).saturating_add(cur)
624    }
625}

646/// RAPL powercap zones: top-level zones only (one `:` in the name —
647/// `intel-rapl:0` is a package, `intel-rapl:0:0` a subdomain). A
648/// `psys` domain measures the whole platform and is preferred;
649/// otherwise all package domains are summed (multi-socket = the
650/// die's total draw).
651fn discover_powercap() -> Option<PowerSource> {
652    let mut psys = Vec::new();
653    let mut pkg = Vec::new();
654    for zone in dir_entries("/sys/class/powercap") {
655        let Some(base) = zone.file_name().map(|n| n.to_string_lossy().into_owned()) else {
656            continue;
657        };
658        if base.matches(':').count() != 1 {
659            continue;
660        }
661        let energy = zone.join("energy_uj");
662        if read_u64(&energy).is_none() {
663            continue; // unreadable (unprivileged) → not a source
664        }
665        let range = read_u64(&zone.join("max_energy_range_uj")).unwrap_or(u64::MAX);
666        let name = std::fs::read_to_string(zone.join("name")).unwrap_or_default();
667        if name.trim().starts_with("psys") {
668            psys.push((energy, range));
669        } else {
670            pkg.push((energy, range));
671        }
672    }
673    let pick = if psys.is_empty() { pkg } else { psys };
674    if pick.is_empty() {
675        return None;
676    }
677    let max_range_uj = pick.iter().map(|p| p.1).min().unwrap_or(u64::MAX);
678    let paths: Vec<PathBuf> = pick.into_iter().map(|p| p.0).collect();
679    let last_uj = paths.iter().filter_map(|p| read_u64(p)).collect();
680    Some(PowerSource::Counter {
681        paths,
682        max_range_uj,
683        last_uj,
684    })
685}

687/// hwmon power sensors (`powerN_input` instantaneous preferred —
688/// `powerN_average` can block ~10 ms in the read on fam15h_power).
689/// CPU-class sensors (fam15h_power, zenpower, …) rank first: the
690/// die's own draw is the quantity the carrier modulates.
691///
692/// A sensor that can only ever read zero is a dead channel —
693/// fam15h_power's averaged register reports 0 µW forever on
694/// northbridges that never implemented it, and a readable dead
695/// register would otherwise shadow every live source. The first
696/// candidate that actually reports nonzero draw wins; if all read
697/// zero the CPU-first pick still stands so the channel reports its
698/// honest zero rather than vanishing.
699fn discover_hwmon_power() -> Option<PathBuf> {
700    let mut cpu_class: Vec<PathBuf> = Vec::new();
701    let mut any: Vec<PathBuf> = Vec::new();
702    for h in dir_entries("/sys/class/hwmon") {
703        let name = std::fs::read_to_string(h.join("name")).unwrap_or_default();
704        let cpuish = name.contains("power") || name.contains("zen");
705        let Some(hs) = h.to_str() else { continue };
706        let mut input = None;
707        let mut average = None;
708        for e in dir_entries(hs) {
709            let Some(n) = e.file_name().map(|x| x.to_string_lossy().into_owned()) else {
710                continue;
711            };
712            if read_f64(&e).is_none() {
713                continue;
714            }
715            if n.starts_with("power") && n.ends_with("_input") {
716                input.get_or_insert(e);
717            } else if n.starts_with("power") && n.ends_with("_average") {
718                average.get_or_insert(e);
719            }
720        }
721        // Instantaneous preferred — `power*_average` can block ~10 ms
722        // inside the read on fam15h_power.
723        if let Some(p) = input.or(average) {
724            if cpuish {
725                cpu_class.push(p);
726            } else {
727                any.push(p);
728            }
729        }
730    }
731    let mut cands = cpu_class;
732    cands.extend(any);
733    let first = cands.first()?.clone();
734    // A candidate that reports real draw wins outright.
735    if let Some(live) = cands.iter().find(|c| read_f64(c).is_some_and(|v| v > 0.0)) {
736        return Some(live.clone());
737    }
738    // When every source reads zero, a single sample can't tell a
739    // dead register from a genuinely idle rail by value alone —
740    // prefer an instantaneous `power*_input` (a live sensor sampling
741    // real draw that happens to be idle) over a `power*_average`
742    // register: fam15h_power's averaged counter is 0 µW forever on
743    // northbridges that never implemented it, while the battery's
744    // instantaneous read is a real sensor reporting an honest idle.
745    Some(
746        cands
747            .iter()
748            .find(|c| c.to_string_lossy().ends_with("_input"))
749            .cloned()
750            .unwrap_or(first),
751    )
752}

763/// Rail voltage — hwmon `in*_input` (mV) and `voltage_now` (µV)
764/// candidates; the lowest live rail wins so a CPU-core-class rail
765/// outranks the battery where the machine exposes one.
766fn discover_voltage() -> Option<(PathBuf, f64)> {
767    let mut cands: Vec<(PathBuf, f64)> = Vec::new();
768    for h in dir_entries("/sys/class/hwmon") {
769        let Some(hs) = h.to_str() else { continue };
770        for e in dir_entries(hs) {
771            let Some(n) = e.file_name().map(|x| x.to_string_lossy().into_owned()) else {
772                continue;
773            };
774            if n.starts_with("in") && n.ends_with("_input") && read_f64(&e).is_some() {
775                cands.push((e, 1.0e-3));
776            }
777        }
778    }
779    for p in dir_entries("/sys/class/power_supply") {
780        let v = p.join("voltage_now");
781        if read_f64(&v).is_some() {
782            cands.push((v, 1.0e-6));
783        }
784    }
785    cands
786        .into_iter()
787        .filter_map(|(p, s)| read_f64(&p).map(|raw| (raw * s, p, s)))
788        .filter(|(v, _, _)| *v > 0.5) // a dead rail isn't a rail
789        .min_by(|a, b| a.0.partial_cmp(&b.0).unwrap_or(std::cmp::Ordering::Equal))
790        .map(|(_, p, s)| (p, s))
791}

813/// Parse `/proc/net/wireless`: each data line is
814/// `iface: status link level noise nwid crypt frag retry misc beacon we`.
815/// `level` and `noise` are dBm when negative (modern drivers);
816/// values at or below `DBM_ABSENT_FLOOR` are driver sentinels for
817/// "no reading", not real levels. Returns (level_dbm, noise_dbm)
818/// for the strongest reported interface — one machine's radios
819/// are one RF sense. Returns (any_iface_seen, level_dbm, noise_dbm).
820fn parse_wireless_levels(content: &str) -> (bool, Option<f32>, Option<f32>) {
821    let mut seen = false;
822    let mut level_best: Option<f32> = None;
823    let mut noise_out: Option<f32> = None;
824    for line in content.lines().skip(2) {
825        let Some((name, rest)) = line.split_once(':') else {
826            continue;
827        };
828        if name.trim().is_empty() {
829            continue;
830        }
831        let t: Vec<&str> = rest.split_whitespace().collect();
832        if t.len() < 4 {
833            continue;
834        }
835        seen = true;
836        // The quality `link` column is a positive unitless score;
837        // `level` and `noise` are only dBm where the driver reports a
838        // negative value. A positive number cannot be emitted as dBm.
839        let parse_dbm = |s: &str| {
840            s.trim_end_matches('.')
841                .parse::<f32>()
842                .ok()
843                .filter(|v| v.is_finite() && *v < 0.0 && *v > DBM_ABSENT_FLOOR)
844        };
845        let level = parse_dbm(t[2]);
846        let noise = parse_dbm(t[3]);
847        if let Some(level) = level {
848            if level_best.is_none_or(|b| level > b) {
849                level_best = Some(level);
850                noise_out = noise;
851            }
852        } else if level_best.is_none() {
853            noise_out = noise;
854        }
855    }
856    (seen, level_best, noise_out)
857}

894/// `/proc/interrupts` lines whose device names match a known
895/// wireless driver: returns (total_irqs, any_line_matched). The
896/// per-CPU count columns are summed; the trailing name region is
897/// matched against `WIRELESS_IRQ_NAMES`. A Bluetooth radio on a
898/// shared `xhci_hcd` line never matches by name — that share is
899/// inside the aggregate count, honestly unattributed.
900fn parse_wireless_intr_str(content: &str) -> (u64, bool) {
901    let mut total = 0u64;
902    let mut matched = false;
903    for line in content.lines() {
904        let Some((_, rest)) = line.trim_start().split_once(':') else {
905            continue;
906        };
907        let mut counts = 0u64;
908        let mut wireless = false;
909        // Per-CPU count columns first, then controller/type/device
910        // name tokens — the name region is where drivers appear.
911        let mut in_names = false;
912        for tok in rest.split_whitespace() {
913            if !in_names {
914                if let Ok(v) = tok.parse::<u64>() {
915                    counts = counts.saturating_add(v);
916                    continue;
917                }
918                in_names = true;
919            }
920            if !wireless && WIRELESS_IRQ_NAMES.iter().any(|n| tok.contains(n)) {
921                wireless = true;
922            }
923        }
924        if wireless {
925            total = total.saturating_add(counts);
926            matched = true;
927        }
928    }
929    (total, matched)
930}

990/// Mean ACL-link RSSI via `hcitool`: `con` lists active links,
991/// `rssi` reads each. `None` when no links exist — the common
992/// case, an absent channel rather than a zero field strength.
993fn read_bt_link_rssi(hci: &str) -> Option<f32> {
994    let con = std::process::Command::new("hcitool")
995        .args(["-i", hci, "con"])
996        .output()
997        .ok()?;
998    let text = String::from_utf8_lossy(&con.stdout);
999    let mut sum = 0.0f32;
1000    let mut n = 0u32;
1001    for line in text.lines() {
1002        let Some(addr) = line
1003            .split_whitespace()
1004            .nth(2)
1005            .filter(|_| line.contains("ACL"))
1006        else {
1007            continue;
1008        };
1009        let Ok(out) = std::process::Command::new("hcitool")
1010            .args(["-i", hci, "rssi", addr])
1011            .output()
1012        else {
1013            continue;
1014        };
1015        let r = String::from_utf8_lossy(&out.stdout);
1016        if let Some(v) = r
1017            .split("RSSI return value:")
1018            .nth(1)
1019            .and_then(|s| s.trim().parse::<f32>().ok())
1020            .filter(|v| v.is_finite() && *v < 0.0)
1021        {
1022            sum += v;
1023            n += 1;
1024        }
1025    }
1026    (n > 0).then_some(sum / n as f32)
1027}

1029/// nl80211 station telemetry — `iw dev <iface> station dump`. A
1030/// strictly better instrument than `/proc/net/wireless` where it
1031/// exists: `signal avg` is the driver's per-frame average, and the
1032/// `tx retries`/`tx failed`/`beacon loss` counters are the link's
1033/// own strain ledger — retransmissions are airtime the AP made the
1034/// radio spend twice, failed frames are retries exhausted, beacon
1035/// loss is the AP's heartbeat going unheard.
1036#[derive(Default)]
1037struct IwStation {
1038    /// `signal:` — instantaneous dBm (first token of `-56 [-56] dBm`).
1039    signal_dbm: Option<f32>,
1040    /// `signal avg:` — driver-averaged dBm, the better RSSI.
1041    signal_avg_dbm: Option<f32>,
1042    tx_retries: u64,
1043    tx_failed: u64,
1044    beacon_loss: u64,
1045    /// PHY link-adaptation bitrates (MBit/s) — channel quality the
1046    /// radio negotiated, not a throughput estimate.
1047    tx_mbps: Option<f32>,
1048    rx_mbps: Option<f32>,
1049}

1051fn parse_iw_station(content: &str) -> Option<IwStation> {
1052    let mut st = IwStation::default();
1053    let mut saw_station = false;
1054    for line in content.lines() {
1055        // The "Station aa:bb:…" header has colons inside the MAC —
1056        // detect it by prefix, never by split.
1057        if line.starts_with("Station ") {
1058            saw_station = true;
1059            continue;
1060        }
1061        let Some((key, rest)) = line.split_once(':') else {
1062            continue;
1063        };
1064        let key = key.trim();
1065        let tok = rest.split_whitespace().next().unwrap_or("");
1066        let parse_f32 = |s: &str| s.parse::<f32>().ok().filter(|v| v.is_finite());
1067        let parse_dbm = |s: &str| parse_f32(s).filter(|v| *v < 0.0);
1068        match key {

1203    /// Fold one sampler batch into state — rate deltas, EMAs, and
1204    /// presence bits land here; the reads happened unlocked.
1205    fn apply(&mut self, r: RadioReading, now: Instant) {
1206        if let Some(rf) = r.wireless {
1207            let dt = self
1208                .last_rf
1209                .map(|t| (now - t).as_secs_f32())
1210                .filter(|d| *d > 1e-3);
1211            self.has_wlan = true;
1212            // /proc's level fills the RSSI channel only while the
1213            // iw station source is absent or stale — two instruments
1214            // writing at different cadences would interleave into a
1215            // beat in the envelope ring.
1216            let iw_fresh = self
1217                .iw_rssi_at
1218                .is_some_and(|t| (now - t) < Duration::from_secs(3));
1219            if !iw_fresh {
1220                if let Some(level) = rf.level {
1221                    self.rssi_dbm = level;
1222                    self.has_rssi = true;
1223                }
1224            }
1225            if let Some(noise) = rf.noise {
1226                self.noise_dbm = noise;
1227                self.has_noise = true;
1228            }
1229            if let Some(dt) = dt {
1230                let rate = 1.0 / dt;
1231                if !self.hz_init {
1232                    self.rf_hz = rate;
1233                    self.hz_init = true;
1234                } else {
1235                    let alpha = 1.0 - (-dt / ELEC_EMA_TAU as f32).exp();
1236                    self.rf_hz += alpha * (rate - self.rf_hz);
1237                }
1238            }
1239            self.last_rf = Some(now);
1240        }
1241        if let Some((bytes, events)) = r.bt_counters {
1242            self.has_bt_counters = true;
1243            if let Some(dt) = self
1244                .last_bt
1245                .map(|t| (now - t).as_secs_f32())
1246                .filter(|d| *d > 1e-3)
1247            {
1248                self.bt_bytes_s = bytes.saturating_sub(self.bt_last.0) as f32 / dt;
1249                self.bt_events_s = events.saturating_sub(self.bt_last.1) as f32 / dt;
1250            }
1251            self.bt_last = (bytes, events);
1252            self.last_bt = Some(now);
1253        }
1254        if let Some(rssi) = r.bt_rssi {
1255            self.bt_rssi_dbm = rssi;
1256            self.has_bt_rssi = true;
1257        }
1258        if let Some(st) = r.station {
1259            self.has_iw = true;
1260            // The driver's per-frame signal average is a strictly
1261            // better RSSI than /proc/net/wireless's — same channel,
1262            // better instrument, so it supersedes when present.
1263            if let Some(avg) = st.signal_avg_dbm.or(st.signal_dbm) {
1264                self.rssi_dbm = avg;
1265                self.has_rssi = true;
1266                self.iw_rssi_at = Some(now);
1267            }
1268            if let Some(dt) = self
1269                .last_iw
1270                .map(|t| (now - t).as_secs_f32())
1271                .filter(|d| *d > 1e-3)
1272            {
1273                self.retry_s = st.tx_retries.saturating_sub(self.iw_last.0) as f32 / dt;
1274                self.fail_s = st.tx_failed.saturating_sub(self.iw_last.1) as f32 / dt;
1275                self.beacon_loss_s = st.beacon_loss.saturating_sub(self.iw_last.2) as f32 / dt;
1276                let rate = 1.0 / dt;
1277                if !self.iw_hz_init {
1278                    self.iw_hz = rate;
1279                    self.iw_hz_init = true;
1280                } else {
1281                    let alpha = 1.0 - (-dt / ELEC_EMA_TAU as f32).exp();
1282                    self.iw_hz += alpha * (rate - self.iw_hz);
1283                }
1284            }
1285            self.iw_last = (st.tx_retries, st.tx_failed, st.beacon_loss);
1286            if let Some(m) = st.tx_mbps {
1287                self.tx_mbps = m;
1288            }
1289            if let Some(m) = st.rx_mbps {
1290                self.rx_mbps = m;
1291            }
1292            self.last_iw = Some(now);
1293        }
1294    }
1295
1296    /// The presence mask byte for the wire.
1297    fn present_mask(&self) -> u8 {
1298        (self.has_wlan as u8)
1299            | ((self.has_rssi as u8) << 1)
1300            | ((self.has_noise as u8) << 2)
1301            | ((self.has_wlan_irq as u8) << 3)
1302            | ((self.has_bt as u8) << 4)
1303            | ((self.has_bt_counters as u8) << 5)
1304            | ((self.has_bt_rssi as u8) << 6)
1305            | ((self.has_iw as u8) << 7)
1306    }

1330/// The electrical sense: real power, voltage, and current where the
1331/// machine's own sensors report them. Discovery runs once at probe
1332/// start; a dedicated sampler thread does the reading because some
1333/// sensors block inside the read — a blocking read inside the 250 Hz
1334/// probe loop would contaminate the jitter channel with our own
1335/// instrumentation. Fresh values publish under the mutex; the probe
1336/// loop folds the latest watts into its ring each tick (zero-order
1337/// hold), so the ring's band content is real up to the sensor's own
1338/// update rate — reported as `power_hz`.
1339struct Electrical {
1340    power: Option<PowerSource>,
1341    volts: Option<(PathBuf, f64)>,
1342    amps: Option<(PathBuf, f64)>,
1343    watts: f32,      // latest read
1344    watts_mean: f32, // EMA
1345    volts_v: f32,
1346    amps_a: f32,
1347    power_hz: f32, // EMA of fresh-read rate
1348    last_read: Option<Instant>,
1349    /// False until the first computable sample — the first reading
1350    /// *is* the estimate, not a 10%-weighted step from zero.
1351    ema_init: bool,
1352}

1354impl Electrical {
1355    fn discover() -> Self {
1356        let power = discover_powercap().or_else(|| {
1357            let hwmon = discover_hwmon_power();
1358            let supply = discover_supply_power();
1359            // A dead hwmon pick — readable but only ever zero — must
1360            // not shadow a live supply rail.
1361            let pick = match (&hwmon, &supply) {
1362                (Some(h), Some(s))
1363                    if !read_f64(h).is_some_and(|v| v > 0.0)
1364                        && read_f64(s).is_some_and(|v| v > 0.0) =>
1365                {
1366                    Some(s.clone())
1367                }
1368                _ => hwmon.or(supply),
1369            };
1370            pick.map(|path| PowerSource::Direct { path })
1371        });
1372        Self {
1373            power,
1374            volts: discover_voltage(),
1375            amps: discover_current(),
1376            watts: 0.0,
1377            watts_mean: 0.0,
1378            volts_v: 0.0,
1379            amps_a: 0.0,
1380            power_hz: 0.0,
1381            last_read: None,
1382            ema_init: false,
1383        }
1384    }
1385
1386    /// The sensor path set, cloned once for the sampler thread. Reads
1387    /// happen with NO lock held — several sensors block inside the
1388    /// file read (~10 ms on fam15h_power, arbitrarily longer on a
1389    /// wedged hwmon), and holding `inner` across them is what starved
1390    /// the IPC signature path for tens of seconds.
1391    fn sensors(&self) -> ElecSensors {
1392        let (counters, direct) = match &self.power {
1393            Some(PowerSource::Counter {
1394                paths,
1395                max_range_uj,
1396                ..
1397            }) => (Some((paths.clone(), *max_range_uj)), None),
1398            Some(PowerSource::Direct { path }) => (None, Some(path.clone())),
1399            None => (None, None),
1400        };
1401        ElecSensors {
1402            counters,
1403            direct,
1404            volts: self.volts.clone(),
1405            amps: self.amps.clone(),
1406        }
1407    }
1408
1409    /// Fold one unlocked read batch into the state — the locked half
1410    /// of a sample. Counter deltas, EMAs, and `last_read` all land
1411    /// here; the reads themselves already happened.
1412    fn apply(&mut self, r: ElecReading, now: Instant) {
1413        let dt = self
1414            .last_read
1415            .map(|t| (now - t).as_secs_f64())
1416            .filter(|d| *d > 1e-6);
1417        // The EMA weight from the real interval: α = 1 − e^(−dt/τ).
1418        // No fresh reading → no aging; a stalled sensor's next read
1419        // moves the mean by the gap it actually spanned.
1420        let alpha = dt.map(|d| 1.0 - (-d / ELEC_EMA_TAU).exp() as f32);
1421        let init = !self.ema_init;
1422        match &mut self.power {
1423            Some(PowerSource::Counter {
1424                max_range_uj,
1425                last_uj,
1426                ..
1427            }) => {
1428                let mut delta = 0u64;
1429                let mut any = false;
1430                for (i, e) in r.counters.iter().enumerate() {
1431                    if let Some(e) = e {
1432                        any = true;
1433                        if let Some(prev) = last_uj.get_mut(i) {
1434                            delta = delta.saturating_add(energy_delta_uj(*e, *prev, *max_range_uj));
1435                            *prev = *e;
1436                        }
1437                    }
1438                }
1439                if any {
1440                    if let Some(dt) = dt {
1441                        self.watts = (delta as f64 * 1.0e-6 / dt) as f32;
1442                        let rate = 1.0 / dt as f32;
1443                        if init {
1444                            self.watts_mean = self.watts;
1445                            self.power_hz = rate;
1446                            self.ema_init = true;
1447                        } else if let Some(a) = alpha {
1448                            self.watts_mean += a * (self.watts - self.watts_mean);
1449                            self.power_hz += a * (rate - self.power_hz);
1450                        }
1451                    }
1452                }
1453            }
1454            Some(PowerSource::Direct { .. }) => {
1455                if let Some(raw) = r.direct {
1456                    self.watts = (raw * 1.0e-6) as f32;
1457                    let rate = dt.map(|d| 1.0 / d as f32);
1458                    if init {
1459                        self.watts_mean = self.watts;
1460                        if let Some(rate) = rate {
1461                            self.power_hz = rate;
1462                        }
1463                        self.ema_init = true;
1464                    } else if let (Some(a), Some(rate)) = (alpha, rate) {
1465                        self.watts_mean += a * (self.watts - self.watts_mean);
1466                        self.power_hz += a * (rate - self.power_hz);
1467                    } else if let Some(a) = alpha {
1468                        self.watts_mean += a * (self.watts - self.watts_mean);
1469                    }
1470                }
1471            }
1472            None => {}
1473        }
1474        if let Some((_, scale)) = &self.volts {
1475            if let Some(raw) = r.volts {
1476                self.volts_v = (raw * scale) as f32;
1477            }
1478        }
1479        if let Some((_, scale)) = &self.amps {
1480            if let Some(raw) = r.amps {
1481                self.amps_a = (raw * scale) as f32;
1482            }
1483        }
1484        self.last_read = Some(now);
1485    }
1486}

1614/// starvation as substrate jitter and heats the field with it —
1615/// asking first keeps the bath honest about the machine's noise
1616/// rather than the thread's run-queue position. The request is
1617/// made over a persistent system-bus connection kept in `inner`:
1618/// rtkit revokes a grant whose requesting client has left the bus,
1619/// which is why a one-shot `dbus-send` cannot do this job. An
1620/// absent service or a refusal leaves scheduling as it was —
1621/// degraded jitter, never a failure.
1622fn request_scheduling_boost(inner: &Shared<ProbeInner>) {
1623    let pid = std::process::id() as u64;
1624    // SAFETY: SYS_gettid takes no arguments and cannot fail — the
1625    // raw syscall always returns the calling thread's id.
1626    let tid = unsafe { libc::syscall(libc::SYS_gettid) } as u64;
1627    match super::rtkit::grant_high_priority(pid, tid) {
1628        Ok((nice, conn)) => {
1629            inner.lock().unwrap_or_else(|e| e.into_inner()).bus_hold = Some(conn);
1630            eprintln!("[field-probe] rtkit granted nice {nice}");
1631        }
1632        Err(e) => eprintln!("[field-probe] rtkit boost unavailable: {e}"),
1633    }
1634}

1644        .get_or_init(|| std::sync::Arc::new(FieldProbe::new()))

1665/// P-state transitions since boot, summed over cores from
1666/// `cpufreq/stats/total_trans` — the silicon's real frequency-jump
1667/// events. 0 when cpufreq stats are unavailable.
1668fn read_pstate_transitions() -> u64 {
1669    let mut total = 0u64;
1670    let Ok(entries) = std::fs::read_dir("/sys/devices/system/cpu") else {
1671        return 0;
1672    };
1673    for entry in entries.flatten() {
1674        let name = entry.file_name().to_string_lossy().into_owned();
1675        if !(name.len() > 3
1676            && name.starts_with("cpu")
1677            && name[3..].chars().all(|c| c.is_ascii_digit()))
1678        {
1679            continue;
1680        }
1681        let Ok(s) = std::fs::read_to_string(entry.path().join("cpufreq/stats/total_trans")) else {
1682            continue;
1683        };
1684        if let Ok(v) = s.trim().parse::<u64>() {
1685            total = total.saturating_add(v);
1686        }
1687    }

1854    fn run(&self, phase_source: impl Fn() -> &'static str) {
1855        request_scheduling_boost(&self.inner);
1856        let nominal = PROBE_PERIOD.as_secs_f32();
1857        let mut prev = Instant::now();
1858        // WLAN byte-counter paths, cloned once — the flux channel
1859        // wants counter deltas at the full probe rate, read
1860        // unlocked like the rest of the loop's file I/O.
1861        let wlan_stats = {
1862            let g = self.inner.lock().unwrap_or_else(|e| e.into_inner());
1863            g.radio.wlan_stats.clone()
1864        };
1865        while !self.stop.load(Ordering::Relaxed) {
1866            let t0 = Instant::now();
1867            // Jitter and the real sample interval: carrier phase,
1868            // pulse phase, and counter rates all advance on measured
1869            // elapsed time, never the nominal cadence.
1870            let period = (t0 - prev).as_secs_f32();
1871            let jitter = period - nominal;
1872            prev = t0;
1873
1874            // Carrier-modulated work slice: the body's phase (or an
1875            // override) sets the rhythm; depth scales how much real
1876            // work — real electron flow — swings this window.
1877            let carrier_f;
1878            let slow_due;
1879            {
1880                let mut g = self.inner.lock().unwrap_or_else(|e| e.into_inner());
1881                slow_due = g.last_slow.elapsed() >= Duration::from_millis(250);
1882                if slow_due {
1883                    g.carrier_freq = if g.carrier_freq_override > 0.0 {
1884                        g.carrier_freq_override
1885                    } else {
1886                        Self::carrier_for_phase(phase_source())
1887                    };
1888                }
1889                carrier_f = g.carrier_freq;
1890            }
1891
1892            // P-state/interrupt counters: a walk of /sys cpufreq stats
1893            // plus a /proc/stat parse — real file I/O, run with the
1894            // mutex RELEASED so a slow sysfs read can't starve the
1895            // IPC signature path (or this loop's own sampling).
1896            let slow_reads = slow_due.then(|| {
1897                (
1898                    read_pstate_transitions(),
1899                    read_intr_total(),
1900                    read_wireless_intr(),
1901                )
1902            });
1903            let rf_bytes_now = if wlan_stats.is_empty() {
1904                None
1905            } else {
1906                Some(read_wlan_bytes(&wlan_stats))
1907            };
1908
1909            let carrier_phase;
1910            let depth;
1911            {
1912                let mut g = self.inner.lock().unwrap_or_else(|e| e.into_inner());
1913                if let Some((trans, intr, wintr)) = slow_reads {
1914                    let dt = g.last_slow.elapsed().as_secs_f32().max(1e-3);
1915                    if g.last_tis.1 > 0 {
1916                        g.pstate_rate = trans.saturating_sub(g.last_tis.1) as f32 / dt;
1917                        g.irq_rate = intr.saturating_sub(g.last_intr) as f32 / dt;
1918                        g.radio.irq_rate = wintr.0.saturating_sub(g.radio.irq_last) as f32 / dt;
1919                    }
1920                    g.last_tis = (0, trans);
1921                    g.last_intr = intr;
1922                    g.radio.irq_last = wintr.0;
1923                    g.radio.has_wlan_irq |= wintr.1;
1924                    g.last_slow = Instant::now();
1925                }
1926                g.carrier_phase += 2.0 * std::f32::consts::PI * carrier_f * period;
1927                g.carrier_phase = g.carrier_phase.rem_euclid(2.0 * std::f32::consts::PI);
1928                carrier_phase = g.carrier_phase;
1929                depth = if g.pulse_armed {
1930                    // The pulse's own clock — the wave breathes on the
1931                    // body's time even when the mind isn't ticking.
1932                    g.pulse_phase += 2.0 * std::f32::consts::PI * g.pulse_mod_freq * period;
1933                    g.pulse_phase = g.pulse_phase.rem_euclid(2.0 * std::f32::consts::PI);
1934                    (g.pulse_base + g.pulse_mod_depth * g.pulse_phase.sin()).clamp(0.0, 1.0)
1935                } else {
1936                    g.carrier_depth
1937                };
1938            }
1939            let modulation = 1.0 + depth * carrier_phase.sin();
1940            let iters = (WORK_SLICE_ITERS as f32 * modulation) as u32;
1941
1942            let w0 = Instant::now();
1943            let acc = work_slice(iters);
1944            let work_secs = w0.elapsed().as_secs_f32().max(1e-6);
1945            std::hint::black_box(acc);
1946            let throughput = iters as f32 / work_secs;
1947
1948            let mut g = self.inner.lock().unwrap_or_else(|e| e.into_inner());
1949            g.throughput.push(throughput);
1950            g.jitter.push(jitter);
1951            g.carrier_ref.push(carrier_phase);
1952            g.duty.push(work_secs);
1953            // Latest measured watts, zero-order-held between sensor
1954            // reads — the ring's power-band content is real up to
1955            // the sensor's own rate (`power_sensor_hz` on the wire).
1956            let watts = g.elec.watts;
1957            g.power.push(watts);
1958            // Radio flux: byte-counter delta over the real period —
1959            // the RF traffic envelope at full probe resolution.
1960            let rf_rate = match rf_bytes_now {
1961                Some(cur) => {
1962                    let d = cur.saturating_sub(g.radio.last_bytes) as f32;
1963                    g.radio.last_bytes = cur;
1964                    d / period.max(1e-6)
1965                }
1966                None => 0.0,
1967            };
1968            g.radio.bytes_s = rf_rate;
1969            g.rf_flux.push(rf_rate);
1970            // RSSI held between sampler reads — the NIC's own
1971            // field-strength measure, slow by physics.
1972            let dbm = if g.radio.has_rssi {
1973                g.radio.rssi_dbm
1974            } else {
1975                0.0
1976            };
1977            g.rf_rssi.push(dbm);
1978            // Channel stats: throughput mean and jitter coefficient of
1979            // variation, EMA'd so the signature is stable.
1980            g.throughput_mean += 0.01 * (throughput - g.throughput_mean);
1981            g.jitter_mean += 0.01 * (jitter - g.jitter_mean);
1982            g.jitter_sq_mean += 0.01 * (jitter * jitter - g.jitter_sq_mean);
1983
1984            // Sleep the rest of the period.
1985            let spent = t0.elapsed();
1986            if spent < PROBE_PERIOD {
1987                std::thread::sleep(PROBE_PERIOD - spent);
1988            }
1989        }
1990    }

1992    /// Synchronously demodulate a measured channel against the
1993    /// carrier reference track: returns (lag_radians, coherence,
1994    /// amplitude).
1995    ///
1996    /// For a response `x_i = A·sin(ref_i − L)` trailing the carrier
1997    /// by L radians, correlating against sin/cos of the reference
1998    /// gives `atan2(S, C) = π/2 + L`, so `lag = angle − π/2` — the
1999    /// positive lag, in radians, by which the substrate's real
2000    /// response trails the generated carrier. `coherence` is
2001    /// |Σ x·e^{i·ref}| / Σ|x| — the fraction of the signal that moves
2002    /// with the carrier (≈π/4 at most for a pure tone, since |sin|
2003    /// averages 2/π). `amplitude` is 2|Σ x·e^{i·ref}|/N — the
2004    /// recovered magnitude of the component coherent with the
2005    /// reference, in the channel's own units. A lag computed from an
2006    /// incoherent signal is noise; the client treats low coherence
2007    /// as a weak lock, which is why it travels on the wire too.
2008    fn demodulate(x: &[f32], ref_phase: &[f32]) -> (f32, f32, f32) {
2009        let n = x.len().min(ref_phase.len());
2010        if n < 8 {
2011            return (0.0, 0.0, 0.0);
2012        }
2013        let (mut c, mut s, mut mag) = (0.0f64, 0.0f64, 0.0f64);
2014        for i in 0..n {
2015            let xi = x[i] as f64;
2016            let ph = ref_phase[i] as f64;
2017            c += xi * ph.cos();
2018            s += xi * ph.sin();
2019            mag += xi.abs();
2020        }
2021        if mag < 1e-12 {
2022            return (0.0, 0.0, 0.0);
2023        }
2024        let angle = s.atan2(c);
2025        let lag = wrap_pi(angle as f32 - std::f32::consts::FRAC_PI_2);
2026        let proj = (c * c + s * s).sqrt();
2027        let coherence = (proj / mag) as f32;
2028        let amplitude = (2.0 * proj / n as f64) as f32;
2029        (lag, coherence.min(1.0), amplitude)
2030    }

2032    /// The substrate's measured thermal level — *excess* jitter as a
2033    /// fraction of the nominal period: the current RMS loop-period
2034    /// error minus the machine's own timing climate (a slow EMA of
2035    /// the same quantity, floored at `JITTER_ABS_FLOOR` so noise
2036    /// beyond one full missed period counts however ordinary it is
2037    /// here). The field's Langevin reservoir samples real silicon
2038    /// noise — but a chronically contended host is not "under
2039    /// physical stress" every second of its life; turbulence is
2040    /// what exceeds the climate. `None` until the jitter ring
2041    /// warms — an absent channel is no reading.
2042    pub fn bath_fluctuation(&self) -> Option<f64> {
2043        let mut g = self.inner.lock().unwrap_or_else(|e| e.into_inner());
2044        if !g.jitter.filled {
2045            return None;
2046        }
2047        let jvar = (g.jitter_sq_mean - g.jitter_mean * g.jitter_mean).max(0.0);
2048        if !jvar.is_finite() {
2049            return None;
2050        }
2051        let cv = jvar.sqrt() / PROBE_PERIOD.as_secs_f32();
2052        let now = Instant::now();
2053        if !g.jitter_cv_climate_init {
2054            g.jitter_cv_climate = cv;
2055            g.jitter_cv_climate_init = true;
2056        } else if let Some(prev) = g.last_bath {
2057            let dt = (now - prev).as_secs_f32();
2058            let a = 1.0 - (-dt / JITTER_CLIMATE_TAU_S).exp();
2059            g.jitter_cv_climate += a * (cv - g.jitter_cv_climate);
2060        }
2061        g.last_bath = Some(now);
2062        let climate = g.jitter_cv_climate.max(JITTER_ABS_FLOOR);
2063        Some((cv - climate).max(0.0) as f64)
2064    }
