genesis-merge-ltm — fold one incarnation’s memories into another.

Reads every active episode from a foreign ltm_store (a snapshot of another Genesis data dir — an earlier life, an archived self) and stores it into the live store. The store assigns fresh sequential episode IDs on insert; everything else travels unchanged: original timestamp, salience, both emotional tags, event type, source module, and the text payload itself.

Dedup is on (timestamp, association_hash) — the same moment with the same SimHash fingerprint is the same memory, so re-running the merge or importing a snapshot that overlaps the live store can never duplicate an episode.

Deleted and archived source episodes are skipped: what an earlier life chose to shelve does not resurface here.

Usage: genesis-merge-ltm <live_base> <source_base> [source_base…] e.g. genesis-merge-ltm ~/.local/share/genesis/ltm_store
/tmp/genesis-runtime/runtime/genesis/ltm_store

Run only while she is down — the live store has no cross-process gate, and merging under a running daemon would interleave writes.
