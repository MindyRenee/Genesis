Algebra — polynomial manipulation and closed-form equation solving.

Machine-side counterpart to python/parietal_lobe/math/algebra.py. Represents univariate polynomials c[0] + c[1]·x + … + c[d]·x^d and provides addition, multiplication, Horner evaluation, linear and quadratic real/complex root solving.
