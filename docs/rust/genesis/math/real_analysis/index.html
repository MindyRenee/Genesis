Real analysis — the mathematics of “arbitrarily close.”

The epsilon-delta definition is the heart of the domain: lim x->a f(x) = L means that for every eps > 0 there is a delta > 0 such that every x inside the punctured delta-neighborhood of a (x != a, |x-a| < delta) lands within eps of L. It is a game the machine can actually play: given eps, produce a delta; given a claimed delta, verify it by sampling the punctured neighborhood. Verification is dense sampling — evidence, not proof, and the functions here say so by returning witnesses when a delta fails.

Functions§

bisection
Bisection root-finder — the Intermediate Value Theorem made algorithmic: a sign change on a continuous function traps a root, and halving the interval keeps it trapped.
check_continuous
Continuity at a point, sampled: f(a) must exist and every nearby x must land within eps of f(a). Same game as the limit except the neighborhood is NOT punctured — the point itself counts, which is exactly why continuity needs f(a) to equal L. Returns the offending (x, gap) if found.
check_delta
Does delta answer epsilon for the claim lim x->a f(x) = L? Samples the punctured neighborhood (a - delta, a + delta) \ {a} and returns the worst offender, if any: the x whose image misses the eps-band by the most. None means the delta held at every sample — evidence for the claim, not a proof.
find_delta
Find a delta answering epsilon — geometric search: shrink from start until no sampled point escapes the eps-band. Returns Some(delta) when a sampled-quiet delta is found within max_halvings halvings of start; None when none held.
fixed_point
Fixed-point iteration x_{k+1} = g(x_k): converges when g is a contraction near the fixed point. Returns the limit when the step shrinks under tol, else None.
integral
Riemann-style integral estimate of f on [a, b] with n panels. Simpson ignores the parity of n’s last panel only when n is odd — it needs pairs, so odd n returns None.
is_cauchy_tail
Finite-window Cauchy check: do all terms from index tail onward lie within eps of each other? The sequence’s own coherence — Cauchy converges in R because R is complete.
limit_numeric
Numeric two-sided limit estimate: evaluate f approaching a from both sides along a geometric sequence of offsets; returns the last pair (left, right) when they agree within tol.
newton
Newton–Raphson from a numeric derivative: x - f(x)/f’(x) with a symmetric difference quotient. None when a derivative vanishes or no convergence within max_iters.
plot
Sample a function into (x, y) points over [lo, hi] — the graph’s raw material: n evenly spaced abscissae and their images. What gets drawn is this table of pairs.
ratio_test
Ratio test on |a_{n+1}/a_n| — the sequence of ratios over the tail indices terms (passes |a_k|, returns sampled limit of the ratio). None when magnitudes hit zero or the ratio’s tail spread defeats the tolerance.
seq_limit
Estimate of a sequence’s limit from its tail: midpoint of the tail’s spread when the spread is under tol.
sup_inf
Sup and inf of a finite sample — the analysts’ extrema.
uniform_modulus
Uniform modulus of continuity on [lo, hi]: the least sampled delta answering epsilon at every sampled point of the interval. The distinction is the quantifier order — pointwise lets delta vary with the point; uniform demands one delta for all. None when no delta in the search held everywhere.
