Number sense — the approximate number system (ANS) and subitizing.

Machine-side counterpart to python/parietal_lobe/math/number_sense.py. Encodes quantities on a Weber–Fechner logarithmic mental number line (Dehaene 2003; Feigenson, Dehaene & Spelke 2004).
