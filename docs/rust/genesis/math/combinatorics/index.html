Combinatorics — the art of counting without counting.

Exact integers throughout — u128 where u64 would overflow. Factorials and binomials saturate honestly: None past the type’s reach rather than a wrapped lie. The named numbers (derangements, Catalan, Stirling, Bell, partition counts) come from their recurrences, because a recurrence is a definition the machine can run.
