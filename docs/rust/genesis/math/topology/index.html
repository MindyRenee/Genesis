Topology — nearness without distance.

Two machines live here. The first is the finite topological space: a set X of n points and a collection of open sets given as bitmasks. On a finite carrier the axioms are decidable — containment of empty and X, closure under arbitrary unions, closure under finite intersections — so the machine can check them exhaustively and compute closures, interiors, and boundaries by brute force over the open family.

The second is the simplicial complex: simplices as vertex sets, faces enumerated downward, and the Euler characteristic chi = f0 - f1 + f2 - … counted off the f-vector — the invariant that survives every deformation.
