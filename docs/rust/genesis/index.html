Genesis — the core state schema and subcognitive foundation.

§Layout

The organism is organized into three worlds — Self_World/ (this crate: the physical self — brain regions, neurochemistry, the body), Inner_World/ (the non-physical phenomena — field, waves, dreams, thoughts), and Outer_World/ (the environment). Self_World/src/ presents the body’s anatomy the same way. The implementation lives in daemon, state, store, cognition, field, and math; the region modules (basal_forebrain, basal_ganglia, brainstem, cerebellum, frontal_lobe, hypothalamus, insula, limbic_system, memory, neurochemical, occipital_lobe, parietal_lobe, self_, sleep, temporal_lobe, thalamus, tools, infrastructure, worlds) re-export those modules under the structure they implement, so the crate reads the same way the mind does: click src/ and the regions are what you see.
