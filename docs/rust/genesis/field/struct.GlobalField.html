Fields§

§manifold: StereographicSphere§fibers: Vec<SystemFiber>§transports: Vec<GaugeTransport>§integration_gain: f64§disagreement: f64§temperature: f64

The field’s thermal state — the amplitude of the fluctuation the consensus pull permits. Starts at zero: the field is born ordered, and only unresolved disagreement heats it (see synchronize — the temperature floor snaps to the current disagreement and relaxes at cooling_rate).

§cooling_rate: f64§rng_state: u64

Deterministic pseudo-noise state for the thermal kick — a fixed-seed xorshift64* stream, so the fluctuation model is stochastic in structure and reproducible in sequence.

fn thermal_plan( &self, states: &[Vector], consensus: &Vector, dt: f64, bath: f64, ) -> Result<(f64, f64, f64, f64), FieldError>

The measured tension and the integration parameters both directions share: disagreement is the Fréchet variance of the transported states against the just-computed consensus — measured before the move, the tension the step resolves. gain is the bounded pull fraction; sigma the overdamped-Langevin kick amplitude √(2γT·dt) per tangent component — the fluctuation-dissipation relation with mobility γ = integration_gain, sampling the field’s pre-update temperature so a cold field is exact. And the next temperature: disagreement heats the field, so the floor snaps up to the current tension (capped so the kick stays a fluctuation, not a takeover) and relaxes at cooling_rate — snap fast, drift slow, the adaptive-gate asymmetry.

bath is the second heat source: the substrate’s own measured thermal level, expressed in the same latent² units as disagreement. Where disagreement is the field’s internal tension, the bath is the physical reservoir the Langevin equation actually couples to — real silicon noise driving real kicks (the effective-temperature construction of the fluctuation-dissipation literature: T_eff is measured fluctuation intensity, not a modeled amplitude). It floors the temperature under the same cap: a hot machine makes the field tremble whether or not the fibers disagree.

fn pull_toward( &mut self, target_tangent: &Vector, signed_gain: f64, sigma: f64, ) -> Result<(), FieldError>

The correction machinery shared by synchronize and diverge: every non-reference fiber moves signed_gain of the way toward (positive) or away from (negative) target_tangent — expressed in the reference frame, mapped back through the transport inverse — plus a thermal kick of amplitude sigma. Then all staged states commit at once, so a failure mid-loop leaves the field untouched.

pub fn diverge( &mut self, dt: f64, bath: f64, ) -> Result<Option<Vector>, FieldError>

The opposite of synchronize: the same step with its sign negated — gradient ascent on the disagreement potential instead of descent. Each non-reference fiber moves away from the consensus along its own tangent rather than toward it; a fiber already at consensus feels no push, so divergence amplifies existing deviation rather than manufacturing it. Same thermal bookkeeping either way — divergence is a direction, not an exemption. Returns the consensus the field moved away from (the repeller, where synchronize returns the attractor).
