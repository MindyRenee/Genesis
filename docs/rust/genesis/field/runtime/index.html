Runtime bridge for the multi-fiber Genesis architecture.

Each major subsystem publishes a normalized local projection into one shared latent coordinate space. The global field measures and reduces cross-system disagreement. The persisted core state remains authoritative; this is the integration substrate rather than a second source of truth.

BODY_RELAX_TAU_S 🔒
Per-fiber homeostatic relaxation times (seconds). Between observations each fiber’s engine drifts its state toward nominal — the sphere’s pole — at its own clearance rate: an Ornstein–Uhlenbeck inflow in the ambient coordinates the engine integrates, wound by a skew generator so the relaxation traces a loxodrome — a constant-bearing spiral into the pole, arcing inward along the sphere’s own positive curvature — projected back into the cap. This is the honest prior for unobserved physiology: monoamines clear in minutes, loads decay, no state holds forever. The observation stays the authority — the drift only fills the gaps it leaves. Rates are first-pass physiological guesses ordered by how slowly each subsystem’s measured variables genuinely relax: neurochemical clearance is minutes-scale, the inference signals are faster statistics, the social variables linger longest. The winding rate matches each fiber’s own τ — a 45° loxodrome, one radian of turn per e-fold of decay.
