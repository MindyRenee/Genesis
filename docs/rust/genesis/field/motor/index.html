Module motor 

Source
Expand description

Distributed motor fields — the cognitive mind’s decisions laid out over the coordinate grid rather than collapsed to a symbol.

When the mind decides “act there” or “press action 3”, it writes that decision as fields on the tensor slab:

  • motor.spatial — an f32 field over the world grid; peaks are where cognition wants to act (goal entities attract, hazards repel, unexplored cells pull weakly).
  • motor.actions — an f32 disposition per offered action.
  • motor.action_ids — the u8 token each score corresponds to.

This module is the decode side: it knows the canonical grid shape the action interface addresses, walks fields cell by cell (nested y, x loops over row-major data — flat index i = y*w + x, so x = i % w, y = i / w), and projects the winning field cell onto the canonical coordinate grid.

Structs§

MotorTarget
What the motor fields currently point at. Both halves are optional: a published action field yields action, a published spatial field yields cell (already scaled onto the canonical MOTOR_FIELD_WIDTH × MOTOR_FIELD_HEIGHT grid).
SpatialDistribution
The field’s shape read as a distribution — what the argmax discards. centroid is the softmax mean cell on the canonical grid (continuous — finer than the winning cell), spread the RMS radius about it in canonical cells (how far the urge reaches), entropy the normalized Shannon entropy in 0..1 (0 = a decided point, 1 = maximally diffuse).
