Shared state with a refractory period.

A patch of membrane cannot sit at two potentials at once — while it is depolarized it is refractory, and a second signal arriving then either drops (the impulse is spent, try_lock → Err) or waits in the bouton until the membrane repolarizes (lock spins briefly). The claim is a single atomic state — there is no gate, no queue, no kernel object; the cell is simply busy or it is not.

This is the only exclusion biology has, and it is the only one the body needs: without it two threads hold &mut to the same tissue and the heap tears (concurrent Vec clone vs. drop reads freed memory — measured under ASan). With it the first signal depolarizes, the rest see a busy membrane, and every caller’s existing “busy → skip the cycle” arm does exactly what a dropped impulse does: nothing, this time.

Free<T> is established-once state: the first caller wires the circuit, everyone after reads it.
