Expand description

Scale of field disagreement (Fréchet variance, latent² units) at which the body’s self-inconsistency halves the published precision. Precision is inverse observation variance — the field’s disagreement IS measured variance on the body’s own channels — so the coupling follows the precision-addition rule factor = 1 / (1 + d/REF): disagreement attenuates confidence by exactly the noise it measures.

Calibrated to the field’s measured operating envelope on the stereographic sphere (examples/field_remeasure.rs): bounded distances keep the fibers closer — standing disagreement on a quiet host measures ~0.07–0.08 where the unbounded ball let it sit ~0.2–0.3, and a sustained incoherence excursion peaks ~0.15, so the old d≳0.5 excursion band is geometrically unreachable. At 0.15 the standing band attenuates ~33% — matching the original intent — while a genuine excursion (d≳0.15) reaches the 0.5 floor: the field reports its noise without halving confidence as a baseline.
