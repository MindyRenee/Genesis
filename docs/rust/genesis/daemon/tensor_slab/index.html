Module tensor_slab

Named multidimensional tensor slab — shared numeric state between the daemon and the cognitive mind. Named multidimensional tensor slab — shared numeric state between the subcognitive daemon and the cognitive mind.

The IPC commands PUT_TENSOR / GET_TENSOR / LIST_TENSORS / DROP_TENSOR let either side publish and read dense tensors (world frames, salience fields, embeddings, motor fields) without the data passing through CoreState’s mmap layout. Slab contents are process-local runtime state — a field named world.frame describes a moment and is meaningless across restarts, so it lives beside the shared body-state statics rather than inside the checksummed state schema.

Wire layout (all integers little-endian, data in C row-major order):

tensor        := [u8 dtype] [u8 ndim] [ndim × u32 dims] [payload]
put request   := [u8 name_len] [name utf8] tensor
get request   := [u8 name_len] [name utf8]
get response  := [u8 found] (tensor iff found == 1)
list response := [u16 count] (per entry: [u8 name_len] [name]
                 [u8 dtype] [u8 ndim] [ndim × u32 dims])
drop request  := [u8 name_len] [name utf8]
