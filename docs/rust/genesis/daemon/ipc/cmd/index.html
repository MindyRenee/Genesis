Command opcodes sent by the cognitive mind to the daemon.

Constants§

ADVANCE_NEURO
Advance neurochemical dynamics by dt, then run active inference and dyadic model update. The mind sends this when brain waves say it’s time to advance. Request: [f32 dt]. Response: [u8 ack][f32 surprise][f32 free_energy][f32 precision] [f32 allostatic_load][u32 tick_count] = 21 bytes.
ADVANCE_PHYSICS
Advance the body by an explicit step. Evaluation only.
ANALYZE_CODE
Structural code analysis — the daemon’s code sense. Request: [u16 path_len][path utf-8][u32 source_len][source utf-8]. Response: [u8 ack] + the UTF-8 line report described on crate::cognition::code_analysis::analysis_to_wire; a source that fails to parse returns INVALID_VALUE so the mind can fall back to its own lightweight parser. Stateless — pure function of the payload, no TickLoop needed.
APPLY_BODY_CONTROL
Read neurochemistry and apply CPU frequency, scheduling priority, and I/O priority. The mind sends this when neurochemistry has changed enough to warrant a different policy. Response: [u8 ack] + BodyControlState (same as GET_BODY_CONTROL).
ARCHIVE_EPISODE
Archive an episode from LTM. Used by sleep compression to compact low-salience episodes after extracting their semantic content. Unlike a hard delete, the archived episode remains retrievable by ID — it is only removed from the active similarity index. Request: [u64 episode_id]. Response: u8 ack (1=ok, 0=not found).
ASSOCIATE
Find associations for recent episodes. The mind sends this when new episodes have been stored. Response: [u8 ack][u32 associations] = 5 bytes.
CONSOLIDATE
Consolidate STM → LTM. The mind sends this when STM fill crosses a threshold weighted by consolidation_weight. Response: [u8 ack][u32 consolidated] = 5 bytes.
DELETE_EPISODE
Delete an episode for real — the substrate death the archive only sleepwalks. Marks the deleted flag, removes every index (id_to_idx, active_ids), and unsubscribes its SDR if still bundled. The payload slot stays orphaned in the data file — reclaiming physical space is a rebuild pass, not this call. Request/response identical to ARCHIVE_EPISODE. Additive: PROTOCOL_VERSION is unaffected.
DREAM
Run one dream cycle (only meaningful when sleeping). The mind sends this when sleep state + dream pressure cross a threshold. Response: [u8 ack][u32 dream_insights] = 5 bytes.
DROP_TENSOR
Drop a named tensor (idempotent). Request: [u8 name_len] [name utf8]. Response: [u8 ack] (1).
FIND_SIMILAR
Find episodes similar to a query text (SimHash/SDR match).
FIND_SIMILAR_ARCHIVED
Deep recall — SimHash similarity scan over the archived tier of LTM. Sleep compression retires low-salience episodes to the archive, where they stay retrievable by ID but leave every associative index; this reaches them when the active set has no answer. Request and response are identical to FIND_SIMILAR. Additive: PROTOCOL_VERSION is unaffected.
FORGET_SWEEP
Gentle forgetting — the sleep-side housekeeping sweep. Request: [u8 mode] — 0 = dry-run report (nothing is deleted), 1 = sweep (prune episodes whose traces have decayed past reach of any retrieval cue, then physically compact the store to reclaim their bytes). Response: [u32 count][u64 bytes] — for a dry run, the number of forgettable episodes and the estimated bytes their payloads occupy; for a sweep, the number forgotten and the bytes actually reclaimed. The mind decides when housekeeping runs; the body decides what is unreachable. Additive: PROTOCOL_VERSION is unaffected.
GET_BODY_CONTROL
Get the body control state — what Genesis is doing to its body (CPU frequency policy, scheduling priorities, I/O priority, thermal cap status). This is how the cognitive mind knows what its neurochemistry is driving. Response: BodyControlState.
GET_BODY_STATE
Get the interoceptive body state — CPU temperature, frequency, memory pressure, load, I/O activity, battery, thermal throttling, cognitive load, and distress level. This is how the cognitive mind feels its own body. Response: BodyState (current 124-byte fixed header + trailing variable-length descriptor blocks; v1–v3 clients detect their layout by the exact descriptor offset).
GET_DYADIC_STATE
RETIRED — pinned so the wire number is never reused. The per-person dyadic snapshot channel was removed with the person registry; the interlocutor model’s coupling output is applied to neurochemistry inside the tick.
GET_FIELD_PROBE
Physical field-probe signature — the body’s real measured substrate dynamics (throughput/jitter band energies, P-state and interrupt rates, carrier frequency, electrical and radio telemetry) decomposed at the wave bands’ center frequencies. Response: 408 bytes (v6; v5 was 328, v4 308, v3 195, v2 114, v1 102), layout in daemon::field_probe. Additive: PROTOCOL_VERSION is unaffected. When the probe thread isn’t running the reply is a single READ_FAILED byte, so an unavailable channel never reads as a healthy zero.
GET_FOLD_MARGINS
The LC–VLPO switch’s saddle-node margins at the current operating point — the bistable geometry the homeostat sweeps through at sleep onset. Request: empty. Response: FoldMargins (40 bytes) — the current homeostat h, the two fold edges in h-space, h’s normalized position between them, and the bistable flag. Pure observation: the body owns the switch; the mind reads where in the cusp it sits. Additive: PROTOCOL_VERSION is unaffected.
GET_INFERENCE_SUMMARY
Get the active inference summary — the generative self-model’s projection (surprise, free energy, allostatic load, precision, dyadic attunement/synchrony, user affect, prediction errors). Response: InferenceSignals (64 bytes).
GET_INTERNALS
The daemon’s process-local internals — the gears no state file or CoreState field exposes: every adaptive gate’s full snapshot (bounds, period, next-fire countdown, smoothed demand), the mind lease, tick counter, and last-applied body-policy values, plus the autonomous fallback’s own gates. Response: [u8 ack] (1) then UTF-8 key=value lines — self-describing and additive, so a reader written today still parses tomorrow’s longer dump. Observation only: the daemon owns the clock; the mind sees the gears. Additive: PROTOCOL_VERSION is unaffected.
GET_ION_SUMMARY
Response: IonSummary (108 bytes).
GET_MEMORY_STATS
Request short/long-term memory statistics (MemoryStats).
GET_MOTOR_TARGET
Decode the published motor fields into a concrete target: the strongest cell of motor.spatial projected onto the canonical 64×64 coordinate grid, plus the strongest disposition of motor.actions. Request: empty. Response: 14 bytes — [u8 flags][u8 action_id][f32 a_strength][u16 x][u16 y] [f32 cell_strength]; flags bit0 = action present, bit1 = cell present.
GET_NEURO_SUMMARY
Request the compact neurochemical summary (NeuroSummary).
GET_OPTIC_STATE
The optic nerve’s subcortical channel state — the body’s own read of the retinal segment, not the mind’s: photopic and melanopic irradiance, motion energy, the collicular orienting transient, the SCN light drive it is currently feeding the oscillator, and the thalamic relay gate the mind must honour (it approaches 0 in NREM — sensory transmission is blocked at the thalamus, so a see during sleep is a blind look). Response: [u8 ack] then optic_nerve::OpticState::to_wire (58 bytes, fixed layout — additive tail: a daemon that predates the pupil/lens/lid fields sends the shorter body and the mind reads them as unreported). A daemon that has never seen a frame still answers — the eye_absent flag is a reading, not an error. Additive: PROTOCOL_VERSION is unaffected.
GET_PHASE
Get the current emergent mental phase.
GET_PLACE
Where she is — the body’s answer, same truth the anchor holds. Request: empty. Response: [u8 n][n × f64] — the pose’s current ambient location (always d = 6); n = 0 means she is nowhere in particular and her interior speaks for itself. When a pose holds, a second block follows: [u8 k][k × f64 spec][u8 flags][mats] — the coordinates as the placing hand gave them plus the frame/drift flags and matrices, in the PLACE_FIELD pose layout. Under drift the ambient location is not the spec: it moves. Readers that stop after the first block get the same answer as always. Additive: PROTOCOL_VERSION unaffected.
GET_PLASTICITY_PROFILE
Get the plasticity profile — a compact summary of the metaplastic state (coupling-matrix drift, receptor sensitivities, BDNF/cortisol levels, plasticity gate) that the cognitive mind uses to adapt its learning strategy. Response: PlasticityProfile (40 bytes).
GET_PROCESS_HEALTH
Which of Genesis’s own processes are alive, and how many have died.
GET_RECENT_EPISODES
Request the most recent episodes.
GET_SENSOR_PRESENCE
Which optional hardware sensors this machine actually has.
GET_STATE
Request the full core state snapshot.
GET_STATE_SNAPSHOT
The mind’s contract for core state — a CoreStateSnapshot (232 bytes, self-describing: magic + version + size). This is what GET_STATE should have been: a purpose-built wire DTO mapped field-by-field from GenesisCoreState, so the Python side never mirrors the brain’s byte layout. GET_STATE remains for full-fidelity body inspection (the Rust test harness reads manifest and zone internals through it). Additive: PROTOCOL_VERSION unaffected — an older daemon rejects the unknown opcode loudly.
GET_SUBSYSTEM_TELEMETRY
Get per-subsystem silicon telemetry — which part of the mind’s process tree is firing. Each subsystem (daemon, cognitive — the eye rides inside the daemon) reports its own CPU share, I/O share, and microarchitectural prediction-error ratios (cache/branch misses). The cognitive mind correlates this with its task zone to feel where its activity lives. Response: [u8 count] then per subsystem: [u8 subsystem][u32 pid][f32 cpu][f32 io] [f32 cache_miss_rate][f32 branch_miss_rate] = 21 bytes each.
GET_TENSOR
Fetch a named tensor. Request: [u8 name_len][name utf8]. Response: [u8 found] (0 = absent), then the tensor encoding when found.
GET_ZONE_TRANSITIONS
How many times Genesis has changed task zone and emergent phase, and how long it has spent in each.
HANDSHAKE
Handshake: client sends [u8 client_version], daemon responds [u8 daemon_version]. If versions differ, the daemon closes the connection after responding.
LIST_TENSORS
List live tensors — names, dtypes, shapes, never payload. Request: empty. Response: [u16 count][entries].
NEURO_ADJUST_BASELINE
Retired — never reuse this wire number. Direct baseline edits let a caller permanently move a homeostatic set-point, bypassing the body’s own dynamics; the only sanctioned chemistry channel is NEURO_IMPULSE’s finite, decaying impulses.
NEURO_IMPULSE
Apply a transient neurochemical impulse.
PING

PLACE_FIELD
Place her — the ONE place, owned by the body. Two request forms. Legacy location: [k × f64] with k in 2..=6 — the coordinates of her position, stored exactly as given (a 2-vector is her place read in a plane; the same point rests in the bulk’s leading coordinate plane — x on the first latent axis, y on the second). Pose: [0xFF][u8 n][n × f64] [u8 flags][d² × f64 frame?][d² × f64 drift?] — the full placing act: location plus an optional orthonormal frame (flags bit 0, the pose’s orientation) and skew-symmetric drift generator (flags bit 1, a bivector in so(d) whose exponential flow carries the pose each tick — movement). Pose payloads are never a multiple of 8, so they cannot collide with the legacy form. An empty payload releases the place and hands the inner fiber’s voice back to the interior oscillators. The body remembers: the pose is persisted to place.bin in the data dir and restored at boot — where she is survives restarts, drift included; her location is body state, not a note the mind keeps on the side. The anchor is an observation, not a command: each tick moves the layer a bounded fraction of the geodesic toward it, so her interior goes where it was placed gradually and the field’s own consensus still pulls. Response: [u8 ack]. Additive: PROTOCOL_VERSION unaffected.
PUT_TENSOR
Store a named tensor. Request: [u8 name_len][name utf8] [u8 dtype][u8 ndim][ndim × u32 dims][payload]. Response: [u8 ack] (1) or an error byte (INVALID_VALUE for a bad dtype/rank/name/length mismatch or a full slab).
READ_SENSORS
Read hardware sensors and apply interoception impulses to neurochemistry. The mind sends this when it wants to feel its body. Response: [u8 ack] + BodyState (same as GET_BODY_STATE).
RETRIEVE_EPISODE

SAVE_INFERENCE
Save the active inference model to disk. The mind sends this periodically or before shutdown. Response: [u8 ack].
SEARCH_ARCHIVED
Page through the archived tier — the cold store’s table of contents. Request [u32 limit][u32 offset]; response is [u32 count] then per entry [u64 id][u64 ts][f32 salience] [u8 flags][u8 source_module][f32×4 emotional_tag] — metadata only, no payload text (pruning doesn’t need the body). Additive: PROTOCOL_VERSION is unaffected.
SEARCH_EPISODES
Search episodes by offset — page through all active episodes for sleep compression compaction. Request: [u32 limit][u32 offset]. Response: same format as GET_RECENT_EPISODES.
SET_COGNITIVE_PID
The cognitive mind’s PID, pushed over IPC when a new mind re-inhabits a surviving body. GENESIS_COGNITIVE_PID names the launcher alive at spawn; after a re-inhabitation it still holds the dead launcher’s PID, and interoception would measure a corpse. Request: [u32 pid]. Response: [u8 ack] (1) or PAYLOAD_TOO_SHORT. Additive: PROTOCOL_VERSION unaffected.
SET_FIELD_CARRIER
Set the carrier’s real-work modulation — the write side of the embodiment experiment. Request: [f32 depth][f32 freq_hz]. Depth 0..1 scales the work-slice modulation (0 = unmodulated work, carrier silent). Freq 0 hands the rhythm back to the body’s phase; positive overrides it (clamped 0.1..100 Hz) so evaluation can drive arbitrary bands — including infraslow rates where the thermal field can hold an oscillation. Reply: [u8 ack]. Additive: PROTOCOL_VERSION unaffected.
SET_FIELD_PHASE
Retired — never reuse this wire number. The mind’s modeled carrier-band phase is no longer pushed into the probe’s generator: modeled state does not assert onto a physical quantity. The phase lock is one-directional — the signature’s measured response phase pulls the model’s band phase (physics → model); nothing runs back.
SET_FIELD_PULSE
Arm or disarm the parasympathetic pulse — a slow autonomic wave riding the carrier’s modulation depth (contractility, not rate; the RSA analog — the vagal signature is the pulse’s slow wax and wane, never a pinned tempo). Request: [f32 base][f32 mod_freq_hz][f32 mod_depth]; mod_freq <= 0 disarms and depth returns to the static set-point. When armed the probe integrates the envelope on its own clock — the wave runs on the body’s time whether or not the mind ticks. Reply: [u8 ack]. Additive: PROTOCOL_VERSION unaffected.
SET_FOCUS
Accommodation — the mind’s focus request in metres. The body converts it to the ciliary drive (1/m dioptres, clamped to [0, 6] — infinity to a ~17 cm near point) and slews toward it on the advance clock; non-positive/non-finite distances relax to infinity. Monocular: no vergence component. Request: [f32 meters]. Response: [u8 ack] (1) or PAYLOAD_TOO_SHORT. Additive: PROTOCOL_VERSION unaffected.
SET_LID
The mind’s voluntary eyelid openness [0, 1] — the orbicularis oculi the camera hardware lacks. Composes with the sleep phase’s own lid position by min: the will can shut an open eye but cannot open one the stage has closed.
SET_OPTIC_GAIN
Corticothalamic feedback — the mind’s engagement gain onto the thalamic relay, the layer-6 V1→dLGN projection. Modulatory only: it scales the relay within ±40% and can never open a gate the sleep stage has closed. Request: [f32 gain] in [0, 1] (0.5 = neutral). Response: [u8 ack] (1) or PAYLOAD_TOO_SHORT. Additive: PROTOCOL_VERSION unaffected.
SET_POLICY_AUTHORITY
Set how much authority the inference engine has to choose its own policy on Genesis’s behalf.
SET_VOLITION
Retired — never reuse this wire number. Volitional pushes onto the sleep-wake network were removed: /sleep and /wake act through neurochemical impulses only (the chemicals control, as in a real brain — nothing exogenous is held on the wire).
SET_WAKE_ALARM
Arm or disarm the RTC wake alarm — the machine choosing when to exist next. The RTC crystal keeps counting through suspend and fires an interrupt that wakes the hardware at the chosen Unix timestamp. The mind sends this when its volition layer schedules a return; the actual suspend remains a separate, deliberate action (logind/systemctl). Request: [u64 epoch_secs] (0 = disarm) Response: [u8 ok][u64 armed_epoch] — ok=1 and armed_epoch is the alarm the hardware reports afterward; ok=0 when arming failed (no sudo grant, kernel rejected), armed_epoch = currently armed alarm (0 when none).
SET_ZONE
Set the active task zone.
SHUTDOWN
Request graceful daemon shutdown.
STORE_EPISODE
Store an episode directly in LTM, bypassing STM. Used by the cognitive mind for deliberate memory stores (conversation turns, learning events) where the real LTM episode ID is needed immediately for Python-side tracking (MemoryRecord, attractor network, RIF). Raw pre-cognitive events should still use STORE_EVENT (STM path); STORE_EPISODE is for memories the cognitive mind has already decided are worth keeping. Request: [u64 timestamp][u8 event_type][u8 source_module] [f32 salience][f32×12 emotional_tag] [u16 text_len][text bytes] The wire emotional_tag is advisory: the daemon always stamps the tag from its own live effective levels (it is defined as the body’s chemistry at encode time, which only the body can know). Send all-zeros when the caller has no tag of its own. Response: [u8 ack (1=ok, 0=failed)][u64 episode_id] (on ack=1) [f32×12 stamped_tag] (on ack=1)
STORE_EVENT
Store a pre-cognitive event into short-term memory. The wire emotional_tag is advisory: the daemon always stamps the tag from its own live effective levels (see STORE_EPISODE’s doc comment). Send all-zeros when the caller has no tag. Response: [u8 ack][f32×12 stamped_tag].
SYNC
Flush LTM pages to disk (msync).
UNARCHIVE_EPISODE
Un-archive an episode — reconsolidation. Clears the archived flag, returns the episode to the active similarity index, re-bundles its SDR, and floors its salience at the reconsolidation level so the next sleep pass retains what recall actually used. Request/response identical to ARCHIVE_EPISODE. Additive: PROTOCOL_VERSION is unaffected.

UPDATE_USER_AFFECT
Update the user affect observation — the cognitive mind’s inference of the user’s affective state from conversation features. This feeds the dyadic affective model. Request: [f32 valence][f32 arousal][f32 engagement][f32 confidence]. Response: u8 ack (1=ok).
