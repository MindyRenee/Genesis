Module error 

Source
Expand description

Error codes returned as the first byte of a response when a request is malformed or rejected.

Convention: success acks use 1 (not 0) for historical reasons — the Python client checks resp[0] == 1. Error codes are therefore renumbered to 0x80+ so they can never collide with the success byte or any valid data response first byte. A client can unambiguously distinguish success (1) from error (>= 0x80) by checking the high bit.
