Expand description

Compact electrochemical ion summary (108 bytes), sent in response to cmd::GET_ION_SUMMARY.

This is the whole-cell view an interoceptive layer needs: resting concentrations and gradients on both sides of the membrane, the Nernst reversal potential driving each ion, and the transporter state that maintains them. Arrays use crate::state::IonId order: calcium, chloride, potassium, sodium.
