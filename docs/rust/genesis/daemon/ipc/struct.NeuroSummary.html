Expand description

Compact neurochemical summary (40 bytes) — sent in response to GetNeuroSummary. This is what the Python side reads to know how Genesis feels without transferring the full state. The trailing dopamine fields were appended in v2 of this packet: older daemons send the 32-byte prefix, and both decoders accept either length — a missing tail reads as zero dopamine tonic/phasic.

Fields§

§arousal: f32

Arousal axis: high = alert, low = drowsy.

§valence: f32

Valence axis: positive = pleasant, negative = unpleasant.

§global_tone: f32

Global neurochemical tone (overall activation level).

§plasticity_gate: f32

Plasticity gate: how capable the system is of forming new memories.

§encoding_weight: f32

Memory encoding weight derived from neurochemistry.

§consolidation_weight: f32

Memory consolidation weight derived from neurochemistry.

§retrieval_weight: f32

Memory retrieval weight derived from neurochemistry.

§phase: u8

Current emergent mental phase.

§_pad: [u8; 3]

Alignment padding.

§dopamine_tonic: f32

Tonic dopamine — the slow background level. Reports the integrated reward environment (vigor; Niv et al., 2007) as distinct from the burst transient below.

§dopamine_phasic: f32

Phasic dopamine — the fast burst transient of reward prediction error, decaying on the ~1.5 s scale. The synaptic tag-and-capture gate reads this directly.
