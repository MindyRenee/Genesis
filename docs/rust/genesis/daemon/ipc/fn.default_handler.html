The default request handler. This is what the daemon uses to process IPC requests.

Response convention: Ack commands (SET_ZONE, NEURO_IMPULSE, SYNC, SHUTDOWN, UPDATE_MODULE_STATUS, UPDATE_USER_AFFECT, PING) return vec![1] on success; STORE_EVENT and STORE_EPISODE append the daemon-stamped emotional tag (see live_emotional_tag). On error they return vec![error::XXX] where error::XXX >= 0x80, so the client can distinguish success (1) from error (>= 0x80) by checking the high bit of the first response byte.

Data commands (GET_STATE, GET_NEURO_SUMMARY, etc.) return raw struct bytes on success, or vec![error::READ_FAILED] if the mmap read fails — a distinguishable error rather than a zeroed struct that would masquerade as valid zero state.
