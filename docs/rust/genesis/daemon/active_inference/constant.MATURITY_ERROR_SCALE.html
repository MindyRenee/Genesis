Expand description

Scale of the live maturity fit mapping exp(-err / this) used by _update_maturity, and of its inverse in the pre-v4 model-file load path (err = -scale * ln(maturity)), where a stored maturity is converted back into an error estimate.

Calibrated so the knee sits inside the error range a living system actually reaches: sustained RMS surprise ~0.006 (good prediction — the observed operating residual) reads ~0.55 fit; ~0.002 reads ~0.82; ~0.02 reads ~0.14; ~0.07 (one dimension making repeated 0.3 excursions — the failing case) reads ~0.001; and the 0.5 untrained init reads exp(-50) ≈ 0. The previous 0.001 demanded a sustained error an order of magnitude below the achievable noise floor, so even an accurate model read ~0 maturity indefinitely.
