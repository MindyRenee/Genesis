EMA rate for the maturity_error_ema tracker. At dt_scale = 1 the time constant is ~500 ticks, which is the timescale on which model_maturity is earned: a fresh engine starts at MATURITY_ERROR_INIT (0.5) and sustained accuracy has to pull that down before fit approaches 1, so a handful of early predictions cannot claim maturity.
