Expand description

The optic nerve, attached to the body. Held by TickLoop; sampled once per physics advance so the afference fed to the integrator describes the same instant as the chemistry it rides beside.

Fields§

§shm_name: String

Segment name — a parameter so tests can use private segments.

§shm: Option<Shmem>

The open shared-memory attachment; None until the capture limb creates the segment, re-tried every sample.

§last_seq: u64

Last consumed frame counter — a frame is consumed once, so an unchanged counter means the limb has not written since.

§last_fresh_ms: u64

current_ms of the last consumed frame (0 = never).

§prev_luma: Vec<u8>

Subsampled luma of the previous frame — the motion baseline.

§illuminance: f32

Photopic illuminance EMA — mean luma in [0, 1]. The pretectal channel.

§melanopic: f32

Blue-weighted irradiance EMA in [0, 1] — the ipRGC/melanopsin proxy (~480 nm peak → blue-weighted).

§motion: f32

Motion energy EMA in [0, 1] — pooled frame-to-frame luma change, the tectal channel’s slow trace.

§orienting: f32

This-sample orienting burst in [0, 1] — the SC’s transient, not smoothed: a burst that decays is what alerting means.

§cortical_gain: f32

The mind’s corticothalamic feedback in [0, 1], set via SET_OPTIC_GAIN. 0.5 is neutral.

§voluntary_lid: f32

The mind’s voluntary lid openness in [0, 1], set via SET_LID. 1.0 is the unrequested state — fully open. The effective lid is phase.min(voluntary): a will can lower the lids on an open phase (closing the eyes to rest them or shut out light) but can never raise them past what the sleep stage allows.

§gate_phase: MentalPhase

The phase the gate was last derived from — kept so a SET_OPTIC_GAIN between advances can re-derive the relay immediately instead of waiting for the next tick.

§relay_gain: f32

Current thalamic relay gain, recomputed each advance from the sleep stage and the cortical feedback.

§pupil_mm: f32

Pupil diameter in mm — the body’s own aperture, integrated on the advance clock from the light reflex and LC sympathetic tone. The mind reads it to scale retinal irradiance; the nerve only publishes it, it does not feed it back into the channels it was measured from.

§pupil_last_ms: u64

current_ms of the last pupil integration (0 = never — the first call seeds the clock).

§accommodation_dpt: f32

Current lens power in dioptres — the ciliary state, integrated on the advance clock toward accom_target_dpt. 0 D is focus at infinity, 6 D a ~17 cm near point.

§accom_target_dpt: f32

The power the ciliary muscle is driving toward, set by the mind’s focus request in meters (SET_FOCUS) converted to dioptres.

§accom_last_ms: u64

current_ms of the last accommodation integration (0 = never).

§frames_seen: u64

Frames consumed since attach.

pub fn frames_seen(&self) -> u64

How many frames this reader has ever consumed — > 0 marks a writer that existed. Together with fresh it separates “no retina has published yet” (0) from “the retina that was here died” (> 0, not fresh) — the distinction eye ownership is arbitrated on.

pub fn lid(&self) -> f32

How open the lids are — the phase’s transmission factor, deepened by the mind’s voluntary closure. Reads gate_phase, so it tracks the stage with at most one advance of lag; a lid that lags the flip-flop by a tick is physiology, not staleness.

Source

pub fn set_lid(&mut self, openness: f32)

The mind’s voluntary lid openness, clamped into [0, 1] — SET_LID. 1.0 releases the eye to the phase’s own position; lower values hold the lid down on whatever the phase allows. It composes with min, so a request to open against a sleeping phase changes nothing — the stage owns the floor. Voluntary state is held, not momentary: lids stay where the mind left them until it moves them again, the way a held blink or a squint persists.

Source

pub fn retinal_lux(&self, now_ms: u64) -> Option<f64>

The retinohypothalamic input for the sleep oscillator, in its lux units — None while the eye is dark or absent, which hands entrainment back to the built-in photoperiod. Lid-filtered: a bright room drives the clock weakly through closed lids, never at full strength.

pub fn alert_lc(&self, f_lc: f64) -> f64

The collicular alerting pulse in LC-input units — applied only while the network is below its own wake threshold, so a salient visual transient is a wake-up call rather than a constant bias. f_lc is the wake population’s firing rate; the caller reads it per sub-step so the pulse follows the state it is pushing on.

pub fn set_cortical_gain(&mut self, gain: f32)

The mind’s corticothalamic feedback, clamped into [0, 1]. Modulatory only — see CORTICAL_FLOOR. The relay re-derives against the last known stage so the feedback lands now, not at the next advance.

Source

pub fn update_pupil(&mut self, now_ms: u64, ne: f32)

Integrate the pupil one step on the advance clock.

The set point is the sphincter/dilator balance: a log-compressive light reflex off the photopic channel (the pretectal arc) plus a sympathetic dilation from effective norepinephrine — LC tone is the same arousal signal that widens a biological pupil. The approach is first-order with an asymmetric tau: constriction is the fast parasympathetic arc, dilation the slow sympathetic mix. ne is the caller’s current effective norepinephrine [0, 1].

The elapsed interval is measured between calls, not assumed — a caller at any cadence gets the same trajectory, matching the body’s no-dt-parameter rule. With no eye the illuminance channel sits at zero and the pupil rests dark-adapted; eye_present says whether the eye itself is there.

Source

pub fn set_focus_m(&mut self, meters: f32)

The mind’s focus request — a distance in metres, converted to the ciliary drive in dioptres (1/m). Non-positive or non-finite distances relax the eye to infinity (0 D); nearer than the ~17 cm near point clamps at ACCOM_MAX_DPT. Monocular: there is no vergence component — this is the ciliary muscle’s own servo, driven by what the mind is attending.

Source

pub fn update_accommodation(&mut self, now_ms: u64)

Integrate the lens power one step on the advance clock.

First-order approach toward the requested power with the ciliary muscle’s asymmetry: releasing back to distance is the faster direction, pulling in for near focus the slower one. The elapsed interval is measured between calls — the same trajectory at any cadence, like the pupil beside it.
