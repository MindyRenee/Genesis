fn yuyv_to_rgb(src: &[u8], width: u32, src_stride: u32, dst: &mut [u8])
Expand description

YUYV 4:2:2 → packed RGB24, BT.601 studio-swing — the same constants the mind’s _yuyv_to_rgb used when the nerve carried raw sensor bytes. src_stride is the driver’s row pitch: padding past width * 2 bytes is skipped. dst is exactly width * height * 3 bytes of wire frame — R,G,B per pixel, rows packed. Truncated or short rows leave their destination span zeroed, never stale.
