Expand description

struct perf_event_attr from linux/perf_event.h (kernel UAPI, stable ABI). The libc crate doesn’t export it, so we declare the prefix the kernel needs — size tells the kernel how many bytes to copy, so a shorter struct is valid (the rest is treated as zero).

Fields§

§type_: u32

Major type: PERF_TYPE_HARDWARE (0) = generic PMU events.

§size: u32

Size of this struct as the kernel should see it.

§config: u64

Event selector within type_ (a PERF_COUNT_HW_* value).

§sample: u64

Union: sample_period / sample_freq. Unused for counting.

§sample_type: u64

Which fields to put in sample records. Unused for counting, but it MUST be present: it occupies the u64 slot at offset 24 in the kernel’s struct, and omitting it shifts every later field by 8 bytes. See the offset assertions below.

§read_format: u64

Which fields to include on read. 0 = raw u64 count, which is what read_counts assumes when it reads 8 bytes per event.

§flags: u64

Attribute bitfield: bit0 disabled, bit5 exclude_kernel, bit6 exclude_hv (see PERF_FLAG_* below).

§wakeup: u32

Union: wakeup_events / wakeup_watermark. Unused.

§bp_type: u32

Breakpoint type. Unused.

§config1: u64

Union: bp_addr / config1. Unused.

§config2: u64

Union: bp_len / config2. Unused.
