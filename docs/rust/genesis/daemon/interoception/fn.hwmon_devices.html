fn hwmon_devices() -> Vec<String>
Expand description

Find the CPU temperature sensor path.

Prefers k10temp (AMD CPU die temperature) as the most accurate measure of CPU heat. Falls back to acpitz (ACPI thermal zone) if k10temp is not available. Enumerate the hwmon class directories, yielding each device’s hwmonN directory path.

Sorted numerically by N so discovery order is deterministic across runs — read_dir yields whatever order the filesystem gives, and several scanners below pick a first match.

This replaces fixed 0..=10 index loops. hwmon numbers are assigned dynamically, and a machine can easily have more than eleven of them — NVMe, GPU, battery, AC, SIO, USB hubs, a dock all get one. A fixed window would place the CPU or fan device past the end and miss it silently. The powercap, thermal, and power_supply scanners in this file already use read_dir; this makes hwmon consistent with them.
