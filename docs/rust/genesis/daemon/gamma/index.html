Kuramoto gamma binding — retinotopic feature assemblies into coherent proto-objects (Singer & von der Malsburg). Gamma-band phase binding — the synchrony layer that forms proto-objects.

The brain does not compute grouping; it resonates it. In V1/V2, features that belong to the same object fire in gamma phase-lock while features of different objects desynchronize (binding-by-synchrony, Singer & von der Malsburg). A proto-object is literally a gamma-coherent assembly: an internal token the system can attend, track, and reason about before any recognition happens.

The math is Kuramoto: each visible cell carries a phase oscillator whose natural frequency is seeded by colour; coupling pulls phase-locked neighbours together (contiguity, the dominant Gestalt term) and adds a weak long-range pull between same-colour cells inside a receptive window (similarity, the second term). After integration, cells sharing phase and linkage are emitted as [ProtoObject] assemblies — same-colour components whose collective phases locked get bound even when not adjacent, which is the Gestalt capability a plain flood-fill lacks.

Discipline: this layer forms objects; it never recognizes them. And a frame it cannot bind reports absence — an empty scene, not a fabricated object.
