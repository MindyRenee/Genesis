fn resonator(samples: &[f32], fs: f32, freq: f32) -> Option<(f32, f32)>

Band energy of samples at freq — a driven Stuart–Landau resonator (the mind’s wave math, carried into the body). Each substrate sample forces a damped Hopf normal form ż = (−γ + iω − |z|²)·z + g·x: the band resonates with the signal rather than being filtered out of it — energy grows where the stream carries content near ω, saturates through the nonlinear term, and rings down without it. None where there is no real measurement: too few samples, or a band above Nyquist — absent channel, not a zero reading.

Returns (|z|², segment-frame phase). The end state is rotated back by the segment’s total turn so the phase reads in the segment’s own start frame — the same convention the demod phasor uses, so inter-segment rotation stays valid.

fn detrend_inplace(samples: &mut [f32])

Least-squares linear detrend in place — fit x[i] ≈ a + b·i and subtract. A DC level can’t leak into any nonzero bin, but a ramp leaks into all of them: the slowest substrate drifts (thermal, governor) otherwise fake band energy everywhere.

Source

fn raw_band_powers(samples: &[f32]) -> [f32; 10]

All ten band energies of samples — the resonator bank over a detrended snapshot, so it can run with no lock held. The lock-holding halves are drain_into (snapshot) and apply_baseline (write-back); the expensive middle belongs outside.

Variance reduction is Bartlett averaging: a full ring splits into two contiguous segments whose band powers are averaged — rectangular, never a taper (sigma and beta1 sit ~2 bins apart; a window’s main lobe would merge them). Two 512- sample segments still resolve every band pair while halving the single-shot variance.

Source

fn band_phasor(samples: &[f32], fs: f32, freq: f32) -> Option<(f32, f32)>

Resonator phasor — the (power, phase) pair band_power truncates to power alone. Same march, same energy; the phase is the entrained component’s angle in the segment’s own sample-index frame (see Channel::resonator). None where there is no real measurement: too few samples, or a band above Nyquist — absent channel, not a zero phase.

Source

fn raw_band_phasors(samples: &[f32]) -> ([f32; 10], [f32; 10], [f32; 10])

Per-band (power, phase, coherence) for a ring. The phase of each half-segment’s phasor is rotated into the ring’s time frame (a phasor’s angle is relative to its own segment’s start; a component at freq advances 2π·freq·offset/fs radians between segments) and the unit phasors are vector-averaged: the mean’s angle is the ring-frame phase and its length is the inter-segment coherence — ~1 when the same rhythm persists across both halves, ~0 when each half’s phase points its own way. That coherence is the instrument’s own “is this a real rhythm” gate — it ships alongside the phase so the consumer never has to trust an angle that could be noise pointing somewhere.

Coherence needs a second look: a lone segment can hold a phase but cannot establish a persistent rhythm, so with one valid segment coherence reports 0 — unknown, not 1.

Source

fn apply_baseline(&mut self, raw: [f32; 10], now: Instant) -> [f32; 10]

EMA the baselines toward raw and return the baseline-relative energies (≈0.125 = typical; >0.125 = elevated). The only mutating half of a signature pass — kept under inner by the caller, where it costs a few dozen float ops. now is the caller’s wall clock: the EMA weight is α = 1 − e^(−dt/τ), so the baseline tracks elapsed time, not call count.
