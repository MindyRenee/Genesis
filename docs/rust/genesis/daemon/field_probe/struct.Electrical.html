Expand description

The electrical sense: real power, voltage, and current where the machine’s own sensors report them. Discovery runs once at probe start; a dedicated sampler thread does the reading because some sensors block inside the read — a blocking read inside the 250 Hz probe loop would contaminate the jitter channel with our own instrumentation. Fresh values publish under the mutex; the probe loop folds the latest watts into its ring each tick (zero-order hold), so the ring’s band content is real up to the sensor’s own update rate — reported as power_hz.

fn sensors(&self) -> ElecSensors

The sensor path set, cloned once for the sampler thread. Reads happen with NO lock held — several sensors block inside the file read (~10 ms on fam15h_power, arbitrarily longer on a wedged hwmon), and holding inner across them is what starved the IPC signature path for tens of seconds.

Source

fn apply(&mut self, r: ElecReading, now: Instant)

Fold one unlocked read batch into the state — the locked half of a sample. Counter deltas, EMAs, and last_read all land here; the reads themselves already happened.
