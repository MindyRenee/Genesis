fn discover_hwmon_power() -> Option<PathBuf>
Expand description

hwmon power sensors (powerN_input instantaneous preferred — powerN_average can block ~10 ms in the read on fam15h_power). CPU-class sensors (fam15h_power, zenpower, …) rank first: the die’s own draw is the quantity the carrier modulates.

A sensor that can only ever read zero is a dead channel — fam15h_power’s averaged register reports 0 µW forever on northbridges that never implemented it, and a readable dead register would otherwise shadow every live source. The first candidate that actually reports nonzero draw wins; if all read zero the CPU-first pick still stands so the channel reports its honest zero rather than vanishing.
