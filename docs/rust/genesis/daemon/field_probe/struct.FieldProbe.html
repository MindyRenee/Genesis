fn carrier_for_phase(phase: &str) -> f32

Carrier frequency for the body’s phase name. Wake ≈ alpha, drowsy/REM ≈ theta, NREM ≈ delta — the body’s actual state carried on real work. Drowsy is the N1 descent: alpha drops out and theta dominates the resting mind (same band REM rides). Unknown/absent phase → wake rate.

pub fn set_pulse(&self, base: f32, mod_freq: f32, mod_depth: f32)

Arm or disarm the parasympathetic pulse (SET_FIELD_PULSE): a slow envelope breathing carrier depth around base at mod_freq, integrated on the probe’s own clock — the body owns the wave’s timing the way it owns every rhythm here. mod_freq <= 0 disarms; depth returns to the static carrier_depth set-point untouched. Clamped: base/mod_depth 0..1, mod_freq to the infraslow band (0.01..4 Hz — below the carrier and above the bath’s own weather).

fn sample_electrical(&self)

The field sampler’s own loop — a separate thread because some sensors block inside the read (~10 ms on fam15h_power) and a blocked 250 Hz loop would poison the jitter channel with our own instrumentation. The file reads run with NO lock held — only the tiny apply step touches inner — so a slow or wedged sensor can never starve signature() on the IPC path. Publishes fresh values under the mutex; the probe loop holds the latest in its ring. Radio telemetry (RSSI, HCI counters, link RSSI, iw station dumps) rides the same thread at slower cadences.

fn demodulate(x: &[f32], ref_phase: &[f32]) -> (f32, f32, f32)

Synchronously demodulate a measured channel against the carrier reference track: returns (lag_radians, coherence, amplitude).

For a response x_i = A·sin(ref_i − L) trailing the carrier by L radians, correlating against sin/cos of the reference gives atan2(S, C) = π/2 + L, so lag = angle − π/2 — the positive lag, in radians, by which the substrate’s real response trails the generated carrier. coherence is |Σ x·e^{i·ref}| / Σ|x| — the fraction of the signal that moves with the carrier (≈π/4 at most for a pure tone, since |sin| averages 2/π). amplitude is 2|Σ x·e^{i·ref}|/N — the recovered magnitude of the component coherent with the reference, in the channel’s own units. A lag computed from an incoherent signal is noise; the client treats low coherence as a weak lock, which is why it travels on the wire too.

pub fn bath_fluctuation(&self) -> Option<f64>

The substrate’s measured thermal level — excess jitter as a fraction of the nominal period: the current RMS loop-period error minus the machine’s own timing climate (a slow EMA of the same quantity, floored at JITTER_ABS_FLOOR so noise beyond one full missed period counts however ordinary it is here). The field’s Langevin reservoir samples real silicon noise — but a chronically contended host is not “under physical stress” every second of its life; turbulence is what exceeds the climate. None until the jitter ring warms — an absent channel is no reading.

pub fn signature(&self) -> Vec<u8> ⓘ

Compute the current signature. Called by the IPC handler. Returns the 408-byte wire body (version byte included).

Three phases: snapshot the rings + scalars under inner (memcpy-scale microseconds), compute the resonator/demodulate/ Maxwell math with the lock RELEASED, then write back the baseline EMAs under a second brief hold. inner never covers compute or I/O, so a sampler stuck on a sysfs read cannot starve this — that starvation used to stall the whole IPC queue for tens of seconds.
