Inhibition — the body’s coordination substrate.

What an operating system calls a mutex, a nervous system calls inhibition. This module is the Rust half of Self_World/inhibition.py; the two files are one mechanism seen from both sides of the organism — here the math, there the words.

§The circuits

  • Inhibition<T> — fast GABAergic mutual exclusion. Serializes access to shared state the way striatal lateral inhibition serializes competing drive: the conducting unit’s neighbours wait in the inhibitory shadow (Groves 1983; Wickens et al. 1991; Koós & Tepper 1999). Wraps std::sync::Mutex and keeps the same API — lock, try_lock, into_inner, get_mut — so it is a drop-in mechanism, not a re-implementation.

  • Innate<T> — wiring fixed once, then immutable. OnceLock under its biological name: an innately wired quantity is established at genesis and never re-learned. A type alias, so every OnceLock API is inherited unchanged.

§The mathematics

Every Inhibition counts its own contention with lock-free Relaxed counters — the measurement adds no synchronization of its own, the same way an electrode does not change the neuron it records:

  • acquisitions — completed admissions
  • contended — admissions that found the gate already conducting
  • wait_nanos — total time competitors spent in the shadow

From these, per the Python side:

  • contention c = contended / max(1, acquisitions)
  • mean wait W̄ = wait_seconds / max(1, contended)
  • arrival rate λ = acquisitions / elapsed

and Little’s law L = λ·W̄ (Little 1961) gives the expected number of competitors held in the shadow, mapped into the interoceptive range by the Naka–Rushton tone = L/(1+L) (1966) — see Inhibition::stats.

§Embodiment exclusivity

One organism, one body. The flock(LOCK_EX | LOCK_NB) on the memory-mapped state file in store/mmap_state.rs is not a lock the substrate could route around — it is the physical law of exclusive embodiment, enforced by the kernel the way a skull enforces it anatomically: exactly one process may map and mutate her persistent state.
