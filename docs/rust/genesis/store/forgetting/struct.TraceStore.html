Expand description

Rehearsal/access state for every episode — persisted beside the LTM store so retrieval strengthens memory without touching the frozen .meta row format.

Fields§

§file: File§slots: HashMap<u64, u32>

episode_id → record slot (byte offset = HEADER + slot·RECORD)

§traces: HashMap<u64, Trace>

episode_id → trace. Entries not present read as the default encoded-once trace — see TraceStore::get.

Open the traces file for base, creating it if absent. A corrupt or partial tail record is ignored rather than fatal — the worst case is a trace that looks one rehearsal weaker.

Source

pub fn touch(&mut self, episode_id: u64, now_ms: u64) -> Result<()>

Rehearsal — the opposite of forgetting. Each retrieval adds a presentation to the trace: n += 1, t_last = now. The added mass is strongest exactly when it lands, so a just-rehearsed memory jumps well clear of the retrieval boundary.

pub fn remove(&mut self, episode_id: u64)

Forget an episode’s trace — the record on disk is left as dead space until retain rewrites the file, mirroring how a deleted episode’s .meta row lingers until compaction.

Source

pub fn retain(&mut self, live: &HashSet<u64>) -> Result<()>

Drop every trace whose episode no longer exists — called during compaction so the sidecar shrinks with the store it shadows.

Source

Flush the traces file. Called from LtmStore::sync().
