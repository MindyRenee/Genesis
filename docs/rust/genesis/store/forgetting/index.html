Gentle forgetting — the power-law decay of memory accessibility.

Forgetting is the mirror of encoding: the store’s store() binds a trace, and this module decides how that trace’s accessibility decays over time. The model follows the empirical biology rather than an arbitrary eviction policy:

  1. Power-law trace decay (Anderson & Schooler 1991; Wixted & Ebbesen 1991): each presentation of a memory leaves a trace whose strength decays as t^(−d), d ≈ 0.5. Repeated presentation leaves multiple traces; total trace mass is the sum of the surviving strengths, M_i = Σ_k (age_k)^(−d).

  2. Base-level activation (ACT-R): B_i = ln M_i + w·salience. Retrieval succeeds when activation exceeds a threshold, with activation noise s·χ making the boundary stochastic — matching the probabilistic retrieval observed in biological memory.

  3. Dopaminergic forgetting (Davis & Zhong 2017): dopamine “forgetting cells” accelerate trace decay while a memory is not being retrieved. High dopamine lowers the effective retrieval threshold τ_eff, raising apparent accessibility for recently encoded items and deepening the forgetting of untouched ones — modeled as a transient shift τ_eff = τ₀ − g·(DA − DA_baseline).

  4. Nothing is deleted while it is still reachable. The prune predicate should_forget fires only when a memory’s activation is below the point where even a maximal-similarity cue could reach it — B_i < τ₀ − w_cue — i.e. the engram is functionally dismantled and only its storage remains. Rehearsal (every call to retrieve) appends a fresh trace, so a memory that is still being used cannot drift to the forget boundary.

Rehearsal is the declared opposite of forgetting: touch() is the + to decay’s −.

Constants§

CUE_WEIGHT
How strongly retrieval-cue similarity contributes to accessibility. A maximal cue (identical hash) contributes +w_cue.
DAY_MS
Milliseconds per day — decay is measured in days so TRACE_DECAY’s empirical value stays meaningful.
DA_BASELINE
Dopamine baseline (resting). The forgetting gate uses deviation from this, not the absolute level.
DA_FORGETTING_GAIN
How strongly above-baseline dopamine eases retrieval (and, below baseline, deepens it). Kept small so chemistry modulates the boundary rather than dominating it.
FORGET_BOUND
The activation below which a memory is unreachable even by a perfect retrieval cue: τ₀ − w_cue. Below this the engram is functionally gone and pruning only reclaims its residue.
MIN_AGE_DAYS 🔒
Minimum age — the decay integral diverges at age 0, and real presentations are separated by at least the encoding quantum.
NOISE_SCALE
Activation-noise scale — the logistic s parameter. The ±1σ band around the threshold is ≈ 1.54·s ≈ ±0.39 logits.
PRUNE_AGE_FLOOR_DAYS
An episode must be at least this old to be a prune candidate — protection against clock anomalies and freshly encoded items.
RETRIEVAL_TAU
Base retrieval threshold — accessibility ≥ τ is retrievable.
SALIENCE_GAIN
Weight of episode salience in base-level activation. A maximally-salient first-hearing memory gets +1.0 on top of its trace term, shifting its forget horizon outward by e^2 ≈ 7.4×.
TRACES_HEADER_SIZE
Traces header size in bytes.
TRACES_MAGIC
Magic bytes for the traces file: ASCII "LTMT".
TRACES_VERSION
Traces file schema version.
TRACE_DECAY
Power-law decay exponent. The classic value (Anderson & Schooler 1991; Wixted 2004) is d ≈ 0.5.
TRACE_RECORD_SIZE
One trace record: episode_id u64 | access_count u32 | _pad u32 | last_access_ms u64.

Functions§

accessibility_score
Full accessibility score for a candidate: B_i + w·sim + s·χ − τ_eff. Positive means the cue reaches the memory.
activation_noise
Deterministic activation noise χ ∈ (−1, 1), hashed from the episode and the query so the retrieval boundary is stochastic but reproducible for the same probe — matching how a given cue at a given moment either surfaces a memory or doesn’t.
base_level
Base-level activation: ln M_i + w·salience.
days_until_forgotten
Predicted days until a memory with this activation reaches the forget boundary — positive while it is still retrievable, and the number a mind would use to decide “rehearse it now or let it go”.
effective_threshold
The retrieval threshold after the dopaminergic forgetting-cell modulation. Above-baseline dopamine lowers τ (easier retrieval of anything still reachable); below-baseline raises it.
is_accessible
Whether a candidate survives the forgetting gate for this probe.
should_forget
The deep-forget predicate: has this memory decayed past the point where any cue could reach it?
trace_mass
Total surviving trace mass for an episode — the sum of each presentation’s power-law-decayed strength.
