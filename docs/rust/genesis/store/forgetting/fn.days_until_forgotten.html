Predicted days until a memory with this activation reaches the forget boundary — positive while it is still retrievable, and the number a mind would use to decide “rehearse it now or let it go”.

B_i = ln(2n/(√a₀ + √a_L)) + w·s → solves for the a₀ at which B_i hits FORGET_BOUND, holding n, a_L ≈ a₀ (the uniform blend): a_forget ≈ (2n / e^{FORGET_BOUND − w·s})² / 4 Returns days remaining until that age; ∞ if it can never fade below the bound with the current trace count.
