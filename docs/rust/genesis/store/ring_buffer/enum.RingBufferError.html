Expand description

Errors for the STM ring buffer.

Variants§

§

Io(Error)

An underlying I/O error from the filesystem.

§

NotFound

The STM file was not found.

§

BadMagic

The file’s magic bytes did not match.

§

VersionMismatch

The file’s schema version did not match the expected one.

Fields

§expected: u32

The version the code expected.

§found: u32

The version found in the file.

§

MmapFailed

Memory-mapping the file failed.

§

MsyncFailed

msync failed while flushing mapped pages to disk.

§

FsyncFailed

fdatasync failed while flushing the file descriptor.

§

FtruncateFailed

ftruncate failed while sizing the file.

§

FileTooSmall

The backing file is smaller than the required size.

Fields

§expected: u64

The expected file size.

§found: u64

The actual file size found.

§

InvalidCapacity

The requested capacity was zero or otherwise invalid.

Fields

§found: u32

The invalid capacity value found.

§

CapacityTooLarge

The requested capacity exceeds the maximum allowed.

Fields

§found: u32

The capacity value found.

§max: u32

The maximum allowed capacity.

§

CorruptHeader

The header’s cursor fields are outside the buffer’s own bounds.

head and tail are full u64s used directly to compute slot offsets, so a value ≥ capacity would address outside the mapping. The header carries no integrity check of its own, so these fields are untrusted on open.

Fields

§head: u64

The out-of-range head found.

§tail: u64

The out-of-range tail found.

§count: u64

The out-of-range count found.

§capacity: u32

The capacity the other fields were checked against.

§

LockBusy

The sole-mapper flock could not be acquired: another process holds a live mapping of this file. Returned instead of blocking so the caller can retry or degrade rather than silently racing a second writer into the same MAP_SHARED pages.
