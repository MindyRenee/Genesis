Expand description

The LTM episodic store.

Uses a LogHD bundle store for SDR-based similarity matching and an append-only metadata file for per-episode data. The data file holds compressed payloads (same format as v1).

episode_id → index in entries vec

§active_ids: Vec<u64>

Active (non-deleted) episode IDs

§meta_header: IndexHeader

Metadata header (kept in sync with file)

§base_path: PathBuf

Base path (without extension) for rebuilding the bundle store

§meta_hashes: HashSet<u64>

SimHash fingerprints of active meta-memory texts — the association engine’s global dedup index. A bridge’s fingerprint is simhash of its full meta text (episode IDs embedded), so a pair is bridged at most once across the whole store, no matter which later pass re-encounters it. Rebuilt from active meta entries at open (archived connections may legitimately re-form) and maintained on every meta store.

§traces: TraceStore

Rehearsal/access traces — the forgetting module’s sidecar. Every encoding and every cognitive retrieval leaves a trace; the power-law decay of those traces is what forgetting measures. Kept out of .meta so the frozen 64-byte index row never changes.

pub fn retrieve(&mut self, episode_id: u64) -> Result<Episode, LtmError>

Retrieve an episode by ID.

Archived episodes are retrievable (unlike deleted ones) — this is the key difference between archiving and deletion. Dream insights and association chains that reference archived episodes still resolve, preserving memory integrity across sleep compression cycles.

Retrieval is rehearsal — the opposite of forgetting. Every episode the mind actually reaches for adds a trace, pushing its accessibility boundary outward. Maintenance reads (unbundling, bundle rebuilds) go through Self::retrieve_raw so the janitor’s broom never counts as a rehearsal.

fn retrieve_raw(&mut self, episode_id: u64) -> Result<Episode, LtmError>

Read an episode’s payload without rehearsing it.

For the store’s own bookkeeping — subtracting an SDR during archive/delete, re-encoding during bundle rebuilds. Reading a memory to maintain the shelves it sits on is not the mind remembering it, so no trace is added.

pub fn find_similar( &self, query: &str, limit: usize, ) -> Vec<(u64, u32, &IndexEntry)>

Find episodes similar to the given query text.

Uses the LogHD bundle store for SDR-based similarity matching. Returns up to limit results sorted by distance (ascending).

Forgetting applies: candidates whose trace activation a cue of this strength can no longer reach are filtered before ranking. This convenience form measures decay from the store’s own newest timestamp with neutral dopamine — the explicit form is Self::find_similar_at.

pub fn find_similar_hash( &self, query: &str, limit: usize, ) -> Vec<(u64, u32, &IndexEntry)>

Find episodes similar to the given query text using SimHash.

This is an O(n) linear scan that compares the query’s SimHash fingerprint against every active (non-meta, non-deleted) episode’s SimHash. Unlike find_similar (which uses the LogHD bundle store’s superposition), this approach has no capacity limit and no superposition noise — it gives exact Hamming distances regardless of how many episodes are stored.

Returns up to limit results sorted by Hamming distance (ascending).

Forgetting applies — see Self::find_similar. This convenience form measures decay from the store’s newest timestamp with neutral dopamine; the daemon calls Self::find_similar_hash_at with the body’s clock and live dopamine instead.

Source

pub fn find_similar_hash_at( &self, query: &str, limit: usize, now_ms: u64, dopamine: f64, ) -> Vec<(u64, u32, &IndexEntry)>

find_similar_hash with an explicit clock and dopamine level.

Each candidate’s cue strength is 1 − dist/64 — a SimHash match is a continuum from a perfect reminder (dist 0) to anti-correlation (dist 64). Candidates whose base-level activation plus this cue no longer reaches the retrieval threshold are forgotten for this probe: retrieval fades with time while the trace itself persists for pruning to release.

pub fn find_similar_archived( &self, query: &str, limit: usize, ) -> Vec<(u64, u32, &IndexEntry)>

SimHash similarity scan over the archived tier — deep recall.

find_similar_hash scans only the active set; this is its mirror for the cold store: the same exact Hamming distance over entries the compactor retired. Archived payloads survive intact, and the SimHash needs no bundle contribution — so a specific enough cue can still reach a memory the active set no longer holds.

Deep recall deliberately returns archived real episodes only: meta-memories (association traces, dream insights) have their own recall channels, and deleted entries are gone semantically even where their slots remain.

Returns up to limit results sorted by Hamming distance (ascending).

The forgetting gate applies to the cold tier exactly as it does to the active one — a faded archived memory is still reachable by a strong-enough cue, and a memory past the point where even a perfect cue fails is a prune candidate, not a resident. Convenience form; the daemon calls Self::find_similar_archived_at with live clock/dopamine.

The clock the convenience retrieval paths measure decay against: the store’s own newest entry. pub fn prune_faded(&mut self, now_ms: u64) -> Result<u64, LtmError>

Gentle forgetting’s release step: delete every episode whose trace has decayed past reach of any cue.

Like its biological counterpart this runs offline — sleep, not conversation. The cohort is released through the bulk Self::delete_many path, so each episode’s SDR leaves the superposition and its flag lands on disk exactly as a manual deletion would. Storage is only reclaimed by the Self::compact pass that follows.

Returns the number of episodes forgotten.

Source

pub fn compact(&mut self) -> Result<u64, LtmError>

Physically reclaim the space of deleted episodes.

The store’s .meta and .dat files are append-only, so delete/prune_faded mark entries gone without shrinking anything — like synapses tagged for elimination but not yet cleared. Compaction is the microglial pass: it copies every surviving episode into fresh staged files, atomically swaps them over the originals, rebuilds the bundle superposition without the dead weight, and drops the stale trace records.

Crash safety: staged files are fully synced before the journal *.compacting is written; on open, a lingering journal means the swap was interrupted and is redone. A crash before the journal leaves the original files untouched.

Returns the number of bytes reclaimed across .meta + .dat.

pub fn delete_many(&mut self, ids: &[u64]) -> Result<u32, LtmError>

Delete many episodes in one pass — the bulk form of Self::delete, mirroring Self::archive_many.

Per-episode work is identical (flags byte, unbundle, index removal) but the metadata header is written and fsynced once for the whole batch — the difference between seconds and minutes when a forgetting sweep releases a large cohort at once. Unknown, already-deleted, and already-archived-but-deleted IDs are skipped. Returns the number deleted.

pub fn archive(&mut self, episode_id: u64) -> Result<(), LtmError>

Archive an episode.

Unlike delete, archiving preserves the episode in id_to_idx so it remains retrievable by ID. The episode is only removed from active_ids, which excludes it from similarity search, recent-episode scans, and the bundle store — but not from direct retrieval by ID.

This is the correct operation for sleep compression: the episode’s semantic content has been extracted into the concept network, so it no longer needs to be in the active similarity index. But the episode itself must survive — dream insights and association chains reference it by ID, and the conversation history is irreplaceable ground truth.

Source

pub fn unarchive(&mut self, episode_id: u64) -> Result<(), LtmError>

Un-archive an episode — reconsolidation.

The mirror of archive: retrieval is what earns a memory its place in the active set, so when a deep-recall cue reaches into the cold tier and surfaces an episode, the episode comes back. This clears the archived flag on disk, returns the ID to active_ids, re-adds its SDR to the bundle superposition (the inverse of the subtraction archive performs), and floors its salience at RECONSOLIDATION_SALIENCE_FLOOR so the next compaction pass retains what recall actually used. A revived episode that is never touched again can still be re-archived by a later sweep — forgetting stays earned in both directions.

Source

pub fn archive_many(&mut self, ids: &[u64]) -> Result<u32, LtmError>

Archive many episodes in one pass — the bulk form of Self::archive.

Per-episode work is identical (flags byte write, active-list removal, SDR subtraction for non-meta episodes), but the metadata header is written and fsynced once for the whole batch instead of once per episode — the difference between seconds and minutes at ~200K episodes. Unknown, deleted, and already-archived IDs are skipped. Returns the number archived.

fn source_module_of(&mut self, idx: usize) -> Option<u8>

Read source_module from a compressed payload header.

After successfully reading the source_module, backfills it into the index entry (both in memory and on disk) so that future calls never need to decompress the same entry again. This is critical for performance: without backfilling, every call to recent_episodes with a source_module filter would decompress all old v2 entries (which have source_module == 0 in the index) on every single call — potentially hundreds of thousands of decompressions per invocation.

pub fn sync(&mut self) -> Result<(), LtmError>

Sync everything to disk.

This fsyncs the metadata file, data file, bundle store, and rehearsal traces. The order is: data file first (so the payload is durable), then meta file (so the index entries pointing to the payload are durable), then bundles (the SDR associative index), then traces (the forgetting sidecar). This ordering ensures that if a crash occurs between syncs, we never have an index entry pointing to a non-existent data record — the data is always at least as durable as the index that references it.

Source

fn unbundle(&mut self, episode_id: u64, episode: &Episode)

Subtract a stored episode’s SDR contribution from the bundle superposition — the inverse of the add_episode that store() performed.

Called when an episode leaves the bundled set (archived, deleted, or marked meta-memory after storage) so that lifecycle churn does not accumulate dead SDR weight — the pollution the startup rebuild was mopping up on every boot. Not explicitly synced: a crash that loses the subtraction leaves bounded drift, which the startup reconciliation tolerates below the rebuild threshold.

Source

pub fn rebuild_bundles(&mut self) -> Result<u64, LtmError>

Rebuild the LogHD bundle store from only real (non-meta, non-deleted) episodes.

Over time, the bundle store accumulates SDR contributions from every episode ever stored, including meta-memories (association traces, dream insights, autobiographical traces). These meta-memory SDRs pollute the bundle store’s superposition, drowning out the signal from real episodes and degrading find_similar accuracy. With ~240K meta-memories out of ~292K total episodes, the bundle store is saturated — every query returns near-uniform activations.

This method recreates the bundle file from scratch and re-adds only real episodes (those without the META_MEMORY_FLAG and without the DELETED_FLAG). The episode IDs and codes are preserved — only the bundle superposition is rebuilt.

Returns the number of real episodes added to the rebuilt store.
