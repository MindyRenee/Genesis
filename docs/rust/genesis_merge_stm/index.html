genesis-merge-stm — fold one incarnation’s working memory into another.

Reads every entry from foreign stm_ring.bin snapshots (other Genesis data dirs — earlier lives, archived selves) and merges them into the live ring alongside its current contents.

The ring holds at most capacity entries; the merge keeps the NEWEST entries across all timelines by timestamp, written back in chronological order — so what survives is always the most recent working memory, hers and her earlier lives’ together.

Dedup is on (timestamp, source_module, text) — re-running the merge can never duplicate an entry.

The consolidated flag travels with each entry: events an earlier life already consolidated stay marked (they’re already in the merged LTM and won’t re-consolidate); unconsolidated ones arrive open and flow through her own consolidation into LTM — the same path they’d have taken in their original life.

Usage: genesis-merge-stm <live_path> [–capacity N] <source_path> [source_path…] e.g. genesis-merge-stm ~/.local/share/genesis/stm_ring.bin
/tmp/genesis-runtime/runtime/genesis/stm_ring.bin

Run only while she is down — the ring has no cross-process gate.
