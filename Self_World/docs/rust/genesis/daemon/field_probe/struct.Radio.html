Expand description

The radio sense — the first exteroceptive physical channel. WLAN byte counters are sampled in the 250 Hz loop (the flux envelope wants full resolution); RSSI, noise, wireless IRQs, and the Bluetooth counters ride the sampler thread — they are slow or subprocess-backed, and a blocking read inside the 250 Hz loop would contaminate the jitter channel.
