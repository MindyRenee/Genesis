§throughput: Channel§jitter: Channel§carrier_ref: Channel

The generator’s own phase at each throughput sample — the reference track the measured response is demodulated against.

§duty: Channel

Execution seconds per work slice — the channel the carrier physically modulates: iters is the plan, work_secs is what the silicon did. Its phase vs. the reference is the real response lag (scheduler + governor + VRM settling).

§power: Channel

Measured power draw in watts (zero-order-held between sensor reads) — the carrier’s literal electrical shadow. Its lag vs. the reference is the answer to “does real power draw move with the body’s rhythm,” measured rather than assumed.

§elec: Electrical

The electrical sense — sensor discovery + latest reads.

§radio: Radio

The radio sense — WLAN flux (probe-loop counter deltas), RSSI envelope, wireless IRQ flux, and HCI counters.

§rf_flux: Channel

WLAN rx+tx bytes/s envelope — radio traffic at the full probe rate.

§rf_rssi: Channel

Received-signal-strength envelope (dBm, zero-order-held between sampler reads) — the room’s radio weather.

Slow EMA of the jitter level — the machine’s own timing climate, so the bath measures excess turbulence rather than this host’s ordinary scheduling weather (the same baseline-relative discipline as the band energies).

§jitter_cv_climate_init: bool§last_bath: Option<Instant>§bus_hold: Option<UnixStream>

The open system-bus connection owning the rtkit grant — the elevation lives only as long as this client does.

§carrier_freq: f32§carrier_phase: f32

The carrier generator’s instantaneous phase (radians).

§carrier_depth: f32

Modulation depth of the carrier’s real work (0 = unmodulated).

§carrier_freq_override: f32

Frequency override (Hz). 0 = derive from the body’s phase; the ring-down experiment drives arbitrary frequencies — including infraslow rates where the thermal field can actually sustain an oscillation.

§pulse_armed: bool

The parasympathetic envelope — a slow wave riding carrier depth itself (SET_FIELD_PULSE). Armed: effective depth is pulse_base + pulse_mod_depth * sin(pulse_phase), the phase integrated on the probe’s own clock so the wave runs whether or not the mind ticks. The RSA analog: vagal signature is the pulse’s slow wax and wane, never a pinned tempo — the carrier rate stays the phase’s own either way.
