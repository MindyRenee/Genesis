fn parse_wireless_levels(content: &str) -> (bool, Option<f32>, Option<f32>)
Expand description

Parse /proc/net/wireless: each data line is iface: status link level noise nwid crypt frag retry misc beacon we. level and noise are dBm when negative (modern drivers); values at or below DBM_ABSENT_FLOOR are driver sentinels for “no reading”, not real levels. Returns (level_dbm, noise_dbm) for the strongest reported interface — one machine’s radios are one RF sense. Returns (any_iface_seen, level_dbm, noise_dbm).
