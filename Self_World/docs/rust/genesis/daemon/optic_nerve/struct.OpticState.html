Expand description

What one GET_OPTIC_STATE returns — the nerve’s measured channel signals and the thalamic gate. Process-local, additive on the wire.

Fields§

§eye_present: bool

The segment is attached and frames were ever consumed.

§frames_fresh: bool

A new frame was consumed within FRESH_WINDOW_MS.

§illuminance: f32

Photopic illuminance EMA [0, 1].

§melanopic: f32

Melanopic (blue-weighted) irradiance EMA [0, 1].

§motion: f32

Motion energy EMA [0, 1].

§orienting: f32

Orienting transient [0, 1] — salient change now.

§relay_gain: f32

Thalamic relay gain [0, 1] — what fraction of retinal drive cortex may receive (TRN gate × corticothalamic feedback).

§cortical_gain: f32

The corticothalamic feedback currently applied.

§retinal_lux: f32

Illuminance on the SCN’s lux scale — what the oscillator is actually being fed (0 when the photoperiod is in charge).

§frame_seq: u64

Last consumed frame counter — freshness the mind can compare against the seq it reads from the segment header.

§frame_age_ms: i64

Milliseconds since the last consumed frame; -1 when none yet.

§pupil_mm: f32

Pupil diameter in mm — the body’s aperture: the light reflex plus LC sympathetic tone. The mind’s optics layer scales retinal irradiance and depth of field by it.

§accommodation_dpt: f32

Lens power in dioptres — the ciliary state. 0 D is focus at infinity (or unreported by an older daemon); the focus distance is 1/dpt metres.

§lid: f32

Eyelid transmission [0, 1] — how much scene light the phase’s lid position still passes. 1.0 awake, ~0.5 drowsy, ~0.03 in NREM/REM (0 also means unreported by an older daemon — the mind reads it as fully open rather than fully shut, so a legacy body never looks asleep to the optics layer).

pub fn to_wire(&self) -> Vec<u8> ⓘ

Wire layout after the ack byte — fixed-size, additive: [u8 flags][u8 _pad][7 × f32][u64 seq][i64 age_ms][f32 pupil_mm] [f32 accommodation_dpt][f32 lid] = 58 bytes. flags bit0 = eye_present, bit1 = frames_fresh. Daemons that predate the trailing fields send shorter bodies; decoders read pupil/lens as 0 (“unreported”) and lid as “open” (1.0).
