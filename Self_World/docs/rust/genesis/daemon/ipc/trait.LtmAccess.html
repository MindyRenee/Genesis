Expand description

A trait for obtaining mutable access to an LtmStore.

This abstraction lets the IpcServer work with both:

  • Shared ownership (daemon): Arc<Inhibition<LtmStore>> implements this trait, locking the mutex and returning a InhibitionGuard.

Without this, the daemon binary had to reimplement the entire IPC accept loop and connection handler — a 100-line duplication that could drift from the library version.
