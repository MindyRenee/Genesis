Module adaptive 

Source
Expand description

Adaptive interval gates — every maintenance gear spins at the rate its own signal demands, bounded so nothing stalls or redlines.

A tick_count % N gate is a gear keyed to the axle: change the tick rate (or pace it from the mind’s ~1 Hz advance_neuro instead of the daemon’s 5 Hz tick) and every gate silently changes period — the defect this module removes. A wall-clock gate keyed to demand keeps its own natural pace at any axle speed.

Adaptation is asymmetric, the same shape rate-adaptive polling and AIMD converged on: a demand signal snaps the period down multiplicatively (fast response), idle drift grows it additively (slow relaxation). The asymmetry is what damps oscillation — a gate that could both leap and crash in one step would chatter against the signal that feeds it. Continuous drivers go through drive, which EMA-smooths the input before mapping it onto [min, max].
