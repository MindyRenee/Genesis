Constant MODEL_FORGETTING 

Source 
const MODEL_FORGETTING: f32 = 0.02;
Expand description

Per-cycle multiplicative decay of learned weights.

0.02 means a weight retains 98% of its value per cycle and half-life of about 34 cycles (~6.8 s at the 5 Hz tick). Chosen to be slow relative to the learning rate so that a well-supported weight is not washed away by decay before evidence accumulates, while still letting a weight the data no longer supports relax back toward zero within a few tens of seconds. Without any decay the model cannot revise a weight it learned once, and cannot track a change in her dynamics.
