Coupling-force gain onto the endocrine pools.

The coupling matrix encodes neural release modulators (e.g. preganglionic ACh → adrenal medulla for epinephrine, cortisol → PNMT induction). Scaled small because the slow pools integrate persistent pushes against minute-scale clearance — unscaled, ordinary coupling deviations would saturate them at the clamp.
