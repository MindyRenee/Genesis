Module phase_partition 

Source
Expand description

Learned phase model — mental phases as latent regimes inferred from the neurochemical trajectory, not boundaries drawn by hand.

A Gaussian hidden Markov model over the effective levels of the eighteen neurochemicals. Each hidden state is a regime with its own mean and diagonal variance; the transition matrix says how regimes persist and how they switch. Nothing about dwell time or the number of regimes is set by hand:

  • Persistence comes from the transition matrix. A fixed Dirichlet pseudo-count on self-transitions keeps regimes from chattering. It is a finite-state stand-in for the sticky HDP-HMM of Fox et al. (2008), which is nonparametric and sampled; it is not that model.
  • The number of regimes is chosen by BIC over 1..=MAX_PHASES, each fit from several random starts by Baum–Welch. This is known to overselect when the trajectory is a continuous drift and the emission model is misspecified, which is what the 48-hour measurement showed. Cross-validated likelihood, which Celeux & Durand (2008) recommend for this situation, is not yet implemented.
  • Online labelling is the forward filter: the belief over regimes after each tick, and the phase is its argmax.

Fitting uses scaled forward–backward, so long trajectories do not underflow. A refit aligns the new regimes to the old ones by mean, so a phase keeps its index across refits when the regime it names still exists.

Persisted as a checksummed sidecar (see PhaseModel::to_bytes). The core state keeps only the current index, in emergent_phase, so the state schema is unchanged.
