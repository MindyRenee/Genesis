The struct size under schema v3 before InferenceSignals gained policy_authority — that field took the reserve from 60 to 64 bytes and the struct from 3288 to 3296.

This was a size migration, not a version one: the schema label stayed at 3 deliberately, because the reserve existed precisely so that growing the signals block would not move any other field. A v3 state file written before the field existed therefore carried version = 3 but state_size = 3288, and the v3 verifier reported CoreStateError::SizeMismatch — a variant that GenesisCoreState::migrate_state never sees, because it dispatches on version. GenesisCoreState::migrate_layout retains the same-version growth path.
