Struct UnitVisitor 

Source 
struct UnitVisitor {
    units: Vec<SemanticUnit>,
    current_module: Vec<String>,
    trait_is_pub: bool,
    impls: Vec<(String, Option<String>)>,
}
Expand description

A visitor that walks the AST and collects semantic units.

Fields§

§units: Vec<SemanticUnit>§current_module: Vec<String>

Lexical scope stack: module names, and the self-type or trait name while inside an impl/trait block. Methods inside impl Foo qualify as mod::Foo::method, so same-named methods on different types don’t collide in the dependency graph.

§trait_is_pub: bool

Visibility of the trait currently being visited — trait items carry no visibility of their own, so they inherit the trait’s.

§impls: Vec<(String, Option<String>)>

Impl relations collected alongside the units: (self-type, trait).

fn visit_fn_like( &mut self, ident: &Ident, is_public: bool, sig: &Signature, attrs: &[Attribute], block: Option<&Block>, line_end: usize, )

Extract a function unit shared by free functions, impl methods, and trait items. block is None for declaration-only items (required trait methods, extern fns). is_public is resolved by the caller because trait items have no visibility field.
