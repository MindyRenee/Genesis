pub fn analysis_to_wire(analysis: &FileAnalysis) -> Vec<u8> ⓘ
Expand description

Serialize a FileAnalysis into the UTF-8 line report served over IPC (ANALYZE_CODE). Fields are tab-separated, list items are ;-separated (Rust type strings can contain commas), and any stray tab/newline inside free text is flattened so each record stays one line. Record layout:

file\t<path>
lines|functions|structs|enums|traits|impls|max_complexity\t<n>
avg_complexity\t<f>
unit\t<kind>\t<name>\t<qualified>\t<start>-<end>\t<flags csv>
    \t<params;list>\t<ret>\t<calls;list>\t<refs;list>
    \t<branches>\t<loops>\t<stmts>\t<doc text>
impl\t<self_type>\t<trait or ->
edge\t<caller qualified>\t<callee qualified>
