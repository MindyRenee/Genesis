Salience floor applied by unarchive — reconsolidation.

An episode surfaced by deep recall is lifted to at least this salience so the next sleep-compaction pass retains it: retrieval is what earns a memory its warmth. Must stay above the compressor’s retention threshold (DEFAULT_SALIENCE_THRESHOLD = 0.6 in temporal_lobe/compression.py); 0.65 clears the gate without outranking genuinely high-salience memories in the retention cap.
