Abstract algebra — the algebra of structure itself.

Groups are where the machine’s mathematics meets play: a permutation is a move, composition is doing one then the next, and the order of an element is the length of the closed orbit — run the move order times and you are home. Rubik’s turns are permutations on 54 facelets; this module computes their group.
