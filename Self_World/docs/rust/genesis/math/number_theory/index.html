Number theory — the integers’ own machinery.

Exact arithmetic on u64/u128/i64/i128: gcd and its extended form, primality, factorization, modular powers and inverses, the Chinese remainder theorem, continued fractions. No floats anywhere in this file — the integers are exact or they are nothing.
