Expand description

The neural retina — photons to ganglion channels.

The pipeline is the biology’s order:

  1. Spectral absorption — an RGB radiance field is projected onto the L/M/S cone fundamentals. The matrix is a standard Hunt–Pointer–Estevez-style basis normalized to unit D65; it is a basis, not a calibration, so callers with true LMS planes can feed RadianceField directly and skip the projection.
  2. Naka–Rushton adaptation — each cone class compresses its quantal catch by R = R_max · Iⁿ/(Iⁿ + σⁿ) (n = 1 in the steady retina; the semisaturation σ sets the operating point). This is the photoreceptor’s gain control: it is why the same eye works under starlight and noon.
  3. Phototransduction — the cGMP cascade as a PDE pair: light drives phosphodiesterase hydrolysis of cGMP, closing cGMP-gated channels and hyperpolarizing the membrane toward ~−70 mV. The graded voltage — not a spike — is what bipolar cells read.
  4. Center-surround antagonism — horizontal cells pool the surround; the bipolar/ganglion signal is a difference of Gaussians (center σ = 1 px, surround σ = 3 px). Uniform fields cancel; edges survive — the retina reports contrast, not luminance.
  5. ON/OFF rectification — ganglion cells can’t fire negative; the DoG output splits into ON (depolarizing-center) and OFF (hyperpolarizing-center) channels, the two parallel pathways the LGN receives.

Integration is forward Euler on the transduction pair — stable for dt ≤ ~10 ms given the rate constants below; Retina::step clamps the states into their physical ranges so a large dt degrades gracefully instead of diverging.
