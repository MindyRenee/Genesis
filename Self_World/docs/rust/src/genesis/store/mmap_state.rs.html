1//! Memory-mapped core state file.
2//!
3//! This is the persistence layer for [`GenesisCoreState`]. It handles:
4//!
5//! - **Creating** a new state file on disk (zeroed, then initialised)
6//! - **Opening** an existing state file and mapping it into memory
7//! - **Crash recovery**: detecting corruption via magic, version, and
8//!   checksum, and recovering when possible
9//! - **Lock-free reads**: readers get an owned copy of the state via
10//!   a single volatile copy — no Rust reference to the mmap'd
11//!   memory is ever created, so there is no aliasing with concurrent
12//!   writers. A racing read may observe a torn snapshot; readers that
13//!   cannot tolerate that take the flock-serialized
14//!   `read_consistent_locked` path.
15//! - **Serialized writes**: writers are serialized by the in-process
16//!   `write_lock` mutex and the cross-process flock; each publish is
17//!   a single volatile copy of a fully-prepared stack state.
18//! - **Synchronisation**: `sync()` flushes dirty pages to disk so
19//!   state survives a crash
20//!
21//! ## Why mmap instead of read/write?
22//!
23//! On a 4.7 GB RAM machine, we can't afford to hold copies of state
24//! in heap memory. With mmap, the OS manages paging — the ~3.4 KB
25//! state struct occupies a single page (4 KB), and the kernel keeps
26//! it cached or pages it out as needed. We get a direct pointer to
27//! the file's contents with zero copy.
28//!
29//! ## Memory safety: why no `&GenesisCoreState`?
30//!
31//! The mmap'd region is `MAP_SHARED` — it can be modified by another
32//! thread (via [`MmapState::modify`]) or another process at any time. Returning
33//! a Rust `&GenesisCoreState` from the mmap'd memory would be
34//! **undefined behaviour**: Rust's aliasing rules forbid a `&` from
35//! coexisting with a `&mut` to the same bytes. The compiler is free
36//! to assume that a `&`
37//! reference's pointee does not change, which could cause miscompilation
38//! when another thread writes through `&mut`.
39//!
40//! Instead, the read API ([`MmapState::read`] and [`MmapState::read_consistent`]) performs
41//! volatile byte copies through raw pointers, returning an **owned**
42//! `GenesisCoreState` on the stack. Readers therefore create no
43//! reference to the mmap'd memory at all.
44//!
45//! ### The writer never forms a reference into the mapping
46//!
47//! Every production write path — [`MmapState::modify`] and the open-time
48//! repairs/migrations — runs its mutation on a **stack copy** and
49//! publishes it with `publish_stack` (a single `write_volatile`).
50//! No `&` or `&mut` into
51//! the shared mapping is ever formed, so there is no aliasing with
52//! concurrent readers under Stacked/Tree Borrows: the old pattern
53//! (a `&mut GenesisCoreState` materialised into `MAP_SHARED` for the
54//! whole transaction, which Miri flagged and which only happened to
55//! survive because volatile loads are never dead) is gone.
56//!
57//! Consequences, kept deliberately:
58//!
59//! - A panicking [`MmapState::modify`] closure only ever saw the stack copy, so
60//!   the mapping needs no rollback — it was never touched.
61//! - `read_volatile` in the readers remains load-bearing: it stops
62//!   the compiler eliding or merging the loads, it is not (and never
63//!   was) what made concurrent access defined.
64//! - `MmapState::state_mut` was removed: it formed `&mut` references
65//!   into `MAP_SHARED` memory with exclusivity left to the caller,
66//!   and the only callers were tests that now use `modify`'s stack
67//!   copy. No API may vend references into the mapping.
68//!
69//! ## File layout
70//!
71//! ```text
72//! offset 0:     GenesisCoreState (3480 bytes)
73//! offset 3480:  (unused, padding to page boundary)
74//! ```
75//!
76//! The state struct is 3480 bytes and the file is page-aligned, so the
77//! mapping is at least one page and the state sits at its start. (On a
78//! host with a 64 KiB page — aarch64, for instance — `page_align_up`
79//! expands the file to 64 KiB, not 4 KiB.)
80

102/// The actual mmap/ftruncate length: `FILE_SIZE` rounded up to the OS
103/// page size. On 4K-page machines this equals `FILE_SIZE`; on 16K/64K-page

111/// Derive the initial circadian phase [0, 1) from the local time of
112/// day encoded in `now_ms` (Unix epoch milliseconds).
113///
114/// Phase 0.0 = local midnight, matching the melatonin model's
115/// wall-clock semantics ("Phase 0.0 (midnight): 1.0"). The oscillator
116/// advances at exactly 24h per cycle, so its initial phase determines
117/// its permanent offset from the real day/night cycle — anchoring it
118/// to the wall clock at state birth keeps melatonin's night window
119/// and the dopamine/histamine daytime elevation aligned with the
120/// machine's local day.
121///
122/// Uses `localtime_r` so the rhythm follows the machine's timezone.
123/// If the conversion is unavailable (`now_ms` out of `time_t` range,
124/// or `localtime_r` fails), falls back to UTC — deterministic, exact
125/// on UTC machines, and in any case anchored to the real day rather
126/// than to file-creation time.
127fn local_phase_of_day(now_ms: u64) -> f32 {
128    (local_seconds_of_day(now_ms) as f32 / 86_400.0).rem_euclid(1.0)
129}

131/// Seconds since local midnight at `now_ms`, falling back to UTC when the
132/// local conversion is unavailable. See [`local_phase_of_day`].
133pub(crate) fn local_seconds_of_day(now_ms: u64) -> i64 {
134    let secs = now_ms / 1000;
135    // UTC fallback: seconds of day modulo 86400.
136    let utc_secs_of_day = (secs % 86_400) as i64;
137
138    libc::time_t::try_from(secs)
139        .ok()
140        .and_then(|t| {
141            let mut tm: libc::tm = unsafe { std::mem::zeroed() };
142            // SAFETY: `t` is a valid `time_t` (range-checked above) and
143            // `tm` is a properly sized, zero-initialised, caller-owned
144            // struct. `localtime_r` (unlike `localtime`) is thread-safe:
145            // it writes only into `tm` and returns null on failure,
146            // leaving `tm` zeroed — handled by the `None` branch.
147            let ok = unsafe { libc::localtime_r(&t, &mut tm) };
148            if ok.is_null() {
149                None
150            } else {
151                Some(
152                    i64::from(tm.tm_hour) * 3600 + i64::from(tm.tm_min) * 60 + i64::from(tm.tm_sec),
153                )
154            }
155        })
156        .unwrap_or(utc_secs_of_day)
157}

159/// A memory-mapped Genesis core state file.
160///
161/// This owns the mmap'd region and the file descriptor. When dropped,
162/// it unmaps the memory and closes the file.
163///
164/// # Concurrency model
165///
166/// The mmap'd region is `MAP_SHARED` and may be written to by another
167/// thread in this process (via [`MmapState::modify`]) or by another process at
168/// any time. To avoid Rust aliasing undefined behaviour, the read API
169/// ([`MmapState::read`], [`MmapState::read_consistent`]) **never** creates a `&GenesisCoreState`
170/// to the mmap'd bytes. Instead, it performs volatile byte copies through
171/// raw pointers, returning an owned `GenesisCoreState` on the caller's
172/// stack.
173///
174/// Writers are serialised by an in-process `Inhibition` ([`MmapState::modify`]) and a
175/// cross-process `flock(LOCK_EX)` advisory lock on the state file.
176/// [`MmapState::modify`] copies the current snapshot to an owned stack value,
177/// hands the closure a `&mut GenesisCoreState` to that private copy,
178/// and publishes it with a single volatile copy. No production write
179/// path creates a Rust reference into the mmap'd memory. The flock
180/// ensures that only one process can write at a time, preventing two
181/// processes from publishing concurrently.
182///
183/// Cross-process reads remain lock-free; a racing read may observe a
184/// torn snapshot — readers that cannot tolerate that take the
185/// flock-serialized `read_consistent_locked` path.
186pub struct MmapState {
187    /// Pointer to the mmap'd region.
188    ptr: *mut u8,
189    /// The file descriptor (kept open for msync).
190    fd: i32,
191    /// Whether we created this file (vs opening an existing one).
192    created: bool,
193    /// Coarse lock serializing writers.
194    ///
195    /// `MmapState` is shared between the daemon's reactive handler and
196    /// the IPC thread via `Arc`. Both threads can call
197    /// [`MmapState::modify`], which
198    /// mutates the mmap'd state. This mutex ensures only one writer
199    /// proceeds at a time, preventing data races on checksums and
200    /// state fields. Reads via [`MmapState::read`] and
201    /// [`MmapState::read_consistent`] remain lock-free.
202    ///
203    /// If the lock is poisoned, [`MmapState::modify`] returns
204    /// `StateFileError::LockFailed`. The daemon intentionally panics
205    /// on this rather than risk writing to a potentially-torn shared
206    /// state.
207    write_lock: crate::inhibition::Inhibition<()>,
208    /// How long the body was dark before this open, in milliseconds —
209    /// `now - header.last_updated` measured before the open path
210    /// overwrote it. Zero for a newly created state. The daemon's
211    /// continuity sentinel reports this so the mind knows how long
212    /// the interruption lasted, not just that it happened.
213    offline_ms: u64,
214}

216// SAFETY: `MmapState` can be sent between threads and shared by
217// reference. The raw pointer and fd are not tied to a specific thread.
218// The safety of concurrent access is ensured by:
219//   - Reads: `read`/`read_consistent` use volatile byte copies through
220//     raw pointers — no Rust references to the mmap'd memory are
221//     created.
222//   - Writes: `modify` acquires `write_lock`, mutates an owned stack
223//     snapshot, then `publish_stack` uses volatile byte copies — no
224//     production writer creates a reference into the mapping.
225unsafe impl Send for MmapState {}
226unsafe impl Sync for MmapState {}

228impl MmapState {
229    /// Create a new state file at the given path, initialise it with
230    /// a fresh `GenesisCoreState`, and map it into memory.
231    ///
232    /// **Fails if the file already exists.** This prevents accidental
233    /// destruction of an existing brain state — a double-start or
234    /// misuse of `create` (instead of `open_or_create`) would otherwise
235    /// truncate the state file, wiping all neurochemical state, memory
236    /// pointers, and runtime manifest. Use `open_or_create` if you want
237    /// to open an existing file or create a new one.
238    pub fn create(
239        path: impl AsRef<Path>,
240        instance_id: u64,
241        now_ms: u64,
242    ) -> Result<Self, StateFileError> {
243        let path = path.as_ref();
244
245        // Create the file — create_new fails with EEXIST if the file
246        // already exists, preventing accidental truncation of an
247        // existing state file.
248        let file = OpenOptions::new()
249            .read(true)
250            .write(true)
251            .create_new(true)
252            .open(path)
253            .map_err(StateFileError::Io)?;
254
255        let fd = file.as_raw_fd();
256
257        // Take the open-time lock immediately, for the same reason
258        // `open` does: between `ftruncate` and the initialising store
259        // below there is a window in which the file exists, is the
260        // right size, and is entirely zeros. `open` locks, so a second
261        // daemon starting in that window would read the zeros and fail
262        // with `BadMagic`. `create_new` has already succeeded, so the
263        // EEXIST path is unaffected.
264        // SAFETY: `fd` is a valid open file descriptor.
265        unsafe { Self::lock_file(fd) }?;
266
267        // Set the file size
268        // SAFETY: ftruncate is a POSIX call on a valid, owned fd. The fd is
269        // obtained from `file.as_raw_fd()` and `file` is kept alive (forgotten
270        // later) so the fd remains valid. FILE_SIZE is a small constant.
271        unsafe {
272            if ftruncate(fd, mapped_len() as i64) != 0 {
273                // This call created the file. Leaving a zero-filled stub
274                // behind would make every subsequent `open_or_create`
275                // fail with `BadMagic` until it was deleted by hand —
276                // turning one transient error into a permanent manual
277                // repair. Unlink it on every failure path below.
278                let _ = std::fs::remove_file(path);
279                return Err(StateFileError::FtruncateFailed);
280            }
281        }
282        // Persist the file size metadata to stable storage. Without
283        // this, a crash after ftruncate but before the inode is
284        // flushed can leave a zero-length file. `msync` only flushes
285        // data pages, not the inode's i_size.
286        if let Err(e) = Self::do_fsync(fd) {
287            let _ = std::fs::remove_file(path);
288            return Err(e);
289        }
290
291        // mmap the file
292        let ptr = match Self::do_mmap(fd) {
293            Ok(p) => p,
294            Err(e) => {
295                let _ = std::fs::remove_file(path);
296                return Err(e);
297            }
298        };
299
300        // Initialise the state
301        let mut state = GenesisCoreState::new(instance_id, now_ms);
302        // Anchor the circadian oscillator to the actual local time of
303        // day (the system clock is the zeitgeber). The constructor's
304        // constant phase is only a placeholder for direct construction
305        // (tests, tools) — here, at the production birth path, the
306        // phase must be derived from the wall clock. Without this the
307        // oscillator's 24h cycle is phase-locked to file-creation time,
308        // so melatonin's night window and the dopamine/histamine
309        // daytime peaks drift permanently out of sync with the real
310        // day. Existing state files keep their evolved phase — this
311        // runs only on first creation.
312        state
313            .neurochemicals
314            .set_circadian_phase(local_phase_of_day(now_ms));
315        // circadian_phase is covered by the CRC32 (region 2 spans the
316        // neurochemical vector), so the checksum computed inside the
317        // constructor is now stale — recompute it, exactly as
318        // `write_end` does after any mutation.
319        state.checksum = state.compute_checksum();
320        // SAFETY: `ptr` was just returned by mmap with PROT_WRITE and
321        // FILE_SIZE ≥ size_of::<GenesisCoreState>(). The region is
322        // exclusively owned (no other references exist yet).
323        // write_volatile prevents the compiler from optimizing out
324        // the store, ensuring the state is written to the mmap'd file.
325        unsafe {
326            std::ptr::write_volatile(ptr as *mut GenesisCoreState, state);
327        }
328
329        // Sync to disk. If this fails we must release the mapping
330        // before returning, otherwise the caller has no way to do so
331        // because `Self` has not been constructed yet.
332        if let Err(e) = Self::do_msync(ptr, mapped_len()) {
333            // SAFETY: `ptr` is a valid mmap'd region of FILE_SIZE bytes
334            // that we own exclusively. The file is still owned by `file`,
335            // which will close the fd when dropped at the end of scope.
336            unsafe {
337                munmap(ptr as *mut c_void, mapped_len());
338            }
339            // See above: unlink the stub this call created.
340            let _ = std::fs::remove_file(path);
341            return Err(e);
342        }
343
344        // The open-time lock only protects initialization. Release it
345        // before returning the live mapping so another MmapState can open
346        // the file and contend through modify()'s writer lock.
347        // SAFETY: fd is valid and the initialization transaction is complete.
348        unsafe { Self::unlock_file(fd) };
349
350        // All fallible steps succeeded. Transfer fd ownership to Self.
351        std::mem::forget(file);
352
353        Ok(Self {
354            ptr,
355            fd,
356            created: true,
357            write_lock: crate::inhibition::Inhibition::new(()),
358            offline_ms: 0,
359        })
360    }

362    /// Open an existing state file, map it into memory, and verify
363    /// its integrity.
364    ///
365    /// If the file doesn't exist, returns `StateFileError::NotFound`.
366    /// If the file is corrupted (bad magic, version mismatch, or
367    /// checksum failure), returns an error with details.
368    ///
369    /// Verification and migration are performed through volatile reads
370    /// and raw pointers — no `&GenesisCoreState` reference to the
371    /// mmap'd memory is created. This is safe even though the mmap
372    /// is `MAP_SHARED` because no `MmapState` has been returned to
373    /// the caller yet, so no other thread in this process can access
374    /// the mapping.
375    pub fn open(path: impl AsRef<Path>) -> Result<Self, StateFileError> {
376        let path = path.as_ref();
377
378        if !path.exists() {
379            return Err(StateFileError::NotFound);
380        }
381
382        let file = OpenOptions::new()
383            .read(true)
384            .write(true)
385            .open(path)
386            .map_err(StateFileError::Io)?;
387
388        let fd = file.as_raw_fd();
389
390        // Serialize open-time verification and migration with writers
391        // in other processes. A volatile snapshot is not coherent while
392        // another process is between write_begin and write_end; holding
393        // the same flock used by modify() makes the snapshot and any
394        // migration atomic with respect to cross-process writes.
395        // SAFETY: `fd` is a valid open file descriptor.
396        unsafe { Self::lock_file(fd) }?;
397
398        // Check file size. Current files are at least the current
399        // struct size, but a known legacy v3 file is intentionally
400        // smaller because the inference-signals tail grew from 60 to
401        // 64 bytes. That layout is migrated below after the mapping is
402        // established. Reject anything smaller than the known legacy
403        // layout rather than trying to interpret arbitrary/truncated
404        // bytes as a Genesis state.
405        let metadata = match file.metadata() {
406            Ok(metadata) => metadata,
407            Err(e) => {
408                // SAFETY: `fd` is valid and the open lock is held.
409                unsafe { Self::unlock_file(fd) };
410                return Err(StateFileError::Io(e));
411            }
412        };
413        if metadata.len() < crate::state::core_state::LEGACY_SIZE as u64 {
414            // SAFETY: `fd` is valid and the open lock is held.
415            unsafe { Self::unlock_file(fd) };
416            return Err(StateFileError::FileTooSmall {
417                expected: GenesisCoreState::SIZE as u64,
418                found: metadata.len(),
419            });
420        }
421
422        // Ensure the file is at least the page-aligned mapping length so
423        // the mmap region is fully backed by the file. Without this, a
424        // file that is exactly the state size would be mapped
425        // as a full page, leaving the tail unbacked — SIGBUS on access.
426        if metadata.len() < mapped_len() as u64 {
427            // SAFETY: `fd` is a valid open file descriptor with write
428            // permissions. ftruncate extends the file to FILE_SIZE,
429            // zero-filling the new bytes.
430            unsafe {
431                if ftruncate(fd, mapped_len() as i64) != 0 {
432                    let error = std::io::Error::last_os_error();
433                    Self::unlock_file(fd);
434                    return Err(StateFileError::Io(error));
435                }
436            }
437            // Persist the size metadata so a crash doesn't leave a
438            // truncated file. See `create` for the full rationale.
439            if let Err(e) = Self::do_fsync(fd) {
440                // SAFETY: `fd` is valid and the open lock is held.
441                unsafe { Self::unlock_file(fd) };
442                return Err(e);
443            }
444        }
445
446        // mmap
447        let ptr = match Self::do_mmap(fd) {
448            Ok(ptr) => ptr,
449            Err(e) => {
450                // SAFETY: `fd` is valid and the open lock is held.
451                unsafe { Self::unlock_file(fd) };
452                return Err(e);
453            }
454        };
455        std::mem::forget(file);
456
457        // Verify integrity using a volatile copy — no reference to the
458        // mmap'd memory is created. This avoids aliasing issues even
459        // though the mapping is MAP_SHARED.
460        //
461        // SAFETY: `ptr` is a valid mmap'd region of FILE_SIZE bytes,
462        // FILE_SIZE ≥ size_of::<GenesisCoreState>(). `read_volatile`
463        // copies the bytes without creating a reference. The state
464        // is repr(C) with no padding gaps that would make the copy
465        // uninitialised.
466        // Verify integrity using a single volatile copy — no reference
467        // to the mmap'd memory is created. This avoids aliasing issues
468        // even though the mapping is MAP_SHARED. Using ONE copy for
469        // both verify() and verify_checksum() prevents a torn read: a
470        // concurrent writer could modify the MAP_SHARED file between
471        // two separate read_volatile calls, so the magic/version check
472        // would apply to one snapshot while the checksum check applied
473        // to a different (possibly partially written) one.
474        //
475        // SAFETY: `ptr` is a valid mmap'd region of FILE_SIZE bytes,
476        // FILE_SIZE ≥ size_of::<GenesisCoreState>(). `read_volatile`
477        // copies the bytes without creating a reference. The state
478        // is repr(C) with no padding gaps that would make the copy
479        // uninitialised.
480        let mut snapshot = unsafe { core::ptr::read_volatile(ptr as *const GenesisCoreState) };
481        if let Err(e) = snapshot.verify() {
482            match e {
483                crate::state::CoreStateError::VersionMismatch { found: 2, .. } => {
484                    // SAFETY: `ptr` is the live MAP_SHARED mapping of
485                    // `mapped_len()` bytes and `fd` is its open file
486                    // descriptor; the open-time flock is held and no
487                    // `MmapState` exists yet, so the migrate sees an
488                    // exclusive stack copy.
489                    snapshot =
490                        unsafe { Self::migrate_and_snapshot(ptr, fd, |s| s.migrate_state(2))? };
491                }
492                // v4 → v5: the sleep network was inserted ahead of the
493                // checksum, so every field from there on moved. Decode the
494                // file through the byte-exact v4 type, widen it (which
495                // seeds the network at its source initial conditions), and
496                // recompute the checksum.
497                crate::state::CoreStateError::VersionMismatch { found: 4, .. } => {
498                    // SAFETY: as for the v3 arm — exclusive ownership and
499                    // the flock is held, and the 4 KB mapping is larger
500                    // than the 3416-byte v4 struct.
501                    let legacy =
502                        unsafe { core::ptr::read_volatile(ptr as *const GenesisCoreStateV4) };
503                    if legacy.header.state_size as usize
504                        != core::mem::size_of::<GenesisCoreStateV4>()
505                    {
506                        // SAFETY: `fd`/`ptr` are the valid, exclusively
507                        // owned descriptors of the mapping made above;
508                        // unlock before unmapping and never touch
509                        // either again on this path.
510                        unsafe {
511                            Self::unlock_file(fd);
512                            munmap(ptr as *mut c_void, mapped_len());
513                            close(fd);
514                        }
515                        return Err(StateFileError::VerificationFailed(e));
516                    }
517                    let widened = legacy.into_current();
518                    // SAFETY: as above.
519                    snapshot = unsafe {
520                        Self::migrate_and_snapshot(ptr, fd, |s| {
521                            *s = widened;
522                            s.migrate_state(4)
523                        })?
524                    };
525                }
526                // v3 → v4: the layout itself changed — `ions` was
527                // inserted ahead of the checksum — so a v3 file cannot
528                // be repaired through a current-layout snapshot: every
529                // field after `manifest` would be read at the wrong
530                // offset. Decode it through the byte-exact v3 type,
531                // widen, then let the normal migration path seed the
532                // ion layer and recompute the checksum.
533                crate::state::CoreStateError::VersionMismatch { found: 3, .. } => {
534                    // SAFETY: as above — `ptr`/`fd` are exclusively
535                    // owned (no `MmapState` exists yet) and the flock is
536                    // held. The mapping is FILE_SIZE (one page), which
537                    // is larger than the 3296-byte v3 struct, so the
538                    // volatile copy stays in bounds.
539                    let legacy =
540                        unsafe { core::ptr::read_volatile(ptr as *const GenesisCoreStateV3) };
541                    if legacy.header.state_size as usize
542                        != core::mem::size_of::<GenesisCoreStateV3>()
543                    {
544                        // A v3 label on a file of some other size is a
545                        // damaged or foreign file, not a migration.
546                        // SAFETY: `fd`/`ptr` are the valid, exclusively
547                        // owned descriptors of the mapping made above;
548                        // unlock before unmapping and never touch
549                        // either again on this path.
550                        unsafe {
551                            Self::unlock_file(fd);
552                            munmap(ptr as *mut c_void, mapped_len());
553                            close(fd);
554                        }
555                        return Err(StateFileError::VerificationFailed(e));
556                    }
557                    let widened = legacy.into_current();
558                    // SAFETY: as above — `ptr`/`fd` are exclusively
559                    // owned here and the flock is held.
560                    snapshot = unsafe {
561                        Self::migrate_and_snapshot(ptr, fd, |s| {
562                            *s = widened;
563                            s.migrate_state(3)
564                        })?
565                    };
566                }
567                // Correct version, older struct size: the reserve at
568                // the end of the struct grew (see
569                // `GenesisCoreState::migrate_layout`), so no field
570                // before the signals block moved but the file is too
571                // short to read as-is. `migrate_layout` validates the
572                // size against `LEGACY_SIZE` itself.
573                crate::state::CoreStateError::SizeMismatch { found, .. } => {
574                    // SAFETY: as above.
575                    snapshot = unsafe {
576                        Self::migrate_and_snapshot(ptr, fd, |s| {
577                            s.migrate_layout(found)?;
578                            s.write_end_tail();
579                            Ok(())
580                        })?
581                    };
582                }
583                other => {
584                    // SAFETY: `fd`/`ptr` are the valid, exclusively
585                    // owned descriptors of the mapping made above; we
586                    // unlock before unmapping and never touch either
587                    // again on this path.
588                    unsafe {
589                        Self::unlock_file(fd);
590                        munmap(ptr as *mut c_void, mapped_len());
591                        close(fd);
592                    }
593                    return Err(StateFileError::VerificationFailed(other));
594                }
595            }
596        }
597
598        // Verify the CRC32 checksum on the same snapshot used for
599        // verify() above (or the re-read after migration). The
600        // `verify()` call only checks magic, version, and state_size —
601        // it does NOT validate the checksum. Without this check, a
602        // torn write or bit-rot that corrupts the neurochemical/zone
603        // state but leaves the header intact is silently accepted,
604        // leading to corrupt state being used by every consumer (tick
605        // loop, IPC, cpufreq).
606        if let Err(e) = snapshot.verify_checksum() {
607            // SAFETY: unlock before munmap/close on valid ptr/fd that
608            // we own exclusively. No other references exist. (close
609            // alone would release the flock; we unlock explicitly to
610            // match every other cleanup path in this function.)
611            unsafe {
612                Self::unlock_file(fd);
613                munmap(ptr as *mut c_void, mapped_len());
614                close(fd);
615            }
616            return Err(StateFileError::VerificationFailed(e));
617        }
618
619        // Re-anchor the circadian oscillator to the current local wall clock on every
620        // daemon restart. The oscillator is a zeitgeber-driven phase, not persistent
621        // elapsed-time state: preserving the old phase across a restart would shift
622        // sleep/wake chemistry by the downtime duration. Recompute all derived fields
623        // afterward because circadian phase contributes to effective levels and the
624        // emergent summary values.
625        let open_now_ms = std::time::SystemTime::now()
626            .duration_since(std::time::UNIX_EPOCH)
627            .map(|d| d.as_millis() as u64)
628            .unwrap_or(0);
629        // Offline rest: the persisted `last_updated` is the last moment
630        // the body was live, so the gap to now is downtime the
631        // integrator never saw. For Process S that gap is rest — the
632        // glymphatic channel clears adenosine whether the body is
633        // asleep or powered off — so apply the same sleep-side decay
634        // the per-tick integrator uses (chi_s = 4.2 h,
635        // Daan/Beersma/Borbély 1984) over the measured gap. A
636        // seconds-long restart keeps the day's accumulated pressure;
637        // an overnight outage clears it. This must run here, before
638        // `last_updated` is overwritten below — and it replaces the
639        // flat "restart ≈ slept" reset the mind used to apply at
640        // launch, which on a frequently restarted host pinned
641        // adenosine at the resting floor so the homeostat could never
642        // reach sleep onset.
643        let offline_ms = open_now_ms.saturating_sub(snapshot.header.last_updated);
644        let offline_hours = offline_ms as f64 / 3_600_000.0;
645        if offline_hours > 0.0 {
646            let adn = &mut snapshot.neurochemicals.chemicals
647                [crate::state::NeurochemicalId::Adenosine as usize];
648            let lower_asymptote = 0.20_f64;
649            let level = f64::from(adn.level);
650            let rested = lower_asymptote
651                + (-offline_hours
652                    / f64::from(
653                        crate::state::NeuroTickParams::DEFAULT.adenosine_clearance_tau_hours,
654                    ))
655                .exp()
656                    * (level - lower_asymptote);
657            let rested = crate::state::finite_clamp(rested as f32, 0.0, 1.0);
658            if level - f64::from(rested) > 0.005 {
659                eprintln!(
660                    "[state] offline rest: {offline_hours:.2}h down, \
661                     adenosine {level:.2} -> {rested:.2}"
662                );
663            }
664            adn.level = rested;
665        }
666        snapshot
667            .neurochemicals
668            .set_circadian_phase(local_phase_of_day(open_now_ms));
669        snapshot.neurochemicals.recompute_derived();
670        snapshot.header.last_updated = open_now_ms;
671        snapshot.checksum = snapshot.compute_checksum();
672        // SAFETY: `ptr` is the live MAP_SHARED mapping of
673        // `mapped_len()` bytes returned by `do_mmap` above; every
674        // munmap path returns before this point, so the mapping is
675        // still valid here. `publish_stack` writes only inside the
676        // mapped range.
677        unsafe { Self::publish_stack(ptr, &snapshot) };
678        if let Err(e) = Self::do_msync(ptr, mapped_len()) {
679            unsafe {
680                Self::unlock_file(fd);
681                munmap(ptr as *mut c_void, mapped_len());
682                close(fd);
683            }
684            return Err(e);
685        }
686
687        // Scrub any non-finite float before the state is published to
688        // any reader. The CRC cannot catch this: a state file that
689        // legitimately contains NaN is byte-exact and passes both
690        // `verify` and `verify_checksum`. The per-tick circuit breaker
691        // would fix most of it on the first tick, but between here and
692        // then a lock-free IPC read would hand NaN to the cognitive
693        // mind.
694        // SAFETY: same invariant as the reads above — `ptr` is a valid,
695        // mmap'd, page-aligned region of exactly `FILE_SIZE` bytes, the
696        // flock is held, and no `MmapState` exists yet. The scrub runs
697        // on a stack copy and publishes through `publish_stack`: no
698        // reference into the mapping is formed.
699        let mut scrubbed = unsafe { core::ptr::read_volatile(ptr as *const GenesisCoreState) };
700        if scrubbed.scrub_non_finite() {
701            let now_ms = std::time::SystemTime::now()
702                .duration_since(std::time::UNIX_EPOCH)
703                .map(|d| d.as_millis() as u64)
704                .unwrap_or(0);
705            scrubbed.header.last_updated = now_ms;
706            scrubbed.header.heartbeat = scrubbed.header.heartbeat.wrapping_add(1);
707            scrubbed.checksum = scrubbed.compute_checksum();
708            // SAFETY: valid ptr/len; flock held so no writer can be
709            // mid-transaction.
710            unsafe { Self::publish_stack(ptr, &scrubbed) };
711            if let Err(msync_err) = Self::do_msync(ptr, mapped_len()) {
712                // SAFETY: unlock before munmap/close on valid ptr/fd
713                // that we own exclusively.
714                unsafe {
715                    Self::unlock_file(fd);
716                    munmap(ptr as *mut c_void, mapped_len());
717                    close(fd);
718                }
719                return Err(msync_err);
720            }
721        }
722
723        // The verification/migration transaction is complete. Release the
724        // open-time flock before returning the live mapping; subsequent
725        // writers synchronize through MmapState::write_lock plus this file
726        // lock in their normal write path.
727        // SAFETY: `fd` is valid and still holds the flock acquired at
728        // open.
729        unsafe { Self::unlock_file(fd) };
730
731        Ok(Self {
732            ptr,
733            fd,
734            created: false,
735            write_lock: crate::inhibition::Inhibition::new(()),
736            offline_ms,
737        })
738    }

790    /// Take a lock-free, wait-free snapshot of the state.
791    ///
792    /// A single volatile copy of the whole struct — there is no
793    /// sequence lock, so a read that races a publish may observe a
794    /// torn snapshot. Callers that need a guarantee take
795    /// [`MmapState::read_consistent_locked`], which serializes
796    /// against writers through the cross-process flock.
797    ///
798    /// The `Option` return is kept for call-site compatibility with
799    /// the former sequence-lock protocol; it now always yields `Some`.
800    ///
801    /// Unlike [`GenesisCoreState::read_consistent`], this method
802    /// operates directly on the raw mmap pointer and **never** creates
803    /// a `&GenesisCoreState` reference to the mmap'd memory. This
804    /// eliminates the aliasing undefined behaviour that would occur if
805    /// a `&` from `state()` coexisted with a `&mut` from `modify()`
806    /// on another thread.
807    ///
808    /// The returned `GenesisCoreState` is an owned stack copy — the
809    /// caller can use it freely without worrying about concurrent
810    /// mutation.
811    ///
812    /// # Example
813    ///
814    /// ```
815    /// # use genesis::store::mmap_state::MmapState;
816    /// # let path = std::env::temp_dir()
817    /// #     .join(format!("genesis-mmap-doctest-{}", std::process::id()));
818    /// # let mmap = MmapState::open_or_create(&path, 1, 0).expect("open");
819    /// let snapshot = mmap.read_consistent();
820    /// assert!(snapshot.is_some());
821    /// # let _ = std::fs::remove_file(&path);
822    /// ```
823    pub fn read_consistent(&self) -> Option<GenesisCoreState> {
824        Some(self.read())
825    }

827    /// Read serialized against writers by the same
828    /// cross-process `flock` that [`MmapState::modify`](Self::modify) holds for
829    /// its entire transaction.
830    ///
831    /// `LOCK_SH` blocks until any exclusive (writer) lock is released,
832    /// so the volatile copy cannot overlap a publish — this is the
833    /// read path for callers that must not observe a torn snapshot.
834    /// Unlike [`MmapState::read_consistent`] it can block briefly while
835    /// a writer publishes.
836    pub fn read_consistent_locked(&self) -> Result<GenesisCoreState, StateFileError> {
837        // SAFETY: `self.fd` is a valid open file descriptor kept alive
838        // for the lifetime of this MmapState.
839        unsafe { Self::lock_file_shared(self.fd) }?;
840        // Under LOCK_SH no writer's exclusive lock is held, so this
841        // volatile copy cannot race a publish.
842        let state = self.read();
843        // SAFETY: `self.fd` is valid and we hold the lock.
844        unsafe { Self::unlock_file(self.fd) };
845        Ok(state)
846    }

850    /// Safely modify the core state within a write transaction.
851    ///
852    /// The closure runs against a **stack copy**, never against the
853    /// mapping: no `&` or `&mut` into the mmap'd memory is formed on
854    /// any path here (see `publish_stack`). On success the prepared
855    /// copy is published as a single volatile copy with its checksum;
856    /// on closure panic the mapping is untouched — there is nothing to
857    /// roll back — and the panic resumes after the flock is released.
858    ///
859    /// This acquires the in-process writer mutex plus the
860    /// cross-process flock (non-blocking; `FileLockBusy` when another
861    /// process is writing), stamps the heartbeat, runs the closure,
862    /// and publishes.
863    ///
864    /// # Errors
865    ///
866    /// Returns `StateFileError::LockFailed` if the internal writer
867    /// mutex is poisoned (a previous writer thread panicked while
868    /// holding the lock).
869    pub fn modify<F>(&self, now_ms: u64, f: F) -> Result<(), StateFileError>
870    where
871        F: FnOnce(&mut GenesisCoreState),
872    {
873        // Serialize writers within this process. Holding this mutex
874        // for the duration of the transaction makes `modify` safe
875        // across threads.
876        let _guard = self
877            .write_lock
878            .lock()
879            .map_err(|_| StateFileError::LockFailed)?;
880
881        // Acquire a cross-process exclusive lock on the state file.
882        // The in-process mutex only protects against concurrent writers
883        // within this process — but the file is mapped MAP_SHARED, so
884        // another process that opens the same path can write to the
885        // same bytes concurrently. The flock
886        // serializes writers across all processes. We use LOCK_NB
887        // (non-blocking) so the daemon doesn't hang if another process
888        // holds the lock — it returns FileLockBusy instead, letting
889        // the caller retry or skip this tick.
890        //
891        // The lock is released after the transaction completes (or on
892        // drop of the MmapState, which closes the fd).
893        // SAFETY: `self.fd` is a valid open file descriptor kept alive
894        // for the lifetime of this MmapState.
895        unsafe { Self::lock_file(self.fd) }?;
896
897        // Stack working copy: `read` copies through a raw pointer and
898        // forms no reference, so the closure's `&mut` below aliases
899        // nothing in the mapping (or anywhere else). Holding the
900        // flock additionally guarantees no other process is
901        // publishing concurrently, so this copy is coherent.
902        let mut next = self.read();
903        // Heartbeat stamp.
904        next.header.last_updated = now_ms;
905        next.header.heartbeat = next.header.heartbeat.wrapping_add(1);
906        let result = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| f(&mut next)));
907        match result {
908            Ok(()) => {
909                next.checksum = next.compute_checksum();
910                // Hold the flock until AFTER the publish completes —
911                // releasing earlier would let another process start
912                // its own publish mid-window, interleaving the two
913                // volatile copies into a torn state.
914                // SAFETY: `self.ptr` is a valid MAP_SHARED mapping of
915                // `GenesisCoreState::SIZE` bytes; the in-process
916                // `write_lock` guard and the flock exclude every other
917                // writer.
918                unsafe { Self::publish_stack(self.ptr, &next) };
919                // SAFETY: `self.fd` is valid and we hold the lock.
920                unsafe { Self::unlock_file(self.fd) };
921                // Don't sync every write — too slow. Caller can sync explicitly.
922                Ok(())
923            }
924            Err(payload) => {
925                // The mapping was never touched — the panicking
926                // closure only saw the stack copy. Release the flock
927                // and resume; the in-process mutex poisons via the
928                // guard's drop, as before.
929                // SAFETY: `self.fd` is valid and we hold the lock.
930                unsafe { Self::unlock_file(self.fd) };
931                std::panic::resume_unwind(payload);
932            }
933        }
934    }

936    /// Flush dirty pages to disk. Call this after important writes
937    /// to ensure state survives a crash.
938    ///
939    /// Acquires `write_lock` and the cross-process flock to serialize
940    /// with any concurrent `modify()` call — including from another
941    /// process. Without this, `msync` could flush a partially written
942    /// (torn) state to disk if an IPC `modify()` is mid-publish, or if
943    /// another process is mid-write.
944    pub fn sync(&self) -> Result<(), StateFileError> {
945        let _guard = self
946            .write_lock
947            .lock()
948            .map_err(|_| StateFileError::LockFailed)?;
949        // SAFETY: `self.fd` is a valid open file descriptor.
950        unsafe { Self::lock_file(self.fd) }?;
951        let result = Self::do_msync(self.ptr, mapped_len());
952        // SAFETY: `self.fd` is valid and we hold the lock.
953        unsafe { Self::unlock_file(self.fd) };
954        result
955    }

957    /// Periodic (non-critical) flush.
958    ///
959    /// `sync` uses `msync(MS_SYNC)`, which blocks until the pages have
960    /// actually reached the device — tens to hundreds of milliseconds
961    /// on a journaled filesystem, and a full fsync stall under load.
962    /// The 5 Hz tick performs a dozen-plus `modify` transactions, each
963    /// running a full coupled-ODE integration, so blocking the tick
964    /// thread on a disk flush also delays every IPC write behind it and
965    /// widens the window in which `read_consistent` exhausts its
966    /// retries.
967    ///
968    /// For the periodic path, flush without blocking and without
969    /// waiting for a writer to finish: a transaction in flight is
970    /// already dirty, and the next flush will carry it. Use `sync` on
971    /// the shutdown path, where durability must be confirmed.
972    pub fn sync_async(&self) -> Result<(), StateFileError> {
973        // `try_lock` rather than `lock`: skipping a flush is always
974        // safe here, blocking the tick loop is not.
975        let Ok(_guard) = self.write_lock.try_lock() else {
976            return Ok(());
977        };
978        // SAFETY: `self.ptr` is a valid mmap'd region of
979        // `mapped_len()` bytes, for the lifetime of `self`.
980        let rc = unsafe { msync(self.ptr as *mut c_void, mapped_len(), MS_ASYNC) };
981        if rc != 0 {
982            return Err(StateFileError::MsyncFailed);
983        }
984        Ok(())
985    }

994    /// Publish a fully-prepared stack state to the mapping.
995    ///
996    /// One `write_volatile` of the whole prepared struct. No `&`/`&mut`
997    /// into the mapping is formed here or by the caller, so there is no
998    /// aliasing with concurrent readers under Stacked/Tree Borrows —
999    /// the previous `&mut`-into-`MAP_SHARED` pattern was unsound
1000    /// (Miri-flagged) and is gone from every production path.
1001    ///
1002    /// There is no sequence lock: a lock-free reader racing this copy
1003    /// may observe a torn snapshot. Readers that cannot tolerate that
1004    /// use [`MmapState::read_consistent_locked`].
1005    ///
1006    /// The caller must hold `write_lock` and the flock, and
1007    /// `prepared.checksum` must already cover `prepared` (as
1008    /// `modify` and the open-time repairs ensure before calling).
1009    ///
1010    /// # Safety
1011    ///
1012    /// `ptr` must be a valid mmap'd region of at least
1013    /// `GenesisCoreState::SIZE` bytes with no other writer active
1014    /// (caller-held locks guarantee this).
1015    unsafe fn publish_stack(ptr: *mut u8, prepared: &GenesisCoreState) {
1016        // SAFETY: `prepared` is a valid stack value (`Copy` — this
1017        // moves bytes without borrowing the mapping); the mapping is
1018        // writable and `SIZE` bytes long. Volatile so the compiler
1019        // must emit the stores.
1020        unsafe {
1021            Self::volatile_copy_region(
1022                (prepared as *const GenesisCoreState).cast::<u8>(),
1023                ptr,
1024                core::mem::size_of::<GenesisCoreState>(),
1025            );
1026        }
1027    }

1029    /// Copy `len` bytes from `src` to `dst` with volatile loads and
1030    /// stores, so the compiler can neither elide nor reorder the copy.
1031    ///
1032    /// Volatile byte-at-a-time rather than `copy_nonoverlapping` for the
1033    /// same reason the reader side uses `read_volatile`: the publish
1034    /// must be an observable effect on the mapping, and a plain copy
1035    /// leaves that to the optimizer's dead-store analysis. The volume
1036    /// is ~3 KB per transaction at ~10 Hz, so the cost is irrelevant
1037    /// next to the ODE integration this wraps.
1038    ///
1039    /// # Safety
1040    ///
1041    /// `src` must be readable and `dst` writable for `len` bytes, and
1042    /// the ranges must not overlap.
1043    unsafe fn volatile_copy_region(src: *const u8, dst: *mut u8, len: usize) {
1044        for i in 0..len {
1045            // SAFETY: caller guarantees both regions are valid for
1046            // `len` bytes; each index is in bounds. Volatile read and
1047            // write so neither is elided.
1048            unsafe {
1049                let byte = src.add(i).read_volatile();
1050                dst.add(i).write_volatile(byte);
1051            }
1052        }
1053    }

1055    fn do_mmap(fd: i32) -> Result<*mut u8, StateFileError> {
1056        // SAFETY: `fd` is a valid open file descriptor with read+write
1057        // permissions. Length is page-aligned via `mapped_len()`.
1058        // MAP_SHARED maps the file into memory for inter-process sharing.
1059        let ptr = unsafe {
1060            mmap(
1061                std::ptr::null_mut(),
1062                mapped_len(),
1063                PROT_READ | PROT_WRITE,
1064                MAP_SHARED,
1065                fd,
1066                0,
1067            )
1068        };
1069        if ptr == MAP_FAILED {
1070            return Err(StateFileError::MmapFailed);
1071        }
1072        Ok(ptr as *mut u8)
1073    }

1084    /// Run a migration against the mapped state in place, under the
1085    /// flock `open()` already holds, and return the post-migration
1086    /// snapshot.
1087    ///
1088    /// The returned snapshot is what the caller's `verify_checksum`
1089    /// must run against: reading the state again afterwards is a
1090    /// separate volatile copy, so the checksum check has to validate the
1091    /// same bytes the migration produced.
1092    ///
1093    /// On any error the flock is released and the mapping and fd are
1094    /// torn down before returning — the caller has no `MmapState` yet,
1095    /// so nothing else owns them. A panicking migration is rolled back
1096    /// the same way and then resumed.
1097    ///
1098    /// # Safety
1099    ///
1100    /// `ptr` must be a valid mmap'd region of at least
1101    /// `GenesisCoreState::SIZE` bytes, `fd` the open fd for it, and the
1102    /// caller must hold the flock and have no other reference to the
1103    /// mapped state. On error the function consumes `fd` and `ptr`.
1104    unsafe fn migrate_and_snapshot(
1105        ptr: *mut u8,
1106        fd: i32,
1107        migrate: impl FnOnce(&mut GenesisCoreState) -> Result<(), CoreStateError>,
1108    ) -> Result<GenesisCoreState, StateFileError> {
1109        // Stack working copy: `read_volatile` forms no reference, so
1110        // the migration's `&mut` aliases nothing in the mapping (or
1111        // anywhere else). A panicking or failing migration leaves the
1112        // mapping untouched — there is nothing to roll back.
1113        // SAFETY: `ptr` is a valid mmap'd region of at least
1114        // `GenesisCoreState::SIZE` bytes; the caller holds the flock
1115        // and no `MmapState` exists yet.
1116        let mut next = unsafe { core::ptr::read_volatile(ptr as *const GenesisCoreState) };
1117        let now_ms = std::time::SystemTime::now()
1118            .duration_since(std::time::UNIX_EPOCH)
1119            .map(|d| d.as_millis() as u64)
1120            .unwrap_or(0);
1121        next.header.last_updated = now_ms;
1122        next.header.heartbeat = next.header.heartbeat.wrapping_add(1);
1123        // Publish the migration under the flock, which excludes other
1124        // writers; lock-free readers may still race the copy.
1125        let migration =
1126            std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| migrate(&mut next)));
1127        match migration {
1128            Ok(Ok(())) => {
1129                // Belt-and-suspenders: the migrations maintain the
1130                // checksum themselves, but the publish must cover
1131                // exactly what it writes — recompute over the final
1132                // bytes (also covers the heartbeat stamp above).
1133                next.checksum = next.compute_checksum();
1134                // SAFETY: same mapping invariants as the read above.
1135                unsafe { Self::publish_stack(ptr, &next) };
1136            }
1137            Ok(Err(mig_err)) => {
1138                // SAFETY: release the lock before cleanup; fd/ptr are
1139                // exclusively owned. No other references exist.
1140                unsafe {
1141                    Self::unlock_file(fd);
1142                    munmap(ptr as *mut c_void, mapped_len());
1143                    close(fd);
1144                }
1145                return Err(StateFileError::VerificationFailed(mig_err));
1146            }
1147            Err(payload) => {
1148                // SAFETY: release the lock before cleanup; fd/ptr are
1149                // exclusively owned. No other references exist.
1150                unsafe {
1151                    Self::unlock_file(fd);
1152                    munmap(ptr as *mut c_void, mapped_len());
1153                    close(fd);
1154                }
1155                std::panic::resume_unwind(payload);
1156            }
1157        }
1158        // Sync the migrated state to disk. A failed msync here IS
1159        // significant: the caller believes the migration succeeded and
1160        // the state is durable, but the on-disk file may still contain
1161        // the old data. If the process crashes before the next explicit
1162        // sync(), the migration is lost and the next open() will
1163        // re-trigger it (which is safe but wasteful) or fail if the file
1164        // is partially written. Propagate the error so the caller knows
1165        // the state is not durable.
1166        if let Err(msync_err) = Self::do_msync(ptr, mapped_len()) {
1167            // SAFETY: unlock before cleanup; fd/ptr are exclusively
1168            // owned. No other references exist.
1169            unsafe {
1170                Self::unlock_file(fd);
1171                munmap(ptr as *mut c_void, mapped_len());
1172                close(fd);
1173            }
1174            return Err(msync_err);
1175        }
1176        // Return the exact bytes published — no second copy, so the
1177        // caller's checksum check validates what migration produced.
1178        Ok(next)
1179    }

1181    /// Flush file metadata (especially the size change from `ftruncate`)
1182    /// to stable storage.
1183    ///
1184    /// `msync` flushes dirty *data pages* but does **not** guarantee
1185    /// that the file's *size metadata* (the inode's `i_size`) is
1186    /// persisted. A crash after `ftruncate` but before the inode is
1187    /// flushed can leave a zero-length file, which would cause the
1188    /// next `open` to fail with `FileTooSmall`. `fdatasync` flushes
1189    /// the inode metadata (without the full `fsync` overhead of
1190    /// flushing ctime/mtime), making the size change durable.
1191    fn do_fsync(fd: i32) -> Result<(), StateFileError> {
1192        // SAFETY: `fd` is a valid open file descriptor.
1193        let rc = unsafe { fdatasync(fd) };
1194        if rc != 0 {
1195            return Err(StateFileError::FsyncFailed);
1196        }
1197        Ok(())
1198    }

1200    /// Acquire an exclusive cross-process advisory lock on the state
1201    /// file. Uses `flock(LOCK_EX | LOCK_NB)` — non-blocking, so if
1202    /// another process holds the lock, this returns
1203    /// `FileLockBusy` immediately instead of hanging the daemon.
1204    ///
1205    /// The lock is associated with the open file description (not the
1206    /// fd or the process), so it is automatically released when the
1207    /// last fd referring to this open file description is closed —
1208    /// including by `Drop` on `MmapState`. For explicit release, use
1209    /// [`unlock_file`].
1210    ///
1211    /// # Safety
1212    ///
1213    /// `fd` must be a valid open file descriptor.
1214    unsafe fn lock_file(fd: i32) -> Result<(), StateFileError> {
1215        // SAFETY: `fd` is a valid open file descriptor. `flock` is
1216        // async-signal-safe and does not allocate.
1217        let rc = unsafe { flock(fd, LOCK_EX | LOCK_NB) };
1218        if rc != 0 {
1219            // Use Rust's platform-neutral errno accessor rather than a
1220            // libc-specific errno symbol.
1221            let errno = std::io::Error::last_os_error().raw_os_error();
1222            if errno == Some(libc::EWOULDBLOCK) || errno == Some(libc::EAGAIN) {
1223                return Err(StateFileError::FileLockBusy);
1224            }
1225            return Err(StateFileError::Io(std::io::Error::last_os_error()));
1226        }
1227        Ok(())
1228    }
1229
1230    /// Acquire the cross-process advisory lock in shared mode,
1231    /// blocking until any exclusive (writer) lock is released.
1232    ///
1233    /// `modify` serializes its whole transaction under `LOCK_EX`, so
1234    /// a shared holder can only ever observe complete publishes.
1235    ///
1236    /// # Safety
1237    ///
1238    /// `fd` must be a valid open file descriptor.
1239    unsafe fn lock_file_shared(fd: i32) -> Result<(), StateFileError> {
1240        // SAFETY: `fd` is a valid open file descriptor. `flock` is
1241        // async-signal-safe and does not allocate.
1242        let rc = unsafe { flock(fd, LOCK_SH) };
1243        if rc != 0 {
1244            return Err(StateFileError::Io(std::io::Error::last_os_error()));
1245        }
1246        Ok(())
1247    }
1248
1249    /// Release the cross-process advisory lock.
1250    ///
1251    /// # Safety
1252    ///
1253    /// `fd` must be a valid open file descriptor that currently holds
1254    /// a lock acquired by [`lock_file`] or [`lock_file_shared`].
1255    unsafe fn unlock_file(fd: i32) {
1256        // SAFETY: `fd` is a valid open file descriptor.
1257        unsafe {
1258            let _ = flock(fd, LOCK_UN);
1259        }
1260    }
1261}

1263impl Drop for MmapState {
1264    fn drop(&mut self) {
1265        // Best-effort msync before munmap. Without this, any core
1266        // state writes that the caller did not explicitly sync()
1267        // before drop are lost. We ignore errors here because Drop
1268        // cannot propagate them.
1269        let _ = Self::do_msync(self.ptr, mapped_len());
1270        // SAFETY: `self.ptr` and `self.fd` are valid and exclusively
1271        // owned by this instance. No other references exist at drop time.
1272        unsafe {
1273            munmap(self.ptr as *mut c_void, mapped_len());
1274            close(self.fd);
1275        }
1276    }
1277}

1279/// Errors that can occur when working with the state file.
1280#[derive(Debug)]
1281pub enum StateFileError {
1282    /// I/O error (file open, metadata, etc.)
1283    Io(std::io::Error),
1284    /// File doesn't exist (from `open`).
1285    NotFound,
1286    /// File is too small to contain a GenesisCoreState.
1287    FileTooSmall {
1288        /// The expected file size.
1289        expected: u64,
1290        /// The actual file size found.
1291        found: u64,
1292    },
1293    /// `ftruncate` failed.
1294    FtruncateFailed,
1295    /// `fdatasync` failed (flushing file metadata after ftruncate).
1296    FsyncFailed,
1297    /// `mmap` failed.
1298    MmapFailed,
1299    /// `msync` failed.
1300    MsyncFailed,
1301    /// State verification failed (bad magic, version, or checksum).
1302    VerificationFailed(CoreStateError),
1303    /// The internal writer mutex was poisoned.
1304    LockFailed,
1305    /// The cross-process file lock could not be acquired (another
1306    /// process is writing to the same state file). This is returned
1307    /// instead of blocking, so the caller can retry or degrade
1308    /// gracefully rather than hanging the daemon.
1309    FileLockBusy,
1310}
1311
1312impl std::fmt::Display for StateFileError {
1313    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
1314        match self {
1315            Self::Io(e) => write!(f, "I/O error: {e}"),
1316            Self::NotFound => write!(f, "state file not found"),
1317            Self::FileTooSmall { expected, found } => {
1318                write!(
1319                    f,
1320                    "file too small: expected {expected} bytes, found {found}"
1321                )
1322            }
1323            Self::FtruncateFailed => write!(f, "ftruncate failed"),
1324            Self::FsyncFailed => write!(f, "fdatasync failed"),
1325            Self::MmapFailed => write!(f, "mmap failed"),
1326            Self::MsyncFailed => write!(f, "msync failed"),
1327            Self::VerificationFailed(e) => write!(f, "verification failed: {e}"),
1328            Self::LockFailed => write!(f, "state writer lock poisoned"),
1329            Self::FileLockBusy => write!(f, "state file locked by another process"),
1330        }
1331    }
1332}
