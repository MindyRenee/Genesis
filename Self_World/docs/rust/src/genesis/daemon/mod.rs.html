1//! Subcognitive daemon — the always-on background process.
2//!
3//! This is Genesis's subcognitive mind. It runs continuously, even when
4//! nobody is interacting with it, and owns the core state, memory
5//! stores, and the IPC surface the cognitive mind talks to. It:
6//!
7//! - Advances the neurochemical dynamics (the "feel" loop)
8//! - Consolidates short-term memories into long-term storage
9//! - Finds associations between memories
10//! - Dreams when sleeping (free association → creative insights)
11//! - Maintains the core state and memory stores
12//!
13//! # Process model
14//!
15//! The daemon is a standalone process that owns the core state file,
16//! STM ring buffer, and LTM store. Other processes (the Python
17//! cognitive mind) communicate with it via a Unix domain socket.
18//!
19//! The daemon is **lease-driven**: the cognitive mind holds a short
20//! lease (renewed by every reactive IPC command) and drives each
21//! function through IPC while alive. Past the lease
22//! (`tick::MIND_LEASE_SECS`), the daemon drives the full loop
23//! itself — neurochemistry, consolidation, sleep-gated dreaming,
24//! association, sensing, intention expiry with zone arbitration and
25//! traces, body-control recommendation publishing, and model
26//! checkpoints — so the system keeps living instead of freezing
27//! during a stall, crash, or disconnect. Body-control *application*
28//! stays mind-requested; the fallback publishes and senses but never
29//! acts outward on its own. Staleness detection runs regardless, so
30//! a crashed mind's modules still read Stopped.
31//!
32//! ```text
33//! ┌──────────────────────────────────────────────────────────┐
34//! │                  Subcognitive Daemon                      │
35//! │                                                           │
36//! │  ┌───────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐ │
37//! │  │ Reactive  │→ │ Neuro    │→ │ Consol-  │→ │ Assoc-   │ │
38//! │  │ dispatch  │  │ chem     │  │ idation  │  │ iation   │ │
39//! │  └───────────┘  └──────────┘  └──────────┘  └──────────┘ │
40//! │       │                                          │        │
41//! │       ▼                                          ▼        │
42//! │  ┌─────────┐  ┌──────────┐  ┌──────────┐  ┌───────────┐  │
43//! │  │ Dream   │  │ House-   │  │ IPC      │  │ Manifest  │  │
44//! │  │ (sleep) │  │ keeping  │  │ Server   │  │ Update    │  │
45//! │  └─────────┘  └──────────┘  └──────────┘  └───────────┘  │
46//! └──────────────────────────────────────────────────────────┘
47//! ```
