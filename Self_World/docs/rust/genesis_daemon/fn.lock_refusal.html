Decide what a try_lock refusal means in the fallback loop.

WouldBlock is the normal case: the mind is mid-drive and this cycle should simply be skipped. Poisoned means some other thread panicked while holding the lock, and it never clears — every subsequent attempt fails the same way. Collapsing the two into continue made a dead subsystem look like a busy one: the daemon kept answering PING while neurochemistry, consolidation, dreaming and zone arbitration had all silently stopped. Poisoning is therefore reported, once per mutex, so it is visible without flooding the log on every cycle.
