genesis-retina — the eye as its own organ.

The retina opens the V4L2 capture device itself and publishes raw frames into the POSIX shared-memory segment /genesis_optic_nerve — the same segment the daemon’s embedded capture limb writes when no retina is running. One capture implementation, two carriers: the daemon runs it on a thread (OpticCapture), this binary runs it on the main thread of a dedicated process.

The CLI launches the retina before the daemon; ownership is settled on the nerve itself — the daemon’s own optic reader sees these frames arriving and keeps its embedded limb closed, and if this process dies the daemon takes the camera back. Exactly one process owns the device at a time. On SIGINT/SIGTERM the limb winds down and the segment’s name is unlinked, so a dead eye never publishes stale frames under a live name.
