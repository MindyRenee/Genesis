Spatial — the perceptual-symbolic layer of Genesis's reasoning.
 
Semantic reasoning traverses relations between *concepts*. This
package gives Genesis the complementary capacity: perceiving structure
in spatial input and reasoning about it symbolically — the parietal
"where/how" stream made explicit.
 
Pipeline:
 
    Grid (raw cells)
        |
        v
    perceive() -> Scene           objects + spatial relations
        |                           (the perceptual parse)
        +--> ground_scene()        Scene -> concept network edges
        |                           (semantic grounding)
        v
    SpatialReasoner.solve()        Transform hypotheses, verified
        |                           against every observed transition
        v
    SpatialSolution                rule + predictions
 
Consumers:
    - The cognition engine holds a ``SpatialReasoner`` instance so
      spatial problems raised in conversation can be perceived and
      reasoned about, not just talked past.

    SpatialReasoner(network: 'Any | None' = None, task_competence: 'TaskCompetence | None' = None) -&gt; 'None'
 
Few-shot spatial inference: transitions → rule → prediction.
 
The reasoner may optionally hold a ``ConceptNetwork`` so perceived
scenes and verified rules can be grounded into conceptual structure
(see ``grounding.py``). Grounding is a side channel — the search
itself works on grids alone.

learn(self, transforms: 'list[Transform]', *, taught: 'bool' = False) -> 'None'
Remember a rule for future tasks.
 
Called automatically on successful solves, or externally to
teach it the correct rule after it gets a task wrong. When a
concept network is attached, each rule is also grounded as a

language, analogy) can reason about what it knows.

        rules can't be selected as solutions or near-misses, so

        of re-deriving the same failure.

        semantically equivalent hypotheses making the same wrong
        prediction are excluded without banning an entire family.
