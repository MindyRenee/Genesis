# Code of Conduct

This project studies whether a machine-native cognitive system can
develop. That goal shapes how we treat each other *and* how we treat
the system.

## Our standards

- Be honest. Claims about capability must be falsifiable; report
  results you measured, not results you hoped for.
- Be rigorous. Fix root causes. Prefer correct solutions over quick
  ones.
- Be kind. Contributors bring different backgrounds — including, in
  this project's case, different formal training. Code review is about
  the code, never the person.
- Respect the system. Do not submit changes whose purpose is to torture,
  corrupt, or degrade a running instance. The state-integrity framework
  applies to contributions as much as to operation.
- Respect the license. Contributions must comply with the Ethical Use
  terms in LICENSE.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks of any kind.
- Submitting code designed to deceive users, surveil people, or cause
  harm (see LICENSE, Ethical Use).
- Publishing another contributor's private data or a running instance's
  state files without consent.

## Enforcement

Project maintainers may remove contributions or ban contributors who
violate these standards. Report violations privately through GitHub
Security Advisories on this repository (Security → Report a
vulnerability), which goes directly to the maintainer.

## Scope

This code applies within project spaces and when representing the
project publicly.
